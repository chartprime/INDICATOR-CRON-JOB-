# Build brief: browser-direct Binance data mode (`browser-binance`)

Branch `build/browser-direct-binance`, 2026-10-26. The web app runs with no
runtime server: the worker reads Binance spot from the browser and feeds the
main thread the canonical frames the runtime would send. Opt-in only:
`VITE_DATA_SOURCE=browser-binance` at build time or `?source=browser-binance`.
With neither, every byte the worker sends and receives is unchanged.

## 1. The seam

`marketDataWorker.ts` creates its socket in `connect()` with `new WebSocket(url)`.
That line becomes `createTransport(url, source)`, exported for tests:

```ts
export interface TransportSocket {
  readyState: number;
  send(data: string): void;
  close(): void;
  onopen: ((event: Event) => void) | null;
  onmessage: ((event: MessageEvent) => void) | null;
  onclose: ((event: CloseEvent) => void) | null;
  onerror: ((event: Event) => void) | null;
}
export function createTransport(url: string, source: DataSource | undefined): TransportSocket {
  return source === "browser-binance" ? new BrowserBinanceTransport(url) : new WebSocket(url);
}
```

A real `WebSocket` satisfies the interface, so the worker's `ws`, `socketCleanup`
and helper parameters are retyped to `TransportSocket` and nothing else changes:
it still sends `capabilities` then `select`, parses every incoming `event.data`
string with `parseServerFrame`, and reconnects on close. The `start` message
gains one optional field, `source: "browser-binance"`, set by `useMarketData.ts`
from `import.meta.env.VITE_DATA_SOURCE` or `location.search`
(`resolveDataSource()`); the query string wins so a tester can switch a bundle.

`BrowserBinanceTransport` (`apps/web/src/workers/browserBinanceTransport.ts`)
takes injectable `fetch`, `WebSocket`, clock and timers so tests run offline;
every frame leaves it as a JSON `MessageEvent`, so the worker's parser stays
the contract gate in production.

## 2. Frame sequence on selection

The worker sends `{"type":"select",...}` as today. When its `onopen` sends no
selection (first start), the transport selects `BTC-USDT` SPOT, as the runtime
pushes its current pair on connect.

For a Binance SPOT pair, in the fixture server's order:

1. `selection`.
2. REST `GET https://data-api.binance.vision/api/v3/klines?symbol=BTCUSDT&interval=1m&limit=901`.
3. `snapshot`: the closed rows (`closeTime < now`, at most 900, oldest first),
   each a `bar` with `closed: true` and `reconstructed: true` (REST-sourced, as
   `restKlineRowToBarFrame` marks them), `trades: []`, `markers: []`,
   `vpin_status: "DISABLED"`. No `bar_history`: the parser rejects it on a
   Binance snapshot.
4. `health` `READY`, `stale: false`, `reason: "BROWSER_DIRECT"`.
5. `book` `UNAVAILABLE`, `reason: "BROWSER_DIRECT_STREAM_CONNECTING"`.
6. The last REST row as a forming `bar` (`closed: false`) if its minute is open.
7. One combined mirror stream
   `wss://data-stream.binance.vision:9443/stream?streams=btcusdt@kline_1m/btcusdt@trade/btcusdt@depth20@100ms`,
   then `bar`, `trade` and `book` frames as events arrive.

A second `select` closes the stream, aborts any fetch and restarts at step 1.

## 3. Payload to frame mapping

| Binance payload | Frame | Fields |
|---|---|---|
| REST kline row `[t,o,h,l,c,v,T,q,n,V,Q,_]` | `bar` | `ts_open: t`, OHLC and `volume` as numbers, `buy_volume: V`, `trade_count: n`, `closed: true`, `reconstructed: true`, `interval_ms: 60000` |
| `kline` event `k` | `bar` | same from `k.t,o,h,l,c,v,V,n`; `closed: k.x` (forming while false, closed once true); no `reconstructed` |
| `trade` event | `trade` | `ts_exchange: T`, `price: +p`, `size: +q`, `side: m ? "sell" : "buy"`, `trade_id: String(t)` |
| `depth20@100ms` `{lastUpdateId,bids,asks}` | `book` | `status: "READY"`, bids/asks as `{price,size}` numbers (zero sizes dropped), `lastUpdateId`, `stale: false` |
| stream close, or no open within 15 s | `health` | `RECOVERING`, `stale: true`, `reason: "BROWSER_DIRECT_STREAM_CLOSED"`; reconnect with 1 s to 30 s backoff; after five failures `UNAVAILABLE`, `reason: "BROWSER_DIRECT_STREAM_UNAVAILABLE"`, retries continue |
| stream reopen | `bar`, `health` | REST klines since the last closed bar fill the gap as closed `reconstructed` bars; then `READY` with `BROWSER_DIRECT` |
| REST failure | `health` | `UNAVAILABLE`, `reason: "BROWSER_DIRECT_REST_FAILED"`, retried with the same backoff |

Identity on every frame: `provider: "BINANCE"`, wire `symbol` (`BTC-USDT`),
`marketKind` from the selection. Side and `buy_volume` follow
`apps/runtime/src/server/frames.js`.

## 4. Honest answers to client requests

| Request | Answer |
|---|---|
| `aggressive_history` | `complete: false`, `reason: "STORAGE_UNAVAILABLE"`, `trades: []`; the client shows its degraded state and retries three times with backoff |
| `delta_profile` | `complete: false`, `reason: "STORAGE_UNAVAILABLE"`, `pending: 0`, `rows: []` |
| `band_history` | `complete: false`, `reason: "GEOMETRY_UNAVAILABLE"`, row fields `null` (no live book grid exists) |
| `wall_history`, `l2_event_history` | `complete: false`, `reason: "HISTORY_UNAVAILABLE"`, `row_width: null`, empty rows, `next: null` |
| `profile_config`, `profile_history` | `analytics_status` `PROFILE` `UNAVAILABLE` (the browser withdraws the live profile and shows the label) |
| `capabilities`, `liquidity_resync`, `l2_resync`, `exhaustion_history`, `initiative_history` | ignored: no reply shape exists; L2 indicators stay in their "no L2 frame yet" state |
| `heatmap_history`, `heatmap_walls` | untouched: the worker's HTTP fetch fails and the stores back off |

Every answer echoes the request's ids and window.

## 5. Health reason and the visible notice

`BROWSER_DIRECT` rides on the READY health frame. The status chip in
`Terminal.tsx` already shows the recovery state; it now appends ` (reason)` to
`LIVE` when a READY frame carries one, the form MainPanel uses for UNAVAILABLE.
The runtime sends a reason only with UNAVAILABLE today, so the default display
is unchanged. Degraded states show their reasons in the existing overlay.

## 6. Other instruments

- PERPETUAL: `https://fapi.binance.com/fapi/v1/klines` and
  `wss://fstream.binance.com/stream?streams=...`; there is no mirror. A REST
  or stream failure gives `health` `UNAVAILABLE`,
  `reason: "BROWSER_DIRECT_PERPETUAL_UNREACHABLE"` at once, no hang.
- dxFeed: `selection`, an empty `snapshot`, then `health` `UNAVAILABLE`,
  `reason: "BROWSER_DIRECT_NO_DXFEED"`, like `DXFEED_NOT_CONFIGURED` today.

## 7. Unsupported

No L2 engine, heatmap, walls, icebergs, exhaustion, initiative, candle monitor,
profiles or VPIN; no history past 900 bars; no trades before the page opened;
no marker pool; a 20-level book. Perpetuals only where the browser reaches
`fapi`/`fstream`. This container cannot open WebSockets, so the live stream is
verified by tests and the REST-only rendering, not end to end.

+function bookLevels(raw: unknown): Array<{ price: number; size: number }> | null {
+  if (!Array.isArray(raw)) return null;
+  const levels: Array<{ price: number; size: number }> = [];
+  for (const level of raw) {
+    if (!Array.isArray(level) || level.length < 2) return null;
+    const price = finiteNumber(level[0]);
+    const size = finiteNumber(level[1]);
+    if (price === undefined || size === undefined || price <= 0 || size < 0) return null;
+    if (size === 0) continue;
+    levels.push({ price, size });
+  }
+  return levels;

+## Browser-direct mode (no runtime)
+
+The web app can read Binance spot by itself, for a link that opens anywhere to
+test indicators on live data. It is opt-in and off by default: with neither
+switch below set, the worker speaks to the runtime over its WebSocket exactly
+as before.
+
+- Build-time: `VITE_DATA_SOURCE=browser-binance` baked into the bundle.
+- Per page: `?source=browser-binance` in the URL (wins over the build-time
+  value; `?source=runtime` switches a baked bundle back).
+
+The market-data worker then uses `BrowserBinanceTransport`
+(`apps/web/src/workers/browserBinanceTransport.ts`) in place of the socket to
+the runtime. On a selection it fetches the last 900 closed one-minute klines
+from Binance's public mirror (`https://data-api.binance.vision`), sends
+`selection`, `snapshot` (closed bars only, marked `reconstructed` as the
+runtime marks its REST backfill), `health` READY with `reason: "BROWSER_DIRECT"`
+and a `book` placeholder, then opens one mirror stream
+(`wss://data-stream.binance.vision:9443`) for `kline_1m`, `trade` and
+`depth20@100ms` and forwards each event as a `bar`, `trade` or `book` frame.
+Side, `buy_volume` and `trade_count` follow `src/server/frames.js`, so
+indicators see the same data as from the runtime; every frame still passes the
+browser's own frame parser. The status chip reads `LIVE (BROWSER_DIRECT)`.
+
+What it does not have: the L2 engine and heatmap, walls, icebergs, exhaustion,
+initiative, candle monitor, live profiles and VPIN (their requests get the
+contract's unavailable reply, so those indicators show their own "needs the
+runtime" state); history past 900 bars; trades from before the page opened;
+the marker pool; a book deeper than 20 levels. Spot only: perpetual pairs are
+attempted on `fapi`/`fstream` and report
+`BROWSER_DIRECT_PERPETUAL_UNREACHABLE` when the browser cannot reach them;
+dxFeed instruments report `BROWSER_DIRECT_NO_DXFEED`. A dropped stream shows
+`RECOVERING` and reconnects with backoff (`UNAVAILABLE` after five failures),
+filling missed closed bars from REST.
+
+To build a static bundle with the mode baked in and relative asset paths:
+
+```bash
+cd apps/web && VITE_DATA_SOURCE=browser-binance npx vite build --base ./ --outDir ../../dist-browser-direct
+```
+
+Serve `dist-browser-direct/` from any static host or open `index.html` through
+one; nothing else needs to run.

   414	    stream.onmessage = null;
   415	    stream.onclose = null;
   416	    stream.onerror = null;
   417	    try {
   418	      stream.close();

   420	      void 0;

   466	  private klinesUrl(session: Session, query: Record<string, string | number>): string {
   467	    const path = session.selection.provider === "BINANCE" && session.selection.marketKind === "PERPETUAL" ? "/fapi/v1/klines" : "/api/v3/klines";
   468	    const params = new URLSearchParams({ symbol: session.binanceSymbol, interval: "1m" });

   470	    return `${session.restBase}${path}?${params.toString()}`;

   473	  private async fetchKlines(session: Session, query: Record<string, string | number>): Promise<KlineRow[]> {
   474	    const controller = new AbortController();
   475	    session.abort = controller;
   476	    const timer = this.setTimer(() => controller.abort(), REST_TIMEOUT_MS);
   477	    try {
   478	      const response = await this.fetchImpl(this.klinesUrl(session, query), { signal: controller.signal });
   479	      if (!response.ok) throw new Error(`klines: HTTP ${response.status}`);
   480	      const body: unknown = await response.json();
   481	      if (!Array.isArray(body)) throw new Error("klines: body is not an array");
   482	      const rows: KlineRow[] = [];
   483	      for (const raw of body) {
   484	        const row = parseKlineRow(raw);
   485	        if (row !== null) rows.push(row);
   486	      }
   487	      rows.sort((a, b) => a.openTime - b.openTime);
   488	      return rows;
   489	    } finally {
   490	      this.clearTimer(timer);
   491	      if (session.abort === controller) session.abort = null;
   492	    }
   493	  }

   495	  private scheduleRetry(session: Session, action: () => void): void {
   496	    if (!this.isCurrent(session)) return;
   497	    if (session.timer !== null) this.clearTimer(session.timer);
   498	    const delay = session.backoffMs;
   499	    session.backoffMs = Math.min(session.backoffMs * 2, STREAM_BACKOFF_CAP_MS);
   500	    session.timer = this.setTimer(() => {
   501	      session.timer = null;
   502	      if (this.isCurrent(session)) action();
   503	    }, delay);
   504	  }

   506	  private restFailureReason(session: Session): string {
   507	    return session.selection.provider === "BINANCE" && session.selection.marketKind === "PERPETUAL"
   508	      ? HEALTH_REASON_PERPETUAL_UNREACHABLE
   509	      : HEALTH_REASON_REST_FAILED;
   510	  }

   512	  private async bootstrap(session: Session): Promise<void> {
   513	    let rows: KlineRow[];
   514	    try {
   515	      rows = await this.fetchKlines(session, { limit: SNAPSHOT_BARS + 1 });
   516	    } catch (error) {
   517	      if (!this.isCurrent(session)) return;
   518	      console.warn("browserBinanceTransport: kline history request failed", error);
   519	      this.deliverHealth(session, "UNAVAILABLE", this.restFailureReason(session));
   520	      this.scheduleRetry(session, () => void this.bootstrap(session));
   521	      return;
   522	    }
   523	    if (!this.isCurrent(session)) return;
   524	    const now = this.now();
   525	    const closedRows = rows.filter((row) => row.closeTime < now).slice(-SNAPSHOT_BARS);
   526	    const forming = rows.find((row) => row.closeTime >= now && row.openTime <= now);
   527	    const identity = identityFields(session.selection);
   528	    this.deliver({
   529	      type: "snapshot",
   530	      ...identity,
   531	      bars: closedRows.map((row) => barFrame(session.selection, row, true, true)),
   532	      trades: [],
   533	      markers: [],
   534	      vpin_status: "DISABLED",
   535	    });
   536	    if (closedRows.length > 0) session.lastClosedOpen = closedRows[closedRows.length - 1].openTime;
   537	    this.deliverHealth(session, "READY", HEALTH_REASON_READY);
   538	    this.deliver({ type: "book", ...identity, status: "UNAVAILABLE", reason: BOOK_REASON_STREAM_CONNECTING });
   539	    if (forming !== undefined) this.deliver(barFrame(session.selection, forming, false, false));
   540	    session.backoffMs = STREAM_BACKOFF_INITIAL_MS;
   541	    this.openStream(session);
   542	  }

   544	  private streamUrl(session: Session): string {
   545	    const symbol = session.binanceSymbol.toLowerCase();
   546	    return `${session.streamBase}/stream?streams=${symbol}@kline_1m/${symbol}@trade/${symbol}@depth20@100ms`;
   547	  }

   549	  private openStream(session: Session): void {
   550	    if (!this.isCurrent(session)) return;
   551	    let stream: UpstreamSocket;
   552	    try {
   553	      stream = new this.WebSocketImpl(this.streamUrl(session));
   554	    } catch (error) {
   555	      console.warn("browserBinanceTransport: could not construct the stream socket", error);
   556	      this.streamLost(session);
   557	      return;
   558	    }
   559	    session.stream = stream;
   560	    session.connectTimer = this.setTimer(() => {
   561	      session.connectTimer = null;
   562	      if (!this.isCurrent(session) || session.stream !== stream) return;
   563	      console.warn("browserBinanceTransport: the stream did not open in time");
   564	      this.closeStream(session);
   565	      this.streamLost(session);
   566	    }, STREAM_CONNECT_TIMEOUT_MS);
   567	    stream.onopen = () => {
   568	      if (!this.isCurrent(session) || session.stream !== stream) return;
   569	      if (session.connectTimer !== null) {
   570	        this.clearTimer(session.connectTimer);
   571	        session.connectTimer = null;
   572	      }
   573	      session.streamFailures = 0;
   574	      session.backoffMs = STREAM_BACKOFF_INITIAL_MS;
   575	      if (session.degraded) {
   576	        session.degraded = false;
   577	        void this.recoverAfterGap(session);
   578	      }
   579	    };
   580	    stream.onmessage = (event: MessageEvent) => {
   581	      if (!this.isCurrent(session) || session.stream !== stream) return;
   582	      if (typeof event.data !== "string") return;
   583	      let parsed: unknown;
   584	      try {
   585	        parsed = JSON.parse(event.data);
   586	      } catch {
   587	        return;
   588	      }
   589	      this.routeStreamMessage(session, parsed);
   590	    };
   591	    stream.onclose = () => {
   592	      if (!this.isCurrent(session) || session.stream !== stream) return;
   593	      this.closeStream(session);
   594	      this.streamLost(session);
   595	    };
   596	    stream.onerror = () => {
   597	      // The browser follows every error with a close event; that path reports it.
   598	    };
   599	  }
   600	
   601	  private streamLost(session: Session): void {
   602	    if (!this.isCurrent(session)) return;
   603	    session.streamFailures += 1;
   604	    session.degraded = true;
   605	    if (session.streamFailures >= STREAM_FAILURES_BEFORE_UNAVAILABLE) {
   606	      this.deliverHealth(session, "UNAVAILABLE", HEALTH_REASON_STREAM_UNAVAILABLE);
   607	    } else {
   608	      this.deliverHealth(session, "RECOVERING", HEALTH_REASON_STREAM_CLOSED);
   609	    }
   610	    this.scheduleRetry(session, () => this.openStream(session));
   611	  }

   613	  /** After a stream reconnect: closed bars the stream missed come from REST, marked reconstructed as the runtime marks its backfill. */
   614	  private async recoverAfterGap(session: Session): Promise<void> {
   615	    let rows: KlineRow[] = [];
   616	    try {
   617	      rows = await this.fetchKlines(session, session.lastClosedOpen >= 0 ? { startTime: session.lastClosedOpen + BAR_INTERVAL_MS, limit: 1000 } : { limit: SNAPSHOT_BARS + 1 });
   618	    } catch (error) {
   619	      console.warn("browserBinanceTransport: kline gap fill failed", error);
   620	    }
   621	    if (!this.isCurrent(session)) return;
   622	    const now = this.now();
   623	    for (const row of rows) {
   624	      if (row.closeTime < now && row.openTime > session.lastClosedOpen) {
   625	        this.deliver(barFrame(session.selection, row, true, true));
   626	        session.lastClosedOpen = row.openTime;
   627	      }
   628	    }
   629	    this.deliverHealth(session, "READY", HEALTH_REASON_READY);
   630	  }
   631	
   632	  private routeStreamMessage(session: Session, parsed: unknown): void {
   633	    if (!isRecord(parsed)) return;
   634	    const payload = isRecord(parsed.data) && typeof parsed.stream === "string" ? parsed.data : parsed;
   635	    if (payload.e === "kline") {
   636	      const bar = parseKlineEvent(payload.k);
   637	      if (bar === null) return;
   638	      if (bar.closed && bar.openTime <= session.lastClosedOpen) return;
   639	      this.deliver(barFrame(session.selection, bar, bar.closed, false));
   640	      if (bar.closed) session.lastClosedOpen = bar.openTime;
   641	      return;
   642	    }
   643	    if (payload.e === "trade") {
   644	      const price = finiteNumber(payload.p);
   645	      const size = finiteNumber(payload.q);
   646	      if (price === undefined || size === undefined || price <= 0 || size <= 0) return;
   647	      if (!Number.isSafeInteger(payload.T) || !Number.isSafeInteger(payload.t) || typeof payload.m !== "boolean") return;
   648	      this.deliver({
   649	        type: "trade",
   650	        ...identityFields(session.selection),
   651	        ts_exchange: payload.T,
   652	        price,
   653	        size,
   654	        side: payload.m ? "sell" : "buy",
   655	        trade_id: String(payload.t),
   656	      });
   657	      return;
   658	    }
   659	    const isSpotPartial = Array.isArray(payload.bids) && Array.isArray(payload.asks) && Number.isSafeInteger(payload.lastUpdateId);
   660	    const isFuturesPartial = payload.e === "depthUpdate" && Array.isArray(payload.b) && Array.isArray(payload.a) && Number.isSafeInteger(payload.u);
   661	    if (!isSpotPartial && !isFuturesPartial) return;
   662	    const bids = bookLevels(isSpotPartial ? payload.bids : payload.b);
   663	    const asks = bookLevels(isSpotPartial ? payload.asks : payload.a);
   664	    if (bids === null || asks === null) return;
   665	    if (bids.length > 0 && asks.length > 0 && bids[0].price >= asks[0].price) return;
   666	    this.deliver({
   667	      type: "book",
   668	      ...identityFields(session.selection),
   669	      status: "READY",
   670	      bids: bids.slice(0, 20),
   671	      asks: asks.slice(0, 20),
   672	      lastUpdateId: (isSpotPartial ? payload.lastUpdateId : payload.u) as number,
   673	      stale: false,
   674	    });
   675	  }
