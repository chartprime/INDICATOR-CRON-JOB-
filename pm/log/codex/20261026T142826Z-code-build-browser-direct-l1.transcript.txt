# Build brief: L1 parity for browser-direct Binance (`build/browser-direct-l1`)

2026-10-26. Browser-direct mode had no frame the runtime *derives* from the
tape (`marker`, the aggressive pool, `aggressive_history`, `marker_history`), so
Large Trade Detector drew its legend and no bubbles. This build computes them in
the worker with the runtime's own algorithms, proven equal by parity tests that
`require` the runtime's CommonJS modules on the same 10,000 recorded trades.

## 1. What the runtime derives from trades, and who reads it

There is no "baseline" for Binance markers (`baseline_log_*` are dxFeed storage
columns). `history.js` retains, per minute and side, the four prints of largest
**USD notional** (`large-trade-detection.js`), ties by time then id, 100,000 at
most, seven days deep; a `marker` follows the `trade` when `recordMarker` admits
it; the snapshot carries the newest 5,000; `marker_history` (opt-in) the full
set, 5,000 rows a frame. The pool (`aggressive-pool.js`) keeps prints at or above
a floor (98th percentile of the last 4,096 sizes once 200 are seen, never
falling), 4 hours, 20,000 at most, on the snapshot as `aggressive_prints*`;
`aggressive_history` answers a window from storage, 10,000 a page.

## 2. Shared algorithm: approach (a)

The runtime modules are CommonJS and the Vite build cannot import
`apps/runtime`. Pure TypeScript mirrors live in `apps/web/src/lib/tape/`:
`largeTradeDetection.ts` (line for line with `large-trade-detection.js`) and
`aggressivePool.ts` (`createAggressivePool`, `print-floor.js`, `floorAbove`).
Marker retention reuses `lib/chart/markerRetention.ts`, already the browser
mirror of `history.js`'s time-covered path. `workers/tests/tapeParity.test.ts`
`require`s the runtime files (vitest runs in Node) and asserts identical
output: every helper result, every per-trade admit decision and the final
marker set, and the pool's prints, floor and `from` after every step, on
10,000 recorded BTC-USDT aggregate trades. Runtime code is not touched.

## 3. Markers

Every live `trade` goes through the marker buffer; an admitted print goes out
as a `marker` right after its `trade`. Bootstrap: after the first snapshot,
alongside the stream, the worker pages `GET /api/v3/aggTrades?limit=1000` from
the mirror, newest first by `fromId`, at most 30 pages (weight 4 each, 120 of
the 6,000 per minute budget; the kline fill's bounded-page discipline, one 10 s
timeout per page), stopping at a short page or seven days. Rows are aggregate trades: id `a<aggTradeId>` (a separate id space
from the stream's `t`), size the summed fills of one taker order at one price,
so a bootstrap marker can be larger than any single print the runtime saw;
rows at or after the first live trade are dropped so nothing is counted twice;
the seconds between the first page and the stream opening are a hole, like the
runtime's connect seam. Then the `snapshot` is re-broadcast (closed bars, last
100 live trades, newest 5,000 markers, the pool), as the runtime does after a
warm-up chunk, and the forming bar re-sent. The runtime's baseline is seven days
of storage; the browser's is what 30 pages cover (about twenty minutes on
BTC-USDT, hours on a quiet pair). The Large Trade Detector's `top N%` target counts the
snapshot bars' `trade_count` (15 hours), so with a short bootstrap the
selection is `truncated`; the legend now appends ` · partial` and the settings
modal already explains it.

## 4. Aggressive pool and `aggressive_history`

The pool is the runtime's: live trades `record`; bootstrap pages `seed`, the
newest 15 minutes with `calibrate: true`, older rows at the floor; `from` never
precedes the oldest row actually read. The snapshot carries the three
`aggressive_prints*` fields, so `coverageOf` reads "thin" over the bootstrap and
"all" from connect. `aggressive_history` is answered from the pool: `complete: true`
when `from_ts >= from` and `min_size >= floor`, trades in time order, 10,000 a
page with `CAP_REACHED` and a base64url cursor (`{ts, id}` bound to the
request); otherwise `complete: false`, `reason: "STORAGE_UNAVAILABLE"`,
`trades: []`, which the client retries three times and then rests, as today.

## 5. `marker_history`

The transport remembers the `capabilities` flag (the worker always sends it);
when the bootstrap completes, and on a later opt-in, it sends the full marker
set as `marker_history` frames, `reset` on the first, 5,000 rows each.

## 6. Degraded states

A failed first page is retried with the stream's backoff; after three failures
the READY health frame carries `reason: "BROWSER_DIRECT_NO_TAPE_HISTORY"` (the
chip shows `LIVE (BROWSER_DIRECT_NO_TAPE_HISTORY)`), markers and the pool start
at connect, and retries continue (a later success publishes the snapshot and
restores `BROWSER_DIRECT`). A failure after some pages keeps what was read,
with `from` honest.

+export interface PoolPrint {
+  readonly ts_exchange: number;
+  readonly size: number;
+  readonly trade_id: string;

+export interface PrintFloor {
+  push(size: number): void;
+  value(): number;

+export interface PoolSnapshot<T extends PoolPrint> {

+export interface AggressivePool<T extends PoolPrint> {
+  record(trade: T): boolean;
+  seed(trades: readonly T[], options?: { fromMs?: number; calibrate?: boolean }): number;

+export const DEFAULT_WINDOW_MS = 4 * 60 * 60 * 1000;
+export const DEFAULT_MAX_PRINTS = 20_000;
+export const DEFAULT_FLOOR_SHARE = 0.02;
+export const DEFAULT_FLOOR_WINDOW = 4_096;
+export const DEFAULT_FLOOR_MIN_SAMPLES = 200;
+export const DEFAULT_CALIBRATION_MS = 15 * 60 * 1000;

+export function floorAbove(size: number): number {
+  return size + Number.EPSILON * Math.max(1, size);
+}

+export function createPrintFloor({ window, share, minSamples }: { window: number; share: number; minSamples: number }): PrintFloor {
+  if (!Number.isSafeInteger(window) || window <= 0) throw new Error("print-floor: window must be a positive safe integer");
+  if (!(share > 0 && share < 1)) throw new Error("print-floor: share must be in (0, 1)");
+  if (!Number.isSafeInteger(minSamples) || minSamples <= 0) throw new Error("print-floor: minSamples must be a positive safe integer");
+
+  const arrivals = new Float64Array(window);
+  const sorted = new Float64Array(window);
+  let next = 0;
+  let filled = 0;
+
+  function firstAbove(size: number): number {
+    let lo = 0;
+    let hi = filled;
+    while (lo < hi) {
+      const mid = (lo + hi) >>> 1;
+      if (sorted[mid] <= size) lo = mid + 1;
+      else hi = mid;
+    }
+    return lo;
+  }
+
+  function remove(size: number): void {
+    const at = firstAbove(size) - 1;
+    sorted.copyWithin(at, at + 1, filled);
+    filled -= 1;
+  }
+
+  function insert(size: number): void {
+    const at = firstAbove(size);
+    sorted.copyWithin(at + 1, at, filled);
+    sorted[at] = size;
+    filled += 1;
+  }
+
+  function push(size: number): void {
+    if (filled === window) remove(arrivals[next]);
+    arrivals[next] = size;
+    next = (next + 1) % window;
+    insert(size);
+  }
+
+  function value(): number {
+    if (filled < minSamples) return 0;
+    const index = Math.min(filled - 1, Math.max(0, Math.ceil(filled * (1 - share)) - 1));
+    return sorted[index];
+  }
+
+  return Object.freeze({ push, value });
+}

+function assertPositiveInteger(value: number, field: string): void {
+  if (!Number.isSafeInteger(value) || value <= 0) throw new Error(`aggressive-pool: ${field} must be a positive safe integer`);
+}

+export function createAggressivePool<T extends PoolPrint>({
+  windowMs = DEFAULT_WINDOW_MS,
+  maxPrints = DEFAULT_MAX_PRINTS,
+  floorShare = DEFAULT_FLOOR_SHARE,
+  floorWindow = DEFAULT_FLOOR_WINDOW,
+  floorMinSamples = DEFAULT_FLOOR_MIN_SAMPLES,
+  now = () => Date.now(),
+}: {
+  windowMs?: number;
+  maxPrints?: number;
+  floorShare?: number;
+  floorWindow?: number;
+  floorMinSamples?: number;
+  now?: () => number;
+} = {}): AggressivePool<T> {
+  assertPositiveInteger(windowMs, "windowMs");
+  assertPositiveInteger(maxPrints, "maxPrints");
+  assertPositiveInteger(floorWindow, "floorWindow");
+  assertPositiveInteger(floorMinSamples, "floorMinSamples");
+  if (!(floorShare > 0 && floorShare < 1)) throw new Error("aggressive-pool: floorShare must be in (0, 1)");
+
+  const printFloor = createPrintFloor({ window: floorWindow, share: floorShare, minSamples: floorMinSamples });
+  let prints: T[] = [];
+  const ids = new Set<string>();
+  let coverageFloor = 0;
+  let from: number | null = null;
+
+  function gate(): number {
+    return printFloor.value();
+  }
+
+  function insert(trade: T): boolean {
+    if (ids.has(trade.trade_id)) return false;
+    ids.add(trade.trade_id);
+    const last = prints[prints.length - 1];
+    if (!last || last.ts_exchange <= trade.ts_exchange) {
+      prints.push(trade);
+      return true;
+    }
+    let lo = 0;
+    let hi = prints.length;
+    while (lo < hi) {
+      const mid = (lo + hi) >>> 1;
+      if (prints[mid].ts_exchange <= trade.ts_exchange) lo = mid + 1;
+      else hi = mid;
+    }
+    prints.splice(lo, 0, trade);
+    return true;
+  }
+
+  function trimWindow(at: number): void {
+    const cutoff = at - windowMs;
+    let drop = 0;
+    while (drop < prints.length && prints[drop].ts_exchange < cutoff) drop += 1;
+    if (drop > 0) for (const gone of prints.splice(0, drop)) ids.delete(gone.trade_id);
+    if (from === null || from < cutoff) from = cutoff;
+  }
+
+  function trimCount(): void {
+    if (prints.length <= maxPrints) return;
+    const bySize = prints.map((print) => print.size).sort((a, b) => a - b);
+    let threshold = bySize[prints.length - maxPrints];
+    let atOrAbove = 0;
+    for (const size of bySize) if (size >= threshold) atOrAbove += 1;
+    if (atOrAbove > maxPrints) {
+      const above = bySize.find((size) => size > threshold);
+      if (above === undefined) {
+        for (const gone of prints) ids.delete(gone.trade_id);
+        prints = [];
+        coverageFloor = Math.max(coverageFloor, floorAbove(threshold));
+        return;
+      }
+      threshold = above;
+    }
+    const kept: T[] = [];
+    for (const print of prints) {
+      if (print.size < threshold) ids.delete(print.trade_id);
+      else kept.push(print);
+    }
+    prints = kept;
+    if (threshold > coverageFloor) coverageFloor = threshold;
+  }
+
+  function record(trade: T): boolean {
+    if (!(trade.size > 0)) return false;
+    printFloor.push(trade.size);
+    const floor = gate();
+    if (floor > coverageFloor) coverageFloor = floor;
+    if (trade.size < Math.max(floor, coverageFloor)) return false;
+    if (!insert(trade)) return false;
+    trimWindow(now());
+    trimCount();
+    return true;
+  }
+
+  function mergeInsertAll(candidates: T[]): number {
+    if (candidates.length === 0) return 0;
+    const ordered = candidates.length === 1 ? candidates : [...candidates].sort((a, b) => a.ts_exchange - b.ts_exchange);
+    const merged: T[] = [];
+    let i = 0;
+    let j = 0;
+    while (i < prints.length && j < ordered.length) {
+      if (prints[i].ts_exchange <= ordered[j].ts_exchange) merged.push(prints[i++]);
+      else merged.push(ordered[j++]);
+    }
+    while (i < prints.length) merged.push(prints[i++]);
+    while (j < ordered.length) merged.push(ordered[j++]);
+    for (const trade of ordered) ids.add(trade.trade_id);
+    prints = merged;
+    return ordered.length;
+  }
+
+  function seed(trades: readonly T[], { fromMs, calibrate = false }: { fromMs?: number; calibrate?: boolean } = {}): number {
+    const admit = calibrate ? 0 : Math.max(coverageFloor, gate());
+    const candidates: T[] = [];
+    const seenInBatch = new Set<string>();
+    for (const trade of trades) {
+      if (!(trade.size > 0) || trade.size < admit) continue;
+      if (calibrate) printFloor.push(trade.size);
+      if (ids.has(trade.trade_id) || seenInBatch.has(trade.trade_id)) continue;
+      seenInBatch.add(trade.trade_id);
+      candidates.push(trade);
+    }
+    const taken = mergeInsertAll(candidates);
+    if (calibrate) {
+      const floor = gate();
+      if (floor > coverageFloor) coverageFloor = floor;
+      if (floor > 0) {
+        const survivors = prints.filter((print) => print.size >= floor);
+        if (survivors.length !== prints.length) {
+          for (const print of prints) if (print.size < floor) ids.delete(print.trade_id);
+          prints = survivors;
+        }
+      }
+    }
+    if (fromMs !== undefined && Number.isFinite(fromMs) && (from === null || fromMs < from)) from = fromMs;
+    trimWindow(now());
+    trimCount();
+    return taken;
+  }
+
+  function boundedForWire(): { prints: T[]; floor: number } {
+    const floor = Math.max(coverageFloor, gate());
+    if (prints.length <= maxPrints) return { prints: prints.slice(), floor };
+    const bySize = prints.slice().sort((a, b) => b.size - a.size);
+    let kept = 0;
+    while (kept < bySize.length) {
+      let end = kept;
+      while (end < bySize.length && bySize[end].size === bySize[kept].size) end += 1;
+      if (end > maxPrints) break;
+      kept = end;
+    }
+    if (kept === 0) {
+      return { prints: [], floor: Math.max(floor, floorAbove(bySize[0].size)) };
+    }
+    const keptIds = new Set(bySize.slice(0, kept).map((print) => print.trade_id));
+    return { prints: prints.filter((print) => keptIds.has(print.trade_id)), floor: Math.max(floor, bySize[kept - 1].size) };
+  }
+
+  function snapshot(): PoolSnapshot<T> {
+    trimWindow(now());
+    const bounded = boundedForWire();
+    return Object.freeze({ prints: Object.freeze(bounded.prints), floor: bounded.floor, from: from ?? now() });
+  }
+
+  return Object.freeze({
+    record,
+    seed,
+    snapshot,
+    gate,
+    get size() {
+      return prints.length;
+    },
+    get floor() {
+      return Math.max(coverageFloor, gate());
+    },
+  });
+}

+export interface RankedPrint {

+export interface TopFractionCount {
+  readonly target: number;
+  readonly shown: number;
+  readonly truncated: boolean;
+  readonly effectiveFraction: number;

+export function usesContractMagnitude(provider: string, assetClass: string | undefined): boolean {
+  return provider === CONTRACT_MAGNITUDE_PROVIDER && assetClass === CONTRACT_MAGNITUDE_ASSET_CLASS;

+export function tradeMagnitude(provider: string, assetClass: string | undefined, price: number, size: number): number {
+  return usesContractMagnitude(provider, assetClass) ? size : price * size;
+}

+export function markerMagnitude(markerFrame: RankedPrint): number {
+  return tradeMagnitude(markerFrame.provider, markerFrame.assetClass, markerFrame.price, markerFrame.size);

+export function lowerMagnitudePriority(candidate: RankedPrint, incumbent: RankedPrint): boolean {
+  const candidateMagnitude = markerMagnitude(candidate);
+  const incumbentMagnitude = markerMagnitude(incumbent);
+  if (candidateMagnitude !== incumbentMagnitude) return candidateMagnitude < incumbentMagnitude;
+  if (candidate.ts_exchange !== incumbent.ts_exchange) return candidate.ts_exchange < incumbent.ts_exchange;
+  return candidate.trade_id < incumbent.trade_id;
+}

+export function resolveTopFractionCount(totalTradeCount: number, fraction: number, availableMarkerCount: number): TopFractionCount {
+  if (!Number.isSafeInteger(totalTradeCount) || totalTradeCount < 0) {
+    throw new Error("large-trade-detection: totalTradeCount must be a non-negative safe integer");
+  }
+  if (!Number.isFinite(fraction) || fraction <= 0 || fraction > 1) {
+    throw new Error("large-trade-detection: fraction must be a finite number in (0, 1]");
+  }
+  if (!Number.isSafeInteger(availableMarkerCount) || availableMarkerCount < 0) {
+    throw new Error("large-trade-detection: availableMarkerCount must be a non-negative safe integer");
+  }
+  const target = totalTradeCount === 0 ? 0 : Math.max(1, Math.ceil(totalTradeCount * fraction));
+  const shown = Math.min(target, availableMarkerCount);
+  return Object.freeze({
+    target,
+    shown,
+    truncated: shown < target,
+    effectiveFraction: totalTradeCount === 0 ? 0 : shown / totalTradeCount,

+    } finally {
+      this.clearTimer(timer);

+    session.tape.started = true;

+  /**
+   * The runtime seeds markers and the pool from storage; the browser reads
+   * recent aggregate trades from the mirror, newest page first by id, within a
+   * bounded page budget, and feeds them through the same retention and pool.
+   * Rows at or after the first live trade are the stream's and are skipped.
+   * A page that fails after others succeeded ends the walk with what was
+   * read; a first page that fails is retried with backoff, and after three
+   * such failures the READY health frame says the tape history is missing.
+   */
+  private async bootstrapTape(session: Session): Promise<void> {
+    const tape = session.tape;
+    tape.inFlight = true;
+    const nowMs = this.now();
+    const oldestWanted = nowMs - MARKER_HISTORY_WINDOW_MS;
+    const calibrationFrom = nowMs - DEFAULT_CALIBRATION_MS;
+    let fromId: number | null = null;
+    let pages = 0;
+    let rowsRead = 0;
+    try {
+      while (pages < MAX_TAPE_BOOTSTRAP_PAGES) {
+        let rows: AggTradeRow[];
+        try {
+          rows = await this.fetchAggTrades(session, fromId);
+        } catch (error) {
+          if (!this.isCurrent(session)) return;
+          if (pages === 0) throw error;
+          console.warn("browserBinanceTransport: a trade history page failed; keeping what was read", error);
+          break;
+        }
+        if (!this.isCurrent(session)) return;
+        pages += 1;
+        if (rows.length === 0) break;
+        rowsRead += this.seedTape(session, rows, calibrationFrom);
+        const oldest = rows[0];
+        if (rows.length < TAPE_BOOTSTRAP_PAGE || oldest.a === 0 || oldest.T < oldestWanted) break;
+        fromId = Math.max(0, oldest.a - TAPE_BOOTSTRAP_PAGE);
+      }
+    } catch (error) {
+      if (!this.isCurrent(session)) return;
+      tape.inFlight = false;
+      tape.attempts += 1;
+      console.warn("browserBinanceTransport: trade history request failed", error);
+      if (tape.attempts >= TAPE_BOOTSTRAP_FAILURES_BEFORE_DEGRADED && !tape.unavailable) {
+        tape.unavailable = true;
+        if (!session.degraded && !session.recovering) this.deliverHealth(session, "READY", this.readyReason(session));
+      }
+      this.scheduleTapeRetry(session);
+      return;
+    }
+    tape.inFlight = false;
+    tape.done = true;
+    const wasUnavailable = tape.unavailable;
+    tape.unavailable = false;
+    if (rowsRead > 0) this.publishTapeState(session);
+    if (wasUnavailable && !session.degraded && !session.recovering) this.deliverHealth(session, "READY", HEALTH_REASON_READY);
+  }
+
+  private scheduleTapeRetry(session: Session): void {
+    if (!this.isCurrent(session)) return;
+    const tape = session.tape;
+    if (tape.timer !== null) this.clearTimer(tape.timer);
+    const delay = tape.backoffMs;
+    tape.backoffMs = Math.min(tape.backoffMs * 2, STREAM_BACKOFF_CAP_MS);
+    tape.timer = this.setTimer(() => {
+      tape.timer = null;
+      if (this.isCurrent(session)) void this.bootstrapTape(session);
+    }, delay);
+  }
+
+  /**
+   * One page into the retention and the pool, as the runtime's warm-up seeds
+   * a storage chunk: the newest fifteen minutes calibrate the floor
+   * (`calibrate: true`, every size counted), older rows are admitted at the
+   * floor; `fromMs` is the oldest row of the page, never further back.
+   * Returns the rows kept.
+   */
+  private seedTape(session: Session, rows: readonly AggTradeRow[], calibrationFrom: number): number {
+    const cutoff = session.firstLiveTradeTs;
+    const calibration: TradeFrame[] = [];
+    const older: TradeFrame[] = [];
+    let oldestTs = Infinity;
+    for (const row of rows) {
+      if (cutoff !== null && row.T >= cutoff) continue;
+      const trade = aggTradeFrame(session.selection, row);
+      if (row.T < oldestTs) oldestTs = row.T;
+      (row.T >= calibrationFrom ? calibration : older).push(trade);
+      this.offerMarker(session, trade, false);
+    }
+    if (oldestTs === Infinity) return 0;
+    if (calibration.length > 0) session.pool.seed(calibration, { fromMs: oldestTs, calibrate: true });
+    if (older.length > 0) session.pool.seed(older, { fromMs: oldestTs });
+    if (session.tapeCoveredFrom === null || oldestTs < session.tapeCoveredFrom) session.tapeCoveredFrom = oldestTs;
+    return calibration.length + older.length;
+  }

type Harness = {
  transport: BrowserBinanceTransport;
  frames: Record<string, unknown>[];
  parsed: () => ServerFrame[];
  aggTradesMock: ReturnType<typeof vi.fn>;
  stream: () => FakeUpstreamSocket;

function jsonResponse(body: unknown, status = 200): Response {
  return new Response(JSON.stringify(body), { status, headers: { "content-type": "application/json" } });
}

function harness(aggTrades: (url: string) => Promise<Response> = async (url) => jsonResponse(recordedPage(url)), now: () => number = () => NOW_MS): Harness {
  FakeUpstreamSocket.instances = [];
  const aggTradesMock = vi.fn(aggTrades);
  const transport = new BrowserBinanceTransport("ws://127.0.0.1:8000/ws", {
    fetch: ((url: string) => (url.includes("/aggTrades") ? aggTradesMock(url) : Promise.resolve(jsonResponse(klines)))) as unknown as typeof fetch,
    WebSocket: FakeUpstreamSocket,
    now,
  });
  const frames: Record<string, unknown>[] = [];
  transport.onmessage = (event) => {
    frames.push(JSON.parse(event.data as string) as Record<string, unknown>);
  };
  return {
    transport,
    frames,
    parsed: () => frames.map((frame) => {
      const parsed = parseServerFrame(frame, { nowMs: now() });
      if (parsed === null) throw new Error(`frame rejected by parseServerFrame: ${JSON.stringify(frame).slice(0, 400)}`);
      return parsed;
    }),
    aggTradesMock,
    stream: () => FakeUpstreamSocket.instances.at(-1)!,
  };
}

async function openAndSelect(h: Harness, { markerHistory = true } = {}): Promise<void> {
  h.transport.onopen = () => {
    if (markerHistory) h.transport.send(JSON.stringify({ type: "capabilities", marker_history: true }));
    h.transport.send(JSON.stringify(SPOT));
  };
  await vi.advanceTimersByTimeAsync(0);
  expect(h.transport.readyState).toBe(1);
}

/** Lets the sequential REST pages of the bootstrap resolve (each page is a few promise hops). */
async function settle(): Promise<void> {
  for (let i = 0; i < 200; i += 1) await vi.advanceTimersByTimeAsync(0);
}

function liveTrade(id: number, ts: number, size: string, sell: boolean, price = "79530.00") {
  return { stream: "btcusdt@trade", data: { e: "trade", E: ts + 5, s: "BTCUSDT", t: id, p: price, q: size, T: ts, m: sell, M: true } };
}

function runtimeMarkers(trades: readonly TradeFrame[]): MarkerFrame[] {
  const buffer = createHistoryBuffer({ markerBucketMs: MARKER_BUCKET_MS, maxMarkersPerBucketSide: MARKERS_PER_BUCKET_SIDE });
  for (const trade of trades) buffer.recordMarker({ ...trade, type: "marker" });
  return buffer.snapshotMarkers();
}
