# Build brief: L1 parity for browser-direct Binance (`build/browser-direct-l1`)

2026-10-26. Browser-direct mode had no frame the runtime *derives* from the
tape (`marker`, the aggressive pool, `aggressive_history`, `marker_history`), so
Large Trade Detector drew its legend and no bubbles. This build computes them in
the worker with the runtime's own algorithms, proven equal by parity tests that
`require` the runtime's CommonJS modules on the same 10,000 recorded trades.

## 1. What the runtime derives from trades, and who reads it

There is no "baseline" for Binance markers (`baseline_log_*` are dxFeed storage
columns). `history.js` retains, per minute and side, the four prints of largest
**USD notional**, ties by time then id, 100,000 at most, seven days; a `marker`
follows the admitted `trade`; the snapshot carries the newest 5,000;
`marker_history` (opt-in) the full set, 5,000 rows a frame. The pool keeps
prints at or above a floor (98th percentile of the last 4,096 sizes once 200
are seen, never falling), 4 hours, 20,000 at most, on the snapshot as
`aggressive_prints*`; `aggressive_history` answers from storage, 10,000 a page.

|---|---|---|---|
| Aggressive Order Flow, Delta Divergence, CVD Divergence, Market Structure Delta, FVG Delta, FVG Boxes, L1 Order Blocks, Volume Profile OHLC | bars via `barSides` | works | nothing |

## 2. Shared algorithm: approach (a)

The runtime modules are CommonJS and the Vite build cannot import
`apps/runtime`. Pure TypeScript mirrors live in `apps/web/src/lib/tape/`:
`largeTradeDetection.ts` (line for line with `large-trade-detection.js`) and
`aggressivePool.ts` (`createAggressivePool`, `print-floor.js`, `floorAbove`).
Marker retention reuses `lib/chart/markerRetention.ts`, already the browser
mirror of `history.js`'s time-covered path. `workers/tests/tapeParity.test.ts`
`require`s the runtime files (vitest runs in Node) and asserts identical
output on 10,000 recorded BTC-USDT aggregate trades: every helper result,
every admit decision, the marker set, the pool's prints, floor and `from`.
Runtime code is not touched.

## 3. Markers

Every live `trade` goes through the marker buffer; an admitted print goes out
as a `marker` right after it. Bootstrap: after the first snapshot, alongside
the stream, the worker pages `GET /api/v3/aggTrades?limit=1000` from the
mirror, newest first by `fromId`, at most 30 pages (weight 4 each, 120 of the
6,000 per minute budget, one 10 s timeout per page), stopping at a short page
or seven days. Rows are aggregate trades: id `a<aggTradeId>` (a separate id space
from the stream's `t`), size the summed fills of one taker order at one price,
so a bootstrap marker can be larger than any single print the runtime saw.
Then the `snapshot` is re-broadcast (closed bars, last 100 live trades, newest
5,000 markers, the pool), as the runtime does after a warm-up chunk, and the
forming bar re-sent. The runtime's baseline is seven days of storage; the
browser's is what 30 pages cover (about twenty minutes on BTC-USDT, hours on
a quiet pair). The detector's `top N%` target counts the snapshot bars' `trade_count`
(15 hours), so a short bootstrap leaves the selection `truncated`; the legend
appends ` · partial`.

## 4. Aggressive pool and `aggressive_history`

The pool is the runtime's: live trades `record`; bootstrap pages are staged
until the stream's first trade is known (or a 2 s grace), reconciled against
every live span by fill id (`f`/`l`), then `seed`, the newest 15 minutes with
`calibrate: true`, older rows at the floor. Coverage is explicit: the
transport keeps every stretch of tape observed in full (validated
id-contiguous pages, each stream span first-to-last trade, ids at the ends)
and claims only inside one, minus milliseconds whose aggregates straddle a
span boundary; the REST-to-stream seam and reconnect holes are filled from
`aggTrades` (by id after a REST row, else `startTime`, 10 pages, three tries)
or stay holes; the bookkeeping is pruned to the pool's 4 h and bounded. A
stream lost after trades closes the transport, as a lost runtime socket
would: the worker reports `closed` (the tick store ends its live stretch,
`AggressiveTape.endLive`) and reconnects to a new instance that keeps the
pair's tape state. `aggressive_prints_from` is the start of the stretch
reaching now, or now itself (no claim) while no stream delivers. A page with
a malformed row is a failed read, never a shorter page. `aggressive_history` is answered from the pool: `complete: true`
when the window lies inside one observed stretch and `min_size >= floor`,
trades in time order, 10,000 a page with `CAP_REACHED` and a base64url cursor (`{ts, id}` bound to the
request); otherwise `complete: false`, `reason: "STORAGE_UNAVAILABLE"`,
`trades: []`, which the client retries three times and then rests, as today.

## 5. `marker_history`

With the `capabilities` flag set (the worker always sends it), the bootstrap's
completion, a later opt-in and a connect with kept state each send the full
marker set as `marker_history` frames, `reset` on the first, 5,000 rows each.

## 6. Degraded states

A failed first page is retried with the stream's backoff; after three failures
the READY health frame carries `reason: "BROWSER_DIRECT_NO_TAPE_HISTORY"`,
markers and the pool start at connect, retries continue (a later success
publishes the snapshot and restores `BROWSER_DIRECT`). A failure after some
pages keeps the pages validated before it.

## 7. Unavailable, with reason

`delta_profile`: `STORAGE_UNAVAILABLE` (needs every trade; the pool is floor
filtered). VPIN: `vpin_status: "DISABLED"`.

  private commitStaged(session: Session): void {

    const staged = tape.staged;

    let endAggId: number | undefined;
    for (const page of staged) {
      kept += this.seedTape(session, page);
      for (const row of page) {
        if (row.T < from) from = row.T;

      }

    // sits in the page never read: that millisecond is claimed only when the
    // walk reached the exchange's first aggregate trade.

  /**
   * Whether a REST row is tape the stream already delivered. Inside a live
   * span (open or closed) it is; at a span's first or last millisecond the
   * aggregate's fill ids decide: wholly before the first live trade or wholly
   * after the last one it is missing tape and is kept, wholly within it is
   * dropped, and an aggregate straddling the boundary cannot be told apart,
   * so it is dropped and that millisecond is marked unverified: no coverage
   * claim includes it.
   */
  private admitRestRow(session: Session, row: AggTradeRow): boolean {
    const spans: readonly LiveSpan[] = session.live === null
      ? session.liveSpans
      : [...session.liveSpans, { from: session.live.from, to: Infinity, firstId: session.live.firstId, lastId: Infinity }];
    for (const span of spans) {
      if (row.T > span.from && row.T < span.to) return false;
      if (row.T !== span.from && row.T !== span.to) continue;
      // At a boundary millisecond, the fill ids place the aggregate: wholly
      // before the span's first trade (only at its first millisecond) or
      // wholly after its last (only at its last) is missing tape; wholly
      // between the two is the stream's; anything else straddles. A span of
      // one millisecond is both boundaries at once.
      const before = row.T === span.from && row.l < span.firstId;
      const after = row.T === span.to && row.f > span.lastId;
      if (before || after) continue;
      const within = row.f >= span.firstId && row.l <= span.lastId;
      if (within) return false;
      this.markUnverified(session, row.T);
      return false;
    }
    return true;
  }

  private markUnverified(session: Session, ms: number): void {
    if (!session.unverified.includes(ms)) session.unverified.push(ms);
  }

  /**
   * One validated page into the retention and the pool, as the runtime's
   * warm-up seeds a storage chunk: rows from the calibration window (the
   * newest fifteen minutes at the bootstrap's start) calibrate the floor
   * (`calibrate: true`, every size counted), older rows are admitted at the
   * floor; rows the stream already delivered are left out. Returns the rows kept.
   */
  private seedTape(session: Session, rows: readonly AggTradeRow[]): number {
    const calibration: TradeFrame[] = [];
    const older: TradeFrame[] = [];
    let oldestTs = Infinity;
    for (const row of rows) {
      if (!this.admitRestRow(session, row)) continue;
      const trade = aggTradeFrame(session.selection, row);
      if (row.T < oldestTs) oldestTs = row.T;
      (row.T >= session.calibrationFrom ? calibration : older).push(trade);
      this.offerMarker(session, trade, false);
    }
    if (oldestTs === Infinity) return 0;
    if (calibration.length > 0) session.pool.seed(calibration, { fromMs: oldestTs, calibrate: true });
    if (older.length > 0) session.pool.seed(older, { fromMs: oldestTs });
    return calibration.length + older.length;
  }

  /** The newest hole between two observed stretches (the open stream span counts) that is neither given up on nor made only of unverified milliseconds. */
  private nextSeamGap(session: Session): TapeInterval | null {
    const intervals = this.coverageIntervals(session);
    for (let i = intervals.length - 1; i >= 1; i -= 1) {
      const gap: TapeInterval = { from: intervals[i - 1].to, to: intervals[i].from, endAggId: intervals[i - 1].endAggId, endTradeId: intervals[i - 1].endTradeId };
      if (session.unfillable.some((open) => open.from === gap.from && open.to === gap.to)) continue;
      const interior = gap.to - gap.from - 1;
      const unverifiedInside = session.unverified.filter((ms) => ms > gap.from && ms < gap.to).length;
      if (interior <= unverifiedInside) continue;
      return gap;
    }
    return null;
  }

  /**
   * Closes the holes the tape has: between the bootstrap's newest row and the
   * stream's first trade, or between one stream's last trade and the next
   * stream's first. Kline recovery repairs bars, not trades, so the prints of
   * such a hole are read from REST within a bounded budget: by id from the
   * row after the last REST row when the hole follows one, else by time from
   * the hole's first millisecond, every row reconciled against the live tape
   * by fill id. A hole that cannot be closed stays a hole and is never inside
   * a completeness claim. One fill runs at a time; when nothing is left to
   * fill and a snapshot is waiting, it goes out.
   */
  private fillNextSeam(session: Session): void {
    if (!this.isCurrent(session) || session.seam.inFlight || session.seam.timer !== null) return;
    const gap = this.nextSeamGap(session);
    if (gap === null) {
      if (session.seam.publishWhenSettled) this.publishTapeState(session);
      return;
    }
    void this.fillSeam(session, gap);
  }

  private async fillSeam(session: Session, gap: TapeInterval): Promise<void> {
    const seam = session.seam;
    seam.inFlight = true;
    seam.gap = gap;
    let closed = false;
    let endAggId = gap.endAggId;
    try {
      let fromId: number | null = gap.endAggId === undefined ? null : gap.endAggId + 1;
      for (let pages = 0; pages < MAX_SEAM_FILL_PAGES; pages += 1) {
        const rows = await this.fetchAggTrades(session, fromId === null ? { startTime: gap.from } : { fromId }, seam);
        if (!this.isCurrent(session)) return;
        const inside = rows.filter((row) => row.T <= gap.to);
        if (inside.length > 0) {
          this.seedTape(session, inside);
          endAggId = inside[inside.length - 1].a;
        }
        // The hole is closed when a row past its end was read, or the page
        // was short (nothing newer existed on the exchange at the read).
        if (inside.length < rows.length || rows.length < TAPE_BOOTSTRAP_PAGE) {
          closed = true;
          break;
        }
        fromId = rows[rows.length - 1].a + 1;
      }
    } catch (error) {
      if (!this.isCurrent(session)) return;
      seam.inFlight = false;
      seam.gap = null;
      seam.failures += 1;
      console.warn("browserBinanceTransport: a tape seam fill failed", error);
      if (seam.failures < SEAM_FILL_FAILURES_BEFORE_GIVING_UP) {
        const delay = seam.backoffMs;
        seam.backoffMs = Math.min(seam.backoffMs * 2, STREAM_BACKOFF_CAP_MS);
        seam.timer = this.setTimer(() => {
          seam.timer = null;
          this.fillNextSeam(session);
        }, delay);
        return;
      }
      seam.failures = 0;
      seam.backoffMs = STREAM_BACKOFF_INITIAL_MS;
      session.unfillable.push({ from: gap.from, to: gap.to });
      this.fillNextSeam(session);
      return;
    }
    seam.inFlight = false;
    seam.gap = null;
    seam.failures = 0;
    seam.backoffMs = STREAM_BACKOFF_INITIAL_MS;
    if (closed) {
      addInterval(session.observed, { from: gap.from, to: gap.to, endAggId });
      // Coverage grew: the snapshot says so.
      session.seam.publishWhenSettled = true;
    } else {
      console.warn("browserBinanceTransport: a tape seam is wider than a fill may walk; it stays open");
      session.unfillable.push({ from: gap.from, to: gap.to });
    }
    this.fillNextSeam(session);
  }
