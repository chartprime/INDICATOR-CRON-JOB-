# Build brief: browser-direct Binance data mode (`browser-binance`)

Branch `build/browser-direct-binance`, 2026-10-26. The web app runs with no
runtime server: the worker reads Binance spot from the browser and feeds the
main thread the canonical frames the runtime would send. Opt-in only:
`VITE_DATA_SOURCE=browser-binance` at build time or `?source=browser-binance`.
With neither, every byte the worker sends and receives is unchanged.

## 1. The seam

`marketDataWorker.ts` creates its socket in `connect()` with `new WebSocket(url)`.
That line becomes `createTransport(url, source)`, exported for tests:

```ts
export interface TransportSocket {
  readyState: number;
  send(data: string): void;
  close(): void;
  onopen: ((event: Event) => void) | null;
  onmessage: ((event: MessageEvent) => void) | null;
  onclose: ((event: CloseEvent) => void) | null;
  onerror: ((event: Event) => void) | null;
}
export function createTransport(url: string, source: DataSource | undefined): TransportSocket {
  return source === "browser-binance" ? new BrowserBinanceTransport(url) : new WebSocket(url);
}
```

A real `WebSocket` satisfies the interface, so the worker's `ws`, `socketCleanup`
and helper parameters are retyped to `TransportSocket` and nothing else changes:
it still sends `capabilities` then `select`, parses every incoming `event.data`
string with `parseServerFrame`, and reconnects on close. The `start` message
gains one optional field, `source: "browser-binance"`, set by `useMarketData.ts`
from `import.meta.env.VITE_DATA_SOURCE` or `location.search`
(`resolveDataSource()`); the query string wins so a tester can switch a bundle.

`BrowserBinanceTransport` (`apps/web/src/workers/browserBinanceTransport.ts`)
takes injectable `fetch`, `WebSocket`, clock and timers so tests run offline;
every frame leaves it as a JSON `MessageEvent`, so the worker's parser stays
the contract gate in production.

## 2. Frame sequence on selection

The worker sends `{"type":"select",...}` as today. When its `onopen` sends no
selection (first start), the transport selects `BTC-USDT` SPOT, as the runtime
pushes its current pair on connect.

For a Binance SPOT pair:

1. `selection`.
2. REST `GET https://data-api.binance.vision/api/v3/klines?symbol=BTCUSDT&interval=1m&limit=901`.
3. `snapshot`: the closed rows (`closeTime < now`, at most 900, oldest first),
   each a `bar` with `closed: true` and `reconstructed: true` (REST-sourced, as
   `restKlineRowToBarFrame` marks them), `trades: []`, `markers: []`,
   `vpin_status: "DISABLED"`. No `bar_history`: the parser rejects it on a
   Binance snapshot.
4. `health` `READY`, `stale: false`, `reason: "BROWSER_DIRECT"`.
5. `book` `UNAVAILABLE`, `reason: "BROWSER_DIRECT_STREAM_CONNECTING"`.
6. The last REST row as a forming `bar` (`closed: false`) if its minute is open.
7. One combined mirror stream
   `wss://data-stream.binance.vision:9443/stream?streams=btcusdt@kline_1m/btcusdt@trade/btcusdt@depth20@100ms`,
   then `bar`, `trade` and `book` frames as events arrive.

A second `select` ends the session and restarts at step 1.

## 3. Payload to frame mapping

| Binance payload | Frame | Fields |
|---|---|---|
| REST kline row `[t,o,h,l,c,v,T,q,n,V,Q,_]` | `bar` | `ts_open: t`, OHLC and `volume` as numbers, `buy_volume: V`, `trade_count: n`, `closed: true`, `reconstructed: true`, `interval_ms: 60000` |
| `kline` event `k` | `bar` | same from `k.t,o,h,l,c,v,V,n`; `closed: k.x` (forming while false, closed once true); no `reconstructed` |
| `trade` event | `trade` | `ts_exchange: T`, `price: +p`, `size: +q`, `side: m ? "sell" : "buy"`, `trade_id: String(t)` |
| `depth20@100ms` `{lastUpdateId,bids,asks}` | `book` | `status: "READY"`, bids/asks as `{price,size}` numbers (zero sizes dropped), `lastUpdateId`, `stale: false` |
| stream close, or no open within 15 s | `health` | `RECOVERING`, `stale: true`, `reason: "BROWSER_DIRECT_STREAM_CLOSED"`; reconnect with 1 s to 30 s backoff; after five failures `UNAVAILABLE`, `reason: "BROWSER_DIRECT_STREAM_UNAVAILABLE"`, retries continue |
| stream reopen | `bar`, `health` | REST klines from the last confirmed closed bar fill the gap as closed `reconstructed` bars; closes the new stream reports meanwhile wait and follow in order; then `READY`. A failed fill keeps `RECOVERING` (`BROWSER_DIRECT_REST_FAILED`) and retries; a stream that dies mid-fill abandons it |
| REST failure | `health` | `UNAVAILABLE`, `reason: "BROWSER_DIRECT_REST_FAILED"`, retried with the same backoff |

Identity on every frame: `provider: "BINANCE"`, wire `symbol`, `marketKind`
from the selection. Side and `buy_volume` follow `apps/runtime/src/server/frames.js`.

## 4. Honest answers to client requests

| Request | Answer |
|---|---|
| `aggressive_history` | `complete: false`, `reason: "STORAGE_UNAVAILABLE"`, `trades: []`; the client shows its degraded state and retries three times with backoff |
| `delta_profile` | `complete: false`, `reason: "STORAGE_UNAVAILABLE"`, `pending: 0`, `rows: []` |
| `band_history` | `complete: false`, `reason: "GEOMETRY_UNAVAILABLE"`, row fields `null` (no live book grid exists) |
| `wall_history`, `l2_event_history` | `complete: false`, `reason: "HISTORY_UNAVAILABLE"`, `row_width: null`, empty rows, `next: null` |
| `profile_config`, `profile_history` | `analytics_status` `PROFILE` `UNAVAILABLE` (the browser withdraws the live profile and shows the label) |
| `capabilities`, `liquidity_resync`, `l2_resync`, `exhaustion_history`, `initiative_history` | ignored: no reply shape exists; L2 indicators stay in their "no L2 frame yet" state |
| `heatmap_history`, `heatmap_walls` | untouched: the HTTP fetch fails, the stores back off |

Every answer echoes the request's ids and window.

## 5. Health reason and the visible notice

`BROWSER_DIRECT` rides on the READY health frame. The status chip in
`Terminal.tsx` appends ` (reason)` to `LIVE` when a READY frame carries one,
the form MainPanel uses for UNAVAILABLE. The runtime sends a reason only with
UNAVAILABLE today, so the default display is unchanged.

## 6. Other instruments

- PERPETUAL: `https://fapi.binance.com/fapi/v1/klines` and
  `wss://fstream.binance.com/stream?streams=...`; there is no mirror. The
  first REST or stream failure gives `health` `UNAVAILABLE`,
  `reason: "BROWSER_DIRECT_PERPETUAL_UNREACHABLE"` (retries continue), no hang.
- dxFeed: `selection`, an empty `snapshot`, then `health` `UNAVAILABLE`,
  `reason: "BROWSER_DIRECT_NO_DXFEED"`, like `DXFEED_NOT_CONFIGURED` today.

## 7. Unsupported

No L2 engine, heatmap, walls, icebergs, exhaustion, initiative, candle monitor,
profiles or VPIN; no history past 900 bars; no trades before the page opened;
no marker pool; a 20-level book. Perpetuals only where the browser reaches
`fapi`/`fstream`. This container cannot open WebSockets, so the live stream is
verified by tests and the REST-only rendering, not end to end.

+function bookLevels(raw: unknown): Array<{ price: number; size: number }> | null {
+  if (!Array.isArray(raw)) return null;

+  /**
+   * After a stream reconnect: closed bars the stream missed come from REST,
+   * marked reconstructed as the runtime marks its backfill. The REST read
+   * starts at the boundary the live stream last confirmed before the gap;
+   * closes the new stream reports meanwhile wait in the buffer, so the main
+   * thread sees closed bars in order and never a hole. A failed read keeps the
+   * feed RECOVERING and is retried with backoff; READY follows only a read that
+   * succeeded for the stream that is still open.

+  private async recoverAfterGap(session: Session, generation: number): Promise<void> {
+    let rows: KlineRow[];

+      rows = await this.fetchKlines(session, session.lastClosedOpen >= 0 ? { startTime: session.lastClosedOpen + BAR_INTERVAL_MS, limit: 1000 } : { limit: SNAPSHOT_BARS + 1 });
+    } catch (error) {

+      this.deliverHealth(session, "RECOVERING", HEALTH_REASON_REST_FAILED);
+      this.scheduleRetry(session, () => {
+        if (this.recoveryIsLive(session, generation)) void this.recoverAfterGap(session, generation);
+      });
+      return;
+    }
+    if (!this.recoveryIsLive(session, generation)) return;
+    const now = this.now();
+    for (const row of rows) {
+      if (row.closeTime < now && row.openTime > session.lastClosedOpen) this.deliverClosedBar(session, row, true);
+    }
+    for (const row of [...session.heldClosedBars.values()].sort((a, b) => a.openTime - b.openTime)) {
+      if (row.openTime > session.lastClosedOpen) this.deliverClosedBar(session, row, false);
+    }
+    session.heldClosedBars.clear();

+    session.heldFormingBar = null;
+    if (forming !== null && forming.openTime > session.lastClosedOpen) this.deliver(barFrame(session.selection, forming, false, false));
+    session.recovering = false;
+    session.degraded = false;
+    session.backoffMs = STREAM_BACKOFF_INITIAL_MS;
+    this.deliverHealth(session, "READY", HEALTH_REASON_READY);
+  }

+  }

+    if (payload.e === "kline") {

+        if (bar.closed) session.heldClosedBars.set(bar.openTime, bar);
+        else session.heldFormingBar = bar;
+        return;
+      }
+      if (bar.closed) this.deliverClosedBar(session, bar, false);
+      else this.deliver(barFrame(session.selection, bar, false, false));
+      return;
+    }
+    if (payload.e === "trade") {
+      const price = finiteNumber(payload.p);
+      const size = finiteNumber(payload.q);
+      if (price === undefined || size === undefined || price <= 0 || size <= 0) return;
+      if (!Number.isSafeInteger(payload.T) || !Number.isSafeInteger(payload.t) || typeof payload.m !== "boolean") return;
+      this.deliver({
+        type: "trade",
+        ...identityFields(session.selection),
+        ts_exchange: payload.T,
+        price,
+        size,
+        side: payload.m ? "sell" : "buy",
+        trade_id: String(payload.t),
+      });
+      return;
+    }
+    const isSpotPartial = Array.isArray(payload.bids) && Array.isArray(payload.asks) && Number.isSafeInteger(payload.lastUpdateId);
+    const isFuturesPartial = payload.e === "depthUpdate" && Array.isArray(payload.b) && Array.isArray(payload.a) && Number.isSafeInteger(payload.u);
+    if (!isSpotPartial && !isFuturesPartial) return;

+    const asks = bookLevels(isSpotPartial ? payload.asks : payload.a);
+    if (bids === null || asks === null) return;
+    if (bids.length > 0 && asks.length > 0 && bids[0].price >= asks[0].price) return;
+    this.deliver({
+      type: "book",
+      ...identityFields(session.selection),
+      status: "READY",
+      bids: bids.slice(0, 20),
+      asks: asks.slice(0, 20),
+      lastUpdateId: (isSpotPartial ? payload.lastUpdateId : payload.u) as number,
+      stale: false,
+    });
+  }

+## Browser-direct mode (no runtime)
+
+The web app can read Binance spot by itself, for a link that opens anywhere to
+test indicators on live data. It is opt-in and off by default: with neither
+switch below set, the worker speaks to the runtime over its WebSocket exactly
+as before.
+
+- Build-time: `VITE_DATA_SOURCE=browser-binance` baked into the bundle.
+- Per page: `?source=browser-binance` in the URL (wins over the build-time
+  value; `?source=runtime` switches a baked bundle back).
+
+The market-data worker then uses `BrowserBinanceTransport`
+(`apps/web/src/workers/browserBinanceTransport.ts`) in place of the socket to
+the runtime. On a selection it fetches the last 900 closed one-minute klines
+from Binance's public mirror (`https://data-api.binance.vision`), sends
+`selection`, `snapshot` (closed bars only, marked `reconstructed` as the
+runtime marks its REST backfill), `health` READY with `reason: "BROWSER_DIRECT"`
+and a `book` placeholder, then opens one mirror stream
+(`wss://data-stream.binance.vision:9443`) for `kline_1m`, `trade` and
+`depth20@100ms` and forwards each event as a `bar`, `trade` or `book` frame.
+Side, `buy_volume` and `trade_count` follow `src/server/frames.js`, so
+indicators see the same data as from the runtime; every frame still passes the
+browser's own frame parser. The status chip reads `LIVE (BROWSER_DIRECT)`.
+
+What it does not have: the L2 engine and heatmap, walls, icebergs, exhaustion,
+initiative, candle monitor, live profiles and VPIN (their requests get the
+contract's unavailable reply, so those indicators show their own "needs the
+runtime" state); history past 900 bars; trades from before the page opened;
+the marker pool; a book deeper than 20 levels. Spot only: perpetual pairs are
+attempted on `fapi`/`fstream` and report
+`BROWSER_DIRECT_PERPETUAL_UNREACHABLE` when the browser cannot reach them;
+dxFeed instruments report `BROWSER_DIRECT_NO_DXFEED`. A dropped spot stream
+shows `RECOVERING` and reconnects with backoff (`UNAVAILABLE` after five
+failures); once it is back, the closed bars it missed come from REST, in order,
+before the feed is `READY` again.
+
+To build a static bundle with the mode baked in and relative asset paths:
+
+```bash
+cd apps/web && VITE_DATA_SOURCE=browser-binance npx vite build --base ./ --outDir ../../dist-browser-direct
+```
+
+Serve `dist-browser-direct/` from any static host or open `index.html` through
+one; nothing else needs to run.

   640	   * marked reconstructed as the runtime marks its backfill. The REST read
   641	   * starts at the boundary the live stream last confirmed before the gap;
   642	   * closes the new stream reports meanwhile wait in the buffer, so the main
   643	   * thread sees closed bars in order and never a hole. A failed read keeps the
   644	   * feed RECOVERING and is retried with backoff; READY follows only a read that
   645	   * succeeded for the stream that is still open.
   646	   */
   647	  private async recoverAfterGap(session: Session, generation: number): Promise<void> {
   648	    let rows: KlineRow[];

   654	      this.deliverHealth(session, "RECOVERING", HEALTH_REASON_REST_FAILED);

   657	      });

   663	      if (row.closeTime < now && row.openTime > session.lastClosedOpen) this.deliverClosedBar(session, row, true);
   664	    }
   665	    for (const row of [...session.heldClosedBars.values()].sort((a, b) => a.openTime - b.openTime)) {
   666	      if (row.openTime > session.lastClosedOpen) this.deliverClosedBar(session, row, false);
   667	    }
   668	    session.heldClosedBars.clear();

   670	    session.heldFormingBar = null;
   671	    if (forming !== null && forming.openTime > session.lastClosedOpen) this.deliver(barFrame(session.selection, forming, false, false));
   672	    session.recovering = false;
   673	    session.degraded = false;
   674	    session.backoffMs = STREAM_BACKOFF_INITIAL_MS;
   675	    this.deliverHealth(session, "READY", HEALTH_REASON_READY);
   676	  }

   678	  private deliverClosedBar(session: Session, bar: KlineRow, reconstructed: boolean): void {
   679	    this.deliver(barFrame(session.selection, bar, true, reconstructed));
   680	    session.lastClosedOpen = bar.openTime;
   681	  }

   683	  private routeStreamMessage(session: Session, parsed: unknown): void {
   684	    if (!isRecord(parsed)) return;

   687	      const bar = parseKlineEvent(payload.k);
   688	      if (bar === null) return;
   689	      if (bar.closed && bar.openTime <= session.lastClosedOpen) return;
   690	      if (session.recovering) {
   691	        if (bar.closed) session.heldClosedBars.set(bar.openTime, bar);
   692	        else session.heldFormingBar = bar;
   693	        return;
   694	      }
   695	      if (bar.closed) this.deliverClosedBar(session, bar, false);
   696	      else this.deliver(barFrame(session.selection, bar, false, false));
   697	      return;
   698	    }
   699	    if (payload.e === "trade") {
   700	      const price = finiteNumber(payload.p);
   701	      const size = finiteNumber(payload.q);
   702	      if (price === undefined || size === undefined || price <= 0 || size <= 0) return;
   703	      if (!Number.isSafeInteger(payload.T) || !Number.isSafeInteger(payload.t) || typeof payload.m !== "boolean") return;
   704	      this.deliver({
   705	        type: "trade",
   706	        ...identityFields(session.selection),
   707	        ts_exchange: payload.T,
   708	        price,
   709	        size,
   710	        side: payload.m ? "sell" : "buy",
   711	        trade_id: String(payload.t),
   712	      });
   713	      return;
   714	    }
   715	    const isSpotPartial = Array.isArray(payload.bids) && Array.isArray(payload.asks) && Number.isSafeInteger(payload.lastUpdateId);
   716	    const isFuturesPartial = payload.e === "depthUpdate" && Array.isArray(payload.b) && Array.isArray(payload.a) && Number.isSafeInteger(payload.u);
   717	    if (!isSpotPartial && !isFuturesPartial) return;
   718	    const bids = bookLevels(isSpotPartial ? payload.bids : payload.b);
   719	    const asks = bookLevels(isSpotPartial ? payload.asks : payload.a);
   720	    if (bids === null || asks === null) return;
   721	    if (bids.length > 0 && asks.length > 0 && bids[0].price >= asks[0].price) return;
   722	    this.deliver({
   723	      type: "book",
   724	      ...identityFields(session.selection),
   725	      status: "READY",
   726	      bids: bids.slice(0, 20),
   727	      asks: asks.slice(0, 20),
   728	      lastUpdateId: (isSpotPartial ? payload.lastUpdateId : payload.u) as number,
   729	      stale: false,
   730	    });
   731	  }
