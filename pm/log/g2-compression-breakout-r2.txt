## The trading question

"Did price leave an established compression range with activity behind the
break bar, and did it come back inside?" Trend is secondary context: it
colours a border and a table row, it never decides.

## Why a fixed range, not a squeeze (the pivot)

The round-3 scratch comparison showed a frozen 20-bar range qualified by
width (k = 2) matching or beating the Bollinger-inside-Keltner squeeze on
every design metric: hits 20/20 versus 18/20, filtered early events 0 versus
10, level validity 20/20 versus 18/18, outcome fixtures 10/10 versus 9/10,
range-control markers 0.4 versus 10.8 per 1,000. The fixtures are monotone
contractions, which favour a fixed-range qualifier, so this is not a claim
that squeezes are worse on real data. The pivot is justified by simplicity
(one ring fewer, no band arithmetic, one sentence: "price has stayed inside a
range narrower than twice its recent bar range") plus equal or better numbers.
The squeeze qualifier stays as a test-only variant, and the live run and the
v2 clause keep the question open.

## Target user and decision

Intraday and swing breakout traders on BTC, ETH, ES, NQ, AAPL, TSLA. Decision:
act on a close outside the compression range, stand aside once it fails, or
treat it as counter-trend context. Descriptive only: "range+vol" means both
activity tests passed on the break bar; "held outside 5 bars" means the
failure window expired, not that a trade worked.

## Data, validity and storage

**Price valid**: open, high, low, close finite, `high ≥ low`, `low ≤ close ≤
high`. **Volume valid**: finite, `≥ 0`. An invalid-price bar contributes
nothing (no ring entry, no range change, no age, no event; status `No usable
price`). Invalid volume keeps the price context; the bar enters no volume
observation and its volume cannot be tested (`vol n/a`). Missing bars
contribute nothing. **Means span valid observations across gaps.** No library
stream drives an event (round 1 evidence); own committed-bar rings, primitives
from `relative-volume/relativeVolumeMath.ts`:

| Ring | Capacity | Serves | Tail |
|---|---|---|---|
| high, low | `rangeLength` (≤ 50) | range width and edges | provisional for the status row; the range opens at commit |
| true range | `2 × rangeLength` (≤ 100) | reference width (the `rangeLength` valid bars preceding the window); range denominator (the preceding 20 valid observations) | excluded from both |
| volume | 20 | volume denominator | excluded |
| close | `trendSlow` (≤ 400) | both MAs | excluded |
| fast-MA history | 6 | slope | excluded |

**True range** uses the previous committed close; on the first bar and on the
first bar after a gap it is `high − low`, so an overnight jump never enters a
reference or a denominator. The slot-median volume baseline is a v2
`volumeRule` option (`createRelativeVolumeEngine`, `reading.rvol`); v1 uses
the rolling denominators so the grade is testable on 400-bar fixtures.

## Calculation

Settings: `rangeLength` 20, `widthMultiple` k 2, `minCompressionBars` 6,
`confirmMultiple` 1.5, `failBars` 5, `holdBars` 40, `trendFast` 50,
`trendSlow` 200. Constant `RANGE_LIFETIME` 500 committed bars.
`committedIndex` counts committed valid-price bars.

1. **Tail and snapshot.** The first dispatch of a new `ts_open` creates the
   tail record and copies the committed state `S`: the five rings,
   `prevClose`, `lastCommittedTsOpen`, `committedIndex`, the active range
   (`hi, lo, openedAt, age, broken, excursion`), the held ranges with
   remaining hold, `lastEvent`. About 600 numbers once per `ts_open`, never
   per revision. **`S` is never modified**; every evaluation, revision and
   correction works on a copy `W`.
2. **Gap (on `W`).** If `ts_open − W.lastCommittedTsOpen > interval_ms`, drop
   the active range from `W` (held ranges stay); status `Gap · range reset`.
   An invalid-price tail cannot reset the committed range.
3. **Provisional values from `W` plus the tail.** `qualified` = width of the
   last `rangeLength` committed highs and lows (`rangeLength − 1` plus the
   tail, status row only) `≤ k ×` mean true range of the `rangeLength` valid
   bars preceding that window; `widthRatio = width / reference` (`null` if the
   reference is 0 or short). Denominators `avgRange20`, `avgVolume20`: mean of
   the preceding 20 valid observations, available only when 20 exist and the
   mean is `> 0`. `gradeBasis` per component = denominator available **and**
   this bar's value valid: 0 none, 1 range, 2 volume, 3 both testable. Trend:
   `fastMA`, `slowMA` over committed closes; slope = `fastMA` now versus five
   committed bars earlier; `up` if `close > slowMA` and slope `> 0`, `down` on
   the mirror, `flat` otherwise; `unknown` until `trendSlow + 5` committed
   closes, or whenever `trendFast ≥ trendSlow`.
4. **Decision, exactly one per bar, read only against `W.active`.**
   - `W.active.broken`: close inside the frozen `[lo, hi]` → `failed`; else
     `committedIndex − brokenIndex === failBars` → `heldOutside`; else
     `pending`. Window = the `failBars` committed bars after the break bar,
     last included.
   - else `W.active` exists and close `> hi` or `< lo`: if `age ≥
     minCompressionBars` → break up / down, tests on testable components only
     (`trueRange ≥ confirmMultiple × avgRange20`, `volume ≥ confirmMultiple ×
     avgVolume20`), `breakGrade` 3 both passed, 1 range only, 2 volume only,
     0 none; if `age < minCompressionBars` → `abandoned` (the range never
     established; silent, not held). Break beats lifetime on the same bar.
   - else `W.active` exists and `committedIndex − openedAt ≥ RANGE_LIFETIME`
     → `expired`.
   - else `none`.
5. **Commit, first dispatch with `closed === true`, in this order.**
   (a) every held range's countdown decrements; one at 0 is removed and its
   handle freed (`holdBars` 0: a retired range disappears at once);
   (b) valid high, low, close and true range enter their rings, valid volume
   its ring, `fastMA` the slope ring;
   (c) the decision is applied: `break` → `broken = {committedIndex, dir,
   grade, basis}`, `excursion` = this bar's high/low; `failed`, `heldOutside`,
   `expired` → the range moves to the held list (`holdBars` remaining;
   `expired` styled like `heldOutside`), `active = null`, `lastEvent`
   updated; `abandoned` → `active = null`, nothing held, no event; `pending`
   → excursion extended, `age += 1`; `none` with an active range → `age += 1`;
   (d) no active range, the window is ready, `qualified` on the committed
   rings, decision `none` → open `{hi, lo}` = the committed window's extremes,
   `openedAt: committedIndex, age: 0`. **Edges never move after opening**; the
   rolling qualification is not re-checked (a frozen range ends only by
   break, abandonment or lifetime);
   (e) `prevClose`, `lastCommittedTsOpen`, `committedIndex` advance; `W`
   becomes the new `S`. `age` counts committed bars inside the frozen edges.
6. **No widening, no re-arm.** A failed break retires its range; a new range
   must requalify and establish again.
7. **Superseded without close**: nothing written; the provisional marker is
   removed on the next dispatch.
8. **Corrections**: a closed re-dispatch of the tail re-runs 2 to 5 from a
   fresh copy of the untouched `S` (cancelled break, removed failure, grade
   change, invalid-to-valid and back). Older corrections arrive as `REBUILT`.
9. **Outputs** (`readOutput`). Persistent: `rangeHigh`, `rangeLow` (active
   range only, incl. pending; `null` otherwise), `widthRatio`, `qualified`,
   `trend` −1/0/1 or `null`, `rangeAge`, `pending` 0/1 (1 from the bar after
   the break through the outcome bar). Pulses, non-zero on the event bar
   only: `breakDir`, `breakGrade`, `gradeBasis`, `failed`, `heldOutside`.
   `rangeHigh`/`rangeLow` are the line outputs.
10. **Pinned transitions** (seed-7 breakout, break at 220, `holdBars` 40):
    `breakDir = 1`, `breakGrade = 3`, `gradeBasis = 3` at 220 only; `pending =
    1` at 221..225; `heldOutside = 1` at 225; `rangeHigh/rangeLow` non-null
    through 225, `null` from 226 until a new range; the held range is drawn
    226..265, its handle freed at 266's commit before any range opens at 266;
    `lastEvent` reads `↑ 220 · range+vol` from 220's commit. `holdBars` 0:
    nothing drawn at 226. A range opened at `committedIndex` 100 with no break
    expires at 600's decision. A range left at `age` 3 is abandoned silently.
11. **Readiness per component.** Qualification and range creation from
    zero-based index `2 × rangeLength − 1` (39 at default; `qualified` and
    `widthRatio` `null` before); grading from index 20 with no invalid bars
    before; trend from `trendSlow + 5`. First possible break at index `39 +
    minCompressionBars`.
12. **Table strings, ≤ 30 characters.** Row 1 `Range 61240–61480`
    (instrument precision, no thousands separators; if the row would exceed
    30 characters both edges round to six significant digits), `Warming up ·
    12 of 40 bars`, or `No range`. Row 2 `Trend ↑ · MA 50/200`, `Trend ↓ ·
    MA 50/200`, `Trend flat · MA 50/200`, `Trend · warming 120/205`, `Trend ·
    fast ≥ slow`. Row 3, first match: `No usable price`; `Gap · range reset`;
    `Failed break`; `Held outside · 5 bars`; `Range expired · 500 bars`;
    break strings `Break ↑ · range+vol`, `range only`, `vol only`,
    `unconfirmed` (both testable), `range · vol n/a`, `vol n/a` (volume not
    testable; range passed / failed), `vol · range n/a`, `range n/a`, `no
    baseline`; `Pending · 2 of 5 bars`; `Range · 9 bars · 1.6×`; `Range
    forming · 3 of 6`; `No range`. Row 4 `Last · ↑ 12:34 · range+vol` or `—`.
    Visible from bar 0; provisional styling on the forming tail.
13. **No future data; fail closed.** Values at bar t use bars with `ts_open ≤
    t.ts_open`; any non-finite intermediate yields `null`.

## Replay policy

(a) **Bounded lifetime.** No range lives past `RANGE_LIFETIME` 500 committed
bars, so every state has a finite horizon: `max(trendSlow + 5, 500 + holdBars
+ failBars)` retained bars (545 at defaults). After the horizon, live and a
replay from the first retained bar must be exactly equal in every output,
event, marker and drawn range; the REBUILT equivalence test asserts a non-zero
compared count after it.
(b) **Pre-horizon difference, documented and tested.** On
`longCompressionBars` with a REBUILT from index 300, the live instance's range
(opened once the window qualifies, expired 500 bars later, a new range after)
and the rebuilt instance's range (opened once its own 40-bar window qualifies)
differ in `openedAt`, `rangeAge`, `rangeHigh`/`rangeLow` and the drawn range
until the horizon; the test pins the expected difference bar by bar and checks
that both see the break at 740 with the same grade. The doc says that after a
reload a range older than the retained history is seen only from the first
retained bar.

## Limitations to state

Descriptive, not predictive. "Held outside 5 bars" means the failure window
expired, nothing about profit; a return inside is failure of this breakout
rule, not evidence for fading. Readiness: range at `2 × rangeLength` bars,
grading at 20 valid bars, trend at `trendSlow + 5`. The qualifier is a
fixed-length range, not a volatility squeeze; the fixtures favour it and the
live run is where the two are compared. A failed break retires its range; a
second break needs a fresh range. Ranges expire at 500 bars. Equity overnight
gaps reset the range and their first true range is `high − low`. A range older
than the retained history is seen only from the first retained bar after a
reload. Unit-free.

+import type { BarFrame } from "../../../types/frames";

+/**
+ * Compression Range Breakout: the pure, incremental state machine.
+ *
+ * A committed `rangeLength`-bar high/low range qualifies when its width is at
+ * most `widthMultiple` times the mean true range of the `rangeLength` valid
+ * bars preceding that window. Its edges freeze the moment it opens. After
+ * `minCompressionBars` committed bars whose close stayed inside, a close
+ * outside is a break, graded by the break bar's true range and volume against
+ * the preceding 20 valid observations. A close back inside (or beyond the
+ * opposite edge) within `failBars` bars is a failure; otherwise the break is
+ * "held outside". Failure, hold and a 500-bar lifetime retire the range; a
+ * new one must qualify and establish again. No widening, no re-arm.
+ *
+ * Three named states (brief amendment 4): `P`, the committed state before the
+ * tail bar, kept untouched for corrections of that tail; `W`, the working view
+ * every evaluation reads (`P` plus the gap rule, never written); `C`, the
+ * committed state after the tail's first closed dispatch, which seeds the next
+ * `ts_open`. A forming revision evaluates against `P` only. A closed
+ * re-dispatch of the tail recomputes `C` from `P`, so a cancelled break, a
+ * removed failure, a changed grade and a validity flip in either field are all
+ * one rule.
+ *
+ * Lifetime, the failure window and the hold countdown count committed
+ * dispatched bars, invalid-price bars included (they skip every other commit
+ * step); denominators count valid observations and carry no bar bound.
+ *
+ * No library stream drives an event: a never-closed bar left in a
+ * `trading-signals` stream would change range creation. Every window here is a
+ * finite ring of committed valid bars, so corrections and replays are exact.
+ */

+export const RANGE_LIFETIME = 500;

+export const MAX_HELD_RANGES = 7;

+/** Mean of the last `count` entries; null when fewer exist. */
+export function tailMean(values: readonly number[], count: number): number | null {
+  if (count <= 0 || values.length < count) return null;
+  let sum = 0;
+  for (let index = values.length - count; index < values.length; index += 1) sum += values[index];
+  const mean = sum / count;
+  return Number.isFinite(mean) ? mean : null;
+}
+
+/** Mean of `values[from, to)`; null when the slice is not fully present. */
+function sliceMean(values: readonly number[], from: number, to: number): number | null {
+  if (from < 0 || to > values.length || to <= from) return null;
+  let sum = 0;
+  for (let index = from; index < to; index += 1) sum += values[index];
+  const mean = sum / (to - from);
+  return Number.isFinite(mean) ? mean : null;
+}
+
+function pushCapped(values: number[], value: number, capacity: number): void {
+  values.push(value);
+  if (values.length > capacity) values.splice(0, values.length - capacity);
+}

+/**
+ * True range against the previous committed close; `high − low` on the first
+ * bar and on the first bar after a gap. Null when the subtraction overflows:
+ * such a bar enters no range observation and its range test is not taken.
+ */
+export function trueRangeOf(bar: BarFrame, prevClose: number | null, gap: boolean): number | null {
+  const span = bar.high - bar.low;
+  const value = prevClose === null || gap ? span : Math.max(span, Math.abs(bar.high - prevClose), Math.abs(bar.low - prevClose));
+  return Number.isFinite(value) ? value : null;
+}
+
+/** A positive denominator from the last `DENOMINATOR_LENGTH` valid observations; null otherwise. */
+export function denominatorOf(values: readonly number[]): number | null {
+  const mean = tailMean(values, DENOMINATOR_LENGTH);
+  return mean !== null && mean > 0 ? mean : null;
+}
+
+/** Population standard deviation of the last `count` values; null when fewer exist. */
+function tailStdev(values: readonly number[], count: number, mean: number): number | null {
+  if (values.length < count) return null;
+  let sum = 0;
+  for (let index = values.length - count; index < values.length; index += 1) sum += (values[index] - mean) ** 2;
+  const stdev = Math.sqrt(sum / count);
+  return Number.isFinite(stdev) ? stdev : null;
+}

+export interface Qualification {
+  ready: boolean;
+  qualified: boolean;
+  widthRatio: number | null;
+  hi: number;
+  lo: number;

+/**
+ * The qualification of the window formed by the last `rangeLength` entries of
+ * the given rings. On the committed rings this decides whether a range opens;
+ * with the tail appended provisionally it feeds the status row only.
+ */
+export function qualificationOf(
+  highs: readonly number[],
+  lows: readonly number[],
+  trs: readonly number[],
+  closes: readonly number[],
+  settings: Required<CompressionBreakoutMathSettings>,
+): Qualification {
+  const length = settings.rangeLength;
+  const none: Qualification = { ready: false, qualified: false, widthRatio: null, hi: Number.NaN, lo: Number.NaN };
+  if (highs.length < length || lows.length < length || trs.length < 2 * length) return none;
+  let hi = -Infinity;
+  let lo = Infinity;
+  for (let index = highs.length - length; index < highs.length; index += 1) hi = Math.max(hi, highs[index]);
+  for (let index = lows.length - length; index < lows.length; index += 1) lo = Math.min(lo, lows[index]);
+  const width = hi - lo;
+  if (!Number.isFinite(width)) return { ready: true, qualified: false, widthRatio: null, hi, lo };
+  const reference = sliceMean(trs, trs.length - 2 * length, trs.length - length);
+  const ratio = reference !== null && reference > 0 ? width / reference : null;
+  const widthRatio = ratio !== null && Number.isFinite(ratio) ? ratio : null;
+  if (settings.qualifier === "always") return { ready: true, qualified: true, widthRatio, hi, lo };
+  if (settings.qualifier === "squeeze") {
+    if (closes.length < length) return none;
+    const mean = tailMean(closes, length);
+    const stdev = mean === null ? null : tailStdev(closes, length, mean);
+    const atr = tailMean(trs, length);
+    const squeezed = mean !== null && stdev !== null && atr !== null && mean + 2 * stdev < mean + 1.5 * atr && mean - 2 * stdev > mean - 1.5 * atr;
+    return { ready: true, qualified: squeezed, widthRatio, hi, lo };
+  }
+  return { ready: true, qualified: widthRatio !== null && widthRatio <= settings.widthMultiple, widthRatio, hi, lo };
+}

+export function createCompressionBreakoutEngine(input: CompressionBreakoutMathSettings): CompressionBreakoutEngine {
+  const settings = normalizedSettings(input);
+  const trCapacity = Math.max(2 * settings.rangeLength, DENOMINATOR_LENGTH);
+  const closeCapacity = Math.max(settings.trendSlow, DENOMINATOR_LENGTH);
+  const readinessCount = 2 * settings.rangeLength;
+  let pre: CommittedState = createCommittedState();
+  let committed: CommittedState = pre;
+  let tailTsOpen: number | null = null;
+  let current: Reading | null = null;
+
+  function evaluate(P: CommittedState, bar: BarFrame): Reading {
+    const priceValid = isPriceValid(bar);
+    const volumeValid = isVolumeValid(bar.volume);
+    const gapNow =
+      P.lastCommittedTsOpen !== null &&
+      Number.isFinite(bar.interval_ms) &&
+      bar.interval_ms > 0 &&
+      bar.interval_ms < DAY_MS &&
+      bar.ts_open - P.lastCommittedTsOpen > bar.interval_ms;
+    // A gap seen by an invalid-price bar is kept pending: that bar skips every commit step (amendment 5), and the
+    // next valid-price bar performs the reset and takes `high − low` as its true range.
+    const gap = gapNow || P.pendingGapReset;
+    // W: P with the gap rule applied, never written.
+    const active = gap && priceValid ? null : P.active;
+    const trueRange = priceValid ? trueRangeOf(bar, P.prevClose, gap) : null;
+    const avgRange = denominatorOf(P.trs);
+    const avgVolume = denominatorOf(P.volumes);
+    const rangeTestable = avgRange !== null && trueRange !== null;
+    const volumeTestable = avgVolume !== null && volumeValid;
+    const gradeBasis = ((rangeTestable ? 1 : 0) + (volumeTestable ? 2 : 0)) as GradeBasis;
+
+    // Provisional qualification: the window of rangeLength − 1 committed bars plus the tail.
+    let qualified: boolean | null = null;
+    let widthRatio: number | null = null;
+    if (priceValid && P.highs.length >= settings.rangeLength - 1 && P.trs.length >= 2 * settings.rangeLength - 1) {
+      const provisional = qualificationOf(
+        [...P.highs, bar.high],
+        [...P.lows, bar.low],
+        [...P.trs, trueRange as number],
+        [...P.closes, bar.close],
+        settings,
+      );
+      if (provisional.ready) {
+        qualified = provisional.qualified;
+        widthRatio = provisional.widthRatio;
+      }
+    }
+
+    // Trend, from committed closes only; the tail's close is compared with them.
+    let trendStatus: TrendStatus = "warming";
+    let trend: -1 | 0 | 1 | null = null;
+    if (settings.trendFast >= settings.trendSlow) {
+      trendStatus = "fastGeSlow";
+    } else if (P.validCount >= settings.trendSlow + 5 && P.closes.length >= settings.trendSlow && P.fastHistory.length >= SLOPE_HISTORY) {
+      trendStatus = "ready";
+      if (priceValid) {
+        const slowMa = tailMean(P.closes, settings.trendSlow);
+        const slope = P.fastHistory[P.fastHistory.length - 1] - P.fastHistory[0];
+        if (slowMa !== null && Number.isFinite(slope)) trend = bar.close > slowMa && slope > 0 ? 1 : bar.close < slowMa && slope < 0 ? -1 : 0;
+      }
+    }
+
+    // Decision, exactly one per bar, read against W.
+    const index = P.committedIndex;
+    let decision: Decision = { kind: "none", dir: 0, grade: 0, basis: gradeBasis, rangePassed: false, volumePassed: false };
+    if (!priceValid) {
+      decision = { ...decision, kind: "invalidPrice" };
+    } else if (active !== null && active.broken !== null) {
+      const inside = bar.close <= active.hi && bar.close >= active.lo;
+      const opposite = active.broken.dir > 0 ? bar.close < active.lo : bar.close > active.hi;
+      if (inside || opposite) decision = { ...decision, kind: "failed", dir: active.broken.dir, grade: active.broken.grade, basis: active.broken.basis };
+      else if (index - active.broken.index >= settings.failBars)
+        decision = { ...decision, kind: "heldOutside", dir: active.broken.dir, grade: active.broken.grade, basis: active.broken.basis };
+      else decision = { ...decision, kind: "pending", dir: active.broken.dir, grade: active.broken.grade, basis: active.broken.basis };
+    } else if (active !== null) {
+      const dir: Direction | 0 = bar.close > active.hi ? 1 : bar.close < active.lo ? -1 : 0;
+      if (dir !== 0) {
+        if (active.age >= settings.minCompressionBars) {
+          const rangePassed = rangeTestable && (trueRange as number) >= settings.confirmMultiple * (avgRange as number);
+          const volumePassed = volumeTestable && bar.volume >= settings.confirmMultiple * (avgVolume as number);
+          const grade: BreakGrade = rangePassed && volumePassed ? 3 : rangePassed ? 1 : volumePassed ? 2 : 0;
+          decision = { kind: "break", dir, grade, basis: gradeBasis, rangePassed, volumePassed };
+        } else {
+          decision = { ...decision, kind: "abandoned", dir };
+        }
+      } else if (index - active.openedAt >= RANGE_LIFETIME) {
+        decision = { ...decision, kind: "expired" };
+      }
+    }
+
+    // Readiness counts committed valid-price bars plus this bar when its price is valid; the rings themselves are capped.
+    const validThroughThisBar = P.validCount + (priceValid ? 1 : 0);
+    return {
+      tsOpen: bar.ts_open,
+      intervalMs: bar.interval_ms,
+      confirmed: bar.closed === true,
+      priceValid,
+      volumeValid,
+      gap,
+      trueRange,
+      warmupCount: Math.min(validThroughThisBar, readinessCount),
+      warmupNeeded: readinessCount,
+      rangeReady: validThroughThisBar >= readinessCount,
+      active,
+      rangeHigh: active?.hi ?? null,
+      rangeLow: active?.lo ?? null,
+      rangeAge: active?.age ?? null,
+      pending: active !== null && active.broken !== null ? 1 : 0,
+      pendingBars: active !== null && active.broken !== null ? index - active.broken.index : 0,
+      qualified,
+      widthRatio,
+      trend,
+      trendStatus,
+      closesCount: Math.min(P.validCount, settings.trendSlow + 5),
+      avgRange,
+      avgVolume,
+      gradeBasis,
+      decision,
+      held: P.held,
+      lastEvent: P.lastEvent,
+    };
+  }
+
+  /** The commit of the tail's first closed dispatch: `C` from `P`, in the brief's order. */
+  function commit(P: CommittedState, bar: BarFrame, reading: Reading): CommittedState {
+    const C = cloneState(P);
+    const index = P.committedIndex;
+    // (a) held countdown: free the ones that reached zero at the previous commit, then count the rest down.
+    C.held = C.held.filter((range) => range.remaining > 0).map((range) => ({ ...range, remaining: range.remaining - 1 }));
+    if (!reading.priceValid) {
+      // The clock advances below; a gap this bar saw waits for the next valid-price commit.
+      C.pendingGapReset = P.pendingGapReset || reading.gap;
+    } else {
+      if (reading.gap) C.active = null;
+      C.pendingGapReset = false;
+      // (b) rings: only finite derived observations enter them.
+      pushCapped(C.highs, bar.high, settings.rangeLength);
+      pushCapped(C.lows, bar.low, settings.rangeLength);
+      pushCapped(C.closes, bar.close, closeCapacity);
+      if (reading.trueRange !== null) pushCapped(C.trs, reading.trueRange, trCapacity);
+      if (reading.volumeValid) pushCapped(C.volumes, bar.volume, DENOMINATOR_LENGTH);
+      const fastMa = tailMean(C.closes, settings.trendFast);
+      if (fastMa !== null) pushCapped(C.fastHistory, fastMa, SLOPE_HISTORY);
+      // (c) the decision
+      const decision = reading.decision;
+      const active = C.active;
+      if (active !== null) {
+        switch (decision.kind) {
+          case "break":
+            active.broken = { index, tsOpen: bar.ts_open, dir: decision.dir as Direction, grade: decision.grade, basis: decision.basis };
+            active.excursionHi = bar.high;
+            active.excursionLo = bar.low;
+            C.lastEvent = { kind: "break", index, tsOpen: bar.ts_open, dir: decision.dir as Direction, grade: decision.grade, basis: decision.basis };
+            break;
+          case "failed":
+          case "heldOutside":
+          case "expired": {
+            const dir = (active.broken?.dir ?? (bar.close >= active.hi ? 1 : -1)) as Direction;
+            C.lastEvent = { kind: decision.kind, index, tsOpen: bar.ts_open, dir, grade: active.broken?.grade ?? 0, basis: active.broken?.basis ?? 0 };
+            retire(C, active, decision.kind, bar.ts_open);
+            C.active = null;
+            break;
+          }
+          case "abandoned":
+            C.active = null;
+            break;
+          case "pending":
+            active.excursionHi = Math.max(active.excursionHi, bar.high);
+            active.excursionLo = Math.min(active.excursionLo, bar.low);
+            active.age += 1;
+            break;
+          case "none":
+            active.age += 1;
+            break;
+          default:
+            break;
+        }
+      }
+      // (d) a new range opens only on a bar with no event, from the committed rings.
+      if (C.active === null && decision.kind === "none") {
+        const qualification = qualificationOf(C.highs, C.lows, C.trs, C.closes, settings);
+        if (qualification.ready && qualification.qualified) {
+          C.active = {
+            hi: qualification.hi,
+            lo: qualification.lo,
+            openedAt: index,
+            openedTs: bar.ts_open,
+            age: 0,
+            widthRatio: qualification.widthRatio,
+            broken: null,
+            excursionHi: qualification.hi,
+            excursionLo: qualification.lo,
+          };
+        }
+      }
+      C.prevClose = bar.close;
+      C.validCount += 1;
+    }
+    // (e) every committed dispatched bar advances the clock, valid or not.
+    C.lastCommittedTsOpen = bar.ts_open;
+    C.committedIndex = index + 1;
+    return C;
+  }
+
+  function retire(C: CommittedState, range: ActiveRange, outcome: Outcome, closedTs: number): void {
+    const held: HeldRange = { hi: range.hi, lo: range.lo, openedTs: range.openedTs, closedTs, outcome, remaining: settings.holdBars };
+    C.held.push(held);
+    // One active handle and seven held ones: the oldest held range gives way to a new one.
+    if (C.held.length > MAX_HELD_RANGES) C.held.splice(0, C.held.length - MAX_HELD_RANGES);
+  }
+
+  function onBar(bar: BarFrame): Reading {
+    if (tailTsOpen !== null && bar.ts_open < tailTsOpen) {
+      // Older than the tail: the runtime replays those as a REBUILT; here it is ignored.
+      return current ?? evaluate(pre, bar);
+    }
+    if (tailTsOpen === null || bar.ts_open > tailTsOpen) {
+      // A new ts_open: C seeds P; a tail superseded without closing wrote nothing.
+      pre = committed;
+      tailTsOpen = bar.ts_open;
+    }
+    const reading = evaluate(pre, bar);
+    if (bar.closed === true) {
+      committed = commit(pre, bar, reading);
+      reading.held = committed.held;
+      reading.lastEvent = committed.lastEvent;
+    } else {
+      committed = pre;
+    }
+    current = reading;
+    return reading;
+  }
+
+  return {
+    settings,
+    onBar,
+    get current() {
+      return current;
+    },
+    get pre() {
+      return pre;
+    },
+    get committed() {
+      return committed;
+    },
+  };
+}

+      } else if (d.kind === "failed" && d.grade >= 1) {
+        ctx.markers.plotshape({ shape: "circle", position: "inBar", color: CB_WARN_COLOR, size: 1 });
+      }
+    },
+    readOutput: (state) => {
+      const r = state.reading;

+        heldOutside: r.decision.kind === "heldOutside" ? 1 : 0,
+        activeHigh: r.rangeHigh,
+        activeLow: r.rangeLow,
+      };
+    },
+  };

+    state.pendingSqueezed = result === null ? null : result.isSqueezed;

+  category: "technical",

+  lines: [{ key: "breakDir" }],

+      ctx.markers.plotshape({ shape: outsideUp ? "arrowUp" : "arrowDown", position: outsideUp ? "belowBar" : "aboveBar", color: outsideUp ? CB_BULL_COLOR : CB_BEAR_COLOR, size: 1 });
+    }
+  },
+  readOutput: (state) => ({ breakDir: state.breakDir }),
+};

+      rangeMarkersPer1000: rangeMarkers / 5,
+      trendMarkersPer1000: trendMarkers / 5,

+    };
+  }

+import type { BarFrame } from "../../../../types/frames";
+import type { CompressionBreakoutLabels, Outputs } from "../../../chart/validation";

+/**
+ * The scoring of the brief and amendment 8, identical for every def:
+ * matched = a break event inside `[breakoutIndex, breakoutIndex + 2]`; hit =
+ * the first matched event carries the labelled direction; wrong-direction = a
+ * break event opposing the label inside that window; early = before the
+ * window (split at `compressionStart`); unmatched = after it; missed = no
+ * matched event; level valid = on a hit, the frozen edges lie inside the
+ * labelled compression range and the close is beyond the tested edge.
+ * Filtering keeps only events whose bar passes the identical activity test
+ * (true range or volume at or above 1.5 times the mean of the preceding 20
+ * bars), computed here from the bars alone, independently of any def.
+ */
+
+export interface BreakEvent {
+  index: number;
+  dir: number;
+  grade: number | null;
+}
+
+export function breakEventsOf(outputs: Outputs): BreakEvent[] {
+  const events: BreakEvent[] = [];
+  const dirs = outputs.breakDir ?? [];
+  const grades = outputs.breakGrade;
+  dirs.forEach((dir, index) => {
+    if (dir !== null && dir !== 0) events.push({ index, dir, grade: grades === undefined ? null : (grades[index] ?? null) });
+  });
+  return events;
+}
+
+/** The identical activity filter: true range or volume at least 1.5× the mean of the preceding 20 bars. */
+export function activityFlags(bars: readonly BarFrame[], multiple = 1.5): boolean[] {
+  const flags: boolean[] = [];
+  const trs: number[] = [];
+  const vols: number[] = [];
+  let prevClose: number | null = null;
+  for (const bar of bars) {
+    const tr = prevClose === null ? bar.high - bar.low : Math.max(bar.high - bar.low, Math.abs(bar.high - prevClose), Math.abs(bar.low - prevClose));
+    const mean = (values: number[]): number | null => (values.length < 20 ? null : values.slice(-20).reduce((a, b) => a + b, 0) / 20);
+    const avgTr = mean(trs);
+    const avgVol = mean(vols);
+    const rangePass = avgTr !== null && avgTr > 0 && tr >= multiple * avgTr;
+    const volumePass = avgVol !== null && avgVol > 0 && bar.volume >= multiple * avgVol;
+    flags.push(rangePass || volumePass);
+    trs.push(tr);
+    vols.push(bar.volume);
+    prevClose = bar.close;
+  }
+  return flags;
+}
+
+export interface Score {
+  hit: 0 | 1;
+  wrongDirection: number;
+  matched: number;
+  early: number;
+  earlyLead: number;
+  earlyCompression: number;
+  unmatched: number;
+  missed: 0 | 1;
+  /** 1 when the hit's edges and close satisfy the level rule; 0 when a hit fails it; null without a hit or without edges. */
+  levelValid: 0 | 1 | null;
+}
+
+export function scoreBreakout(
+  bars: readonly BarFrame[],
+  outputs: Outputs,
+  labels: CompressionBreakoutLabels,
+  filter: readonly boolean[] | null = null,
+  tolerance = 2,
+): Score {
+  const events = breakEventsOf(outputs).filter((event) => filter === null || filter[event.index]);
+  const b = labels.breakoutIndex;
+  const score: Score = { hit: 0, wrongDirection: 0, matched: 0, early: 0, earlyLead: 0, earlyCompression: 0, unmatched: 0, missed: 0, levelValid: null };
+  let first: BreakEvent | null = null;
+  for (const event of events) {
+    if (event.index >= b && event.index <= b + tolerance) {
+      score.matched += 1;
+      if (event.dir !== labels.direction) score.wrongDirection += 1;
+      if (first === null) first = event;
+    } else if (event.index < b) {
+      score.early += 1;
+      if (event.index < labels.compressionStart) score.earlyLead += 1;
+      else score.earlyCompression += 1;
+    } else {
+      score.unmatched += 1;
+    }
+  }
+  if (first === null) {
+    score.missed = 1;
+    return score;
+  }
+  if (first.dir === labels.direction) {
+    score.hit = 1;
+    const hi = outputs.activeHigh?.[first.index];
+    const lo = outputs.activeLow?.[first.index];
+    if (hi !== undefined && lo !== undefined && hi !== null && lo !== null) {
+      const close = bars[first.index].close;
+      const beyond = labels.direction > 0 ? close > hi : close < lo;
+      score.levelValid = hi <= labels.compressionHigh + 1e-9 && lo >= labels.compressionLow - 1e-9 && beyond ? 1 : 0;
+    }
+  }
+  return score;
+}
+
+export function addScores(total: Record<string, number>, score: Score): void {
+  for (const [key, value] of Object.entries(score)) {
+    if (value === null) continue;
+    total[key] = (total[key] ?? 0) + value;
+  }
+  if (score.levelValid !== null) total.levelChecked = (total.levelChecked ?? 0) + 1;
+}
+
+/** The labelled outcome: a break at `breakoutIndex` and the pulse at `outcomeIndex`. */
+export function outcomeHit(outputs: Outputs, breakoutIndex: number, outcomeIndex: number, key: "failed" | "heldOutside"): boolean {
+  const broke = (outputs.breakDir?.[breakoutIndex] ?? 0) !== 0;
+  const outcome = (outputs[key]?.[outcomeIndex] ?? 0) === 1;
+  return broke && outcome;
+}

+# Compression Breakout (20)
+
+[Handbook](../../README.md) · [Indicator index](README.md) ·
+[Data for indicator authors](data-for-indicator-authors.md) ·
+[Setting presets](setting-presets.md)
+
+Code: `apps/web/src/lib/indicators/compression-breakout/`
+(`compressionBreakout.ts` is the registry definition, `compressionBreakoutMath.ts`
+the pure state machine, `tests/` the evidence, including the test-only
+comparator defs). Registry id `compressionBreakout`, label "Compression
+Breakout (20)", category technical, overlay. The code wins over this page.
+
+## The question it answers
+
+"Did price leave an established compression range with activity behind the
+break bar, and did it come back inside?"
+
+A compression range is a committed 20-bar high/low range narrower than twice
+the mean true range of the 20 bars before it: price has stayed inside a band
+narrower than two of its recent bars. Its edges freeze the moment it opens.
+Once six later closed bars stayed inside, a close outside is a break, graded by
+what the break bar did (its true range and its volume against the preceding 20
+bars). A close back inside within five bars is a failed break; otherwise the
+break is "held outside 5 bars". Trend (MA 50 against MA 200) colours a border
+and one table row and never decides anything. Descriptive only: "range+vol"
+says both activity tests passed on the break bar, "held outside" says the
+failure window expired. Neither says anything about profit, and a return
+inside is a failure of this breakout rule, not evidence for fading it.
+
+## Calculation
+
+One bar at a time; `onBar` never rebuilds from an array. Three named states:
+`P`, the committed state before the current bar, kept untouched while that bar
+is the tail; `W`, the working view every evaluation reads (`P` plus the gap
+rule, never written); `C`, the committed state after the bar's first closed
+dispatch, which seeds the next `ts_open`.
+
+1. **Validity.** A bar's price is valid when open, high, low and close are
+   finite with `low ≤ open, close ≤ high`; its volume when finite and at least
+   zero. An invalid-price bar contributes nothing except one tick of the clock
+   (lifetime, failure window, hold countdown): no ring entry, no range change,
+   no age, no event, status `No usable price`. An invalid volume keeps the
+   price context; the bar enters no volume observation and its volume cannot
+   be tested (`vol n/a`). Missing bars contribute nothing. Means span valid
+   observations across gaps.
+2. **Rings of committed valid bars.** Highs and lows (20), true ranges (40),
+   volumes (20), closes (`trendSlow`), the fast MA's last six values. No
+   library stream drives an event: a never-closed bar left in one would change
+   range creation. True range uses the previous committed close; on the first
+   bar and on the first bar after a gap it is `high − low`, so an overnight
+   jump never enters a reference or a denominator.
+3. **Gap.** Below one-day bars, a `ts_open` more than one interval after the
+   last committed bar drops the active range on `W` (status `Gap · range
+   reset`); held ranges stay. Daily and weekly bars never reset on calendar
+   gaps. An invalid-price bar skips the reset with every other commit step.
+4. **Qualification.** The window of the last 20 committed highs and lows
+   qualifies when `width ≤ widthMultiple × mean true range of the 20 valid bars
+   before the window`. Readiness is 40 valid committed bars (zero-based index
+   39 at the earliest); `qualified` and the width ratio are `null` before.
+5. **Opening and establishment.** A range opens at the commit of a qualifying
+   bar with no active range and no event, with `age` 0 and its edges frozen
+   at the window's extremes. Each later committed bar whose close stays inside
+   adds one to `age`. A close outside before `age ≥ minCompressionBars` abandons
+   the range silently (nothing held, no event). The earliest eligible break at
+   defaults is index 46.
+6. **Break and grade.** Eligible and `close > hi` (or `< lo`): a break. The
+   denominators are the means of the preceding 20 valid true ranges and
+   volumes, available only when 20 exist and the mean is positive.
+   `gradeBasis` says which components could be tested on this bar
+   (denominator available and the bar's value valid): 0 none, 1 range, 2
+   volume, 3 both. `breakGrade`: 3 both passed (`range+vol`), 1 range only,
+   2 volume only, 0 none. The threshold is `confirmMultiple` (1.5) on both.
+7. **Outcome.** From the bar after the break: a close back inside the frozen
+   edges, or beyond the opposite edge, is a failure; otherwise, `failBars`
+   committed bars after the break (the last included, invalid bars counted)
+   the break is held outside. Either retires the range into the held list for
+   `holdBars` committed bars (`holdBars` 0 keeps nothing). No widening, no
+   re-arm: a new range must qualify and establish again. A range that never
+   breaks expires 500 committed bars after it opened and is held like a
+   held-outside one.
+8. **Order of a commit.** Held countdown first (a range at zero is freed, the
+   rest count down); then the rings; then the decision (break, failure, hold,
+   expiry, abandonment, pending or inside); then a new range may open; then
+   the clock advances.
+9. **Snapshot and corrections.** `readOutput` reads a snapshot taken after the
+   decision and before any retirement, so the edges are still reported on the
+   outcome bar and `pending` is 1 from the bar after the break through the
+   outcome bar. A forming revision evaluates against `P` only. A closed
+   re-dispatch of the tail recomputes `C` from `P`: a cancelled break, a
+   removed failure, a changed grade and a validity flip in either field are one
+   rule. A correction to an older bar reaches the indicator as a full replay.
+   A tail superseded without closing writes nothing; the hole it leaves is a
+   gap.
+10. **Trend.** `up` if the close is above the slow MA and the fast MA rose over
+    the last five committed bars; `down` on the mirror; `flat` otherwise;
+    unknown until `trendSlow + 5` valid closes, and off when `trendFast ≥
+    trendSlow`.
+
+### Outputs
+
+Line outputs `rangeHigh` and `rangeLow`: the snapshot edges whenever a range
+exists, forming included; a range's last point (its outcome or abandonment
+bar) is painted transparent so the line never joins one range to the next
+with a slope that never existed. Numeric seams for the harness and for later
+layers: `activeHigh`, `activeLow` (the same snapshot under the names the
+harness tests use), `heldCount`, `widthRatio`, `qualified`, `trend`, `rangeAge`, `pending`, and
+the event pulses `breakDir`, `breakGrade`, `gradeBasis`, `failed`,
+`heldOutside`, `expired`, non-zero on the event bar only. The L1 tape tally
+grades intensity on the `breakDir` bar; the L2 Break Defense Monitor watches
+displayed liquidity at the edges while the range is established.
+
+## What the trader sees

+## Controls
+
+Inputs: `Range length (bars)` 20 (10..50; the range needs twice this many bars
+before it can qualify), `Minimum bars inside` 6 (2..30), `Activity threshold
+(×)` 1.5 (1..3, step 0.1: one test passing gives a faded arrow, both a solid
+one). Advanced: `Width limit (× bar range)` 2 (1..4, step 0.5), `Failure window
+(bars)` 5, `Keep retired range (bars)` 40 (0..200), `Trend fast MA (bars)` 50
+(10..199), `Trend slow MA (bars)` 200 (20..400). Visibility: `Show break
+markers`, `Show ranges`. Every setting replays the retained bars when changed,
+the two visibility toggles included (markers and boxes need a replay to be
+rebuilt). No colour pickers in this version. Every key is in the schema, so
+presets work.
+
+## Alert conditions (rendered; no notification channel exists)
+
+**Break**: a close outside an established range with at least one activity
+test passed (`breakGrade ≥ 1`); arrow on the break bar. **Failed break**: a
+marked break whose price closed back inside within five bars; circle on that
+bar. Unconfirmed breaks (`breakGrade` 0) are table and box only. Measured on
+the controls at defaults: 0 markers per 1,000 bars on the ranging and the
+trending fixtures (see Evidence).
+
+## Historical Mode, replay and the retained history
+
+Policy `OHLCV_POLICY`: candles only, every archived instrument, equities
+included (no side is ever read; protocol check 9 is not applicable). Live and
+replay agree exactly for the same bars.
+
+What a reload can change (brief amendment 1): the chart keeps 10,080 one-minute
+bars, so a replay starts from the first retained bar. Every window is finite,
+but a range opened before the retained history exists live and not in the
+replay, and a continuously qualifying market reopens ranges at different
+phases. Outputs, events, markers and drawn ranges are therefore required equal
+from the first retained bar at which the live instance holds no active and no
+held range, once the 20 denominators and `trendSlow + 5` closes lie inside
+retention; before that bar the difference is the range phase, pinned in
+`tests/compressionBreakoutValidation.test.ts` on a 3,000-bar constant-width
+fixture rebuilt at offsets 0, 137 and 500 (the edges are identical on both
+sides, only age and expiry differ) and on a 1,400-bar coil rebuilt from index
+300 (both instances break at 740 with the same grade; their edges may differ
+before). After a reload a range older than the retained history is seen only
+from the first retained bar.
+
+## Limitations
+
+Descriptive, not predictive. Readiness: the range at 40 valid bars, grading
+at 20 valid bars, the trend at `trendSlow + 5`. The qualifier is a
+fixed-length range, not a volatility squeeze; the synthetic fixtures are
+monotone contractions that favour it, and the live run is where the two were
+compared (the squeeze qualifier stays a test-only variant; see the v2 clause
+in the brief). A failed break retires its range; a second break needs a fresh
+range. Ranges expire at 500 bars. Intraday equity ranges reset at the
+overnight gap (the session-open rule is deferred). Unit-free; no sided volume.

import type { BarFrame } from "../../../types/frames";

/**
 * Compression Range Breakout: the pure, incremental state machine.
 *
 * A committed `rangeLength`-bar high/low range qualifies when its width is at
 * most `widthMultiple` times the mean true range of the `rangeLength` valid
 * bars preceding that window. Its edges freeze the moment it opens. After
 * `minCompressionBars` committed bars whose close stayed inside, a close
 * outside is a break, graded by the break bar's true range and volume against
 * the preceding 20 valid observations. A close back inside (or beyond the
 * opposite edge) within `failBars` bars is a failure; otherwise the break is
 * "held outside". Failure, hold and a 500-bar lifetime retire the range; a
 * new one must qualify and establish again. No widening, no re-arm.
 *
 * Three named states (brief amendment 4): `P`, the committed state before the
 * tail bar, kept untouched for corrections of that tail; `W`, the working view
 * every evaluation reads (`P` plus the gap rule, never written); `C`, the
 * committed state after the tail's first closed dispatch, which seeds the next
 * `ts_open`. A forming revision evaluates against `P` only. A closed
 * re-dispatch of the tail recomputes `C` from `P`, so a cancelled break, a
 * removed failure, a changed grade and a validity flip in either field are all
 * one rule.
 *
 * Lifetime, the failure window and the hold countdown count committed
 * dispatched bars, invalid-price bars included (they skip every other commit
 * step); denominators count valid observations and carry no bar bound.
 *
 * No library stream drives an event: a never-closed bar left in a
 * `trading-signals` stream would change range creation. Every window here is a
 * finite ring of committed valid bars, so corrections and replays are exact.
 */

export function normalizedSettings(settings: CompressionBreakoutMathSettings): Required<CompressionBreakoutMathSettings> {

    Number.isFinite(value) ? Math.min(max, Math.max(min, value)) : fallback;

export function isPriceValid(bar: BarFrame): boolean {
  const { open, high, low, close } = bar;
  return (
    Number.isFinite(open) &&
    Number.isFinite(high) &&
    Number.isFinite(low) &&
    Number.isFinite(close) &&
    high >= low &&
    low <= close &&
    close <= high &&
    low <= open &&
    open <= high
  );
}

}

/** Mean of the last `count` entries; null when fewer exist. */
export function tailMean(values: readonly number[], count: number): number | null {
  if (count <= 0 || values.length < count) return null;
  let sum = 0;
  for (let index = values.length - count; index < values.length; index += 1) sum += values[index];
  const mean = sum / count;
  return Number.isFinite(mean) ? mean : null;
}

/** Mean of `values[from, to)`; null when the slice is not fully present. */
function sliceMean(values: readonly number[], from: number, to: number): number | null {
  if (from < 0 || to > values.length || to <= from) return null;
  let sum = 0;
  for (let index = from; index < to; index += 1) sum += values[index];
  const mean = sum / (to - from);
  return Number.isFinite(mean) ? mean : null;
}

function pushCapped(values: number[], value: number, capacity: number): void {
  values.push(value);
  if (values.length > capacity) values.splice(0, values.length - capacity);
}

/**
 * True range against the previous committed close; `high − low` on the first
 * bar and on the first bar after a gap. Null when the subtraction overflows:
 * such a bar enters no range observation and its range test is not taken.
 */
export function trueRangeOf(bar: BarFrame, prevClose: number | null, gap: boolean): number | null {
  const span = bar.high - bar.low;
  const value = prevClose === null || gap ? span : Math.max(span, Math.abs(bar.high - prevClose), Math.abs(bar.low - prevClose));
  return Number.isFinite(value) ? value : null;
}

/** A positive denominator from the last `DENOMINATOR_LENGTH` valid observations; null otherwise. */
export function denominatorOf(values: readonly number[]): number | null {
  const mean = tailMean(values, DENOMINATOR_LENGTH);
  return mean !== null && mean > 0 ? mean : null;
}

/** Population standard deviation of the last `count` values; null when fewer exist. */
function tailStdev(values: readonly number[], count: number, mean: number): number | null {
  if (values.length < count) return null;
  let sum = 0;
  for (let index = values.length - count; index < values.length; index += 1) sum += (values[index] - mean) ** 2;
  const stdev = Math.sqrt(sum / count);
  return Number.isFinite(stdev) ? stdev : null;
}

export interface Qualification {
  ready: boolean;
  qualified: boolean;
  widthRatio: number | null;
  hi: number;
  lo: number;
}

/**
 * The qualification of the window formed by the last `rangeLength` entries of
 * the given rings. On the committed rings this decides whether a range opens;
 * with the tail appended provisionally it feeds the status row only.
 */
export function qualificationOf(
  highs: readonly number[],
  lows: readonly number[],
  trs: readonly number[],
  closes: readonly number[],
  settings: Required<CompressionBreakoutMathSettings>,
): Qualification {
  const length = settings.rangeLength;
  const none: Qualification = { ready: false, qualified: false, widthRatio: null, hi: Number.NaN, lo: Number.NaN };
  if (highs.length < length || lows.length < length || trs.length < 2 * length) return none;
  let hi = -Infinity;
  let lo = Infinity;
  for (let index = highs.length - length; index < highs.length; index += 1) hi = Math.max(hi, highs[index]);
  for (let index = lows.length - length; index < lows.length; index += 1) lo = Math.min(lo, lows[index]);
  const width = hi - lo;
  if (!Number.isFinite(width)) return { ready: true, qualified: false, widthRatio: null, hi, lo };
  const reference = sliceMean(trs, trs.length - 2 * length, trs.length - length);
  const ratio = reference !== null && reference > 0 ? width / reference : null;
  const widthRatio = ratio !== null && Number.isFinite(ratio) ? ratio : null;
  if (settings.qualifier === "always") return { ready: true, qualified: true, widthRatio, hi, lo };
  if (settings.qualifier === "squeeze") {
    if (closes.length < length) return none;
    const mean = tailMean(closes, length);
    const stdev = mean === null ? null : tailStdev(closes, length, mean);
    const atr = tailMean(trs, length);
    const squeezed = mean !== null && stdev !== null && atr !== null && mean + 2 * stdev < mean + 1.5 * atr && mean - 2 * stdev > mean - 1.5 * atr;
    return { ready: true, qualified: squeezed, widthRatio, hi, lo };
  }
  return { ready: true, qualified: widthRatio !== null && widthRatio <= settings.widthMultiple, widthRatio, hi, lo };
}

export function createCompressionBreakoutEngine(input: CompressionBreakoutMathSettings): CompressionBreakoutEngine {
  const settings = normalizedSettings(input);
  const trCapacity = Math.max(2 * settings.rangeLength, DENOMINATOR_LENGTH);
  const closeCapacity = Math.max(settings.trendSlow, DENOMINATOR_LENGTH);
  const readinessCount = 2 * settings.rangeLength;
  let pre: CommittedState = createCommittedState();
  let committed: CommittedState = pre;
  let tailTsOpen: number | null = null;
  let current: Reading | null = null;

  function evaluate(P: CommittedState, bar: BarFrame): Reading {
    const priceValid = isPriceValid(bar);
    const volumeValid = isVolumeValid(bar.volume);
    const gapNow =
      P.lastCommittedTsOpen !== null &&
      Number.isFinite(bar.interval_ms) &&
      bar.interval_ms > 0 &&
      bar.interval_ms < DAY_MS &&
      bar.ts_open - P.lastCommittedTsOpen > bar.interval_ms;
    // A gap seen by an invalid-price bar is kept pending: that bar skips every commit step (amendment 5), and the
    // next valid-price bar performs the reset and takes `high − low` as its true range.
    const gap = gapNow || P.pendingGapReset;
    // W: P with the gap rule applied, never written.
    const active = gap && priceValid ? null : P.active;
    const trueRange = priceValid ? trueRangeOf(bar, P.prevClose, gap) : null;
    const avgRange = denominatorOf(P.trs);
    const avgVolume = denominatorOf(P.volumes);
    const rangeTestable = avgRange !== null && trueRange !== null;
    const volumeTestable = avgVolume !== null && volumeValid;
    const gradeBasis = ((rangeTestable ? 1 : 0) + (volumeTestable ? 2 : 0)) as GradeBasis;

    // Provisional qualification: the window of rangeLength − 1 committed bars plus the tail.
    let qualified: boolean | null = null;
    let widthRatio: number | null = null;
    if (priceValid && P.highs.length >= settings.rangeLength - 1 && P.trs.length >= 2 * settings.rangeLength - 1) {
      const provisional = qualificationOf(
        [...P.highs, bar.high],
        [...P.lows, bar.low],
        [...P.trs, trueRange as number],
        [...P.closes, bar.close],
        settings,
      );
      if (provisional.ready) {
        qualified = provisional.qualified;
        widthRatio = provisional.widthRatio;
      }
    }

    // Trend, from committed closes only; the tail's close is compared with them.
    let trendStatus: TrendStatus = "warming";
    let trend: -1 | 0 | 1 | null = null;
    if (settings.trendFast >= settings.trendSlow) {
      trendStatus = "fastGeSlow";
    } else if (P.validCount >= settings.trendSlow + 5 && P.closes.length >= settings.trendSlow && P.fastHistory.length >= SLOPE_HISTORY) {
      trendStatus = "ready";
      if (priceValid) {
        const slowMa = tailMean(P.closes, settings.trendSlow);
        const slope = P.fastHistory[P.fastHistory.length - 1] - P.fastHistory[0];
        if (slowMa !== null && Number.isFinite(slope)) trend = bar.close > slowMa && slope > 0 ? 1 : bar.close < slowMa && slope < 0 ? -1 : 0;
      }
    }

    // Decision, exactly one per bar, read against W.
    const index = P.committedIndex;
    let decision: Decision = { kind: "none", dir: 0, grade: 0, basis: gradeBasis, rangePassed: false, volumePassed: false };
    if (!priceValid) {
      decision = { ...decision, kind: "invalidPrice" };
    } else if (active !== null && active.broken !== null) {
      const inside = bar.close <= active.hi && bar.close >= active.lo;
      const opposite = active.broken.dir > 0 ? bar.close < active.lo : bar.close > active.hi;
      if (inside || opposite) decision = { ...decision, kind: "failed", dir: active.broken.dir, grade: active.broken.grade, basis: active.broken.basis };
      else if (index - active.broken.index >= settings.failBars)
        decision = { ...decision, kind: "heldOutside", dir: active.broken.dir, grade: active.broken.grade, basis: active.broken.basis };
      else decision = { ...decision, kind: "pending", dir: active.broken.dir, grade: active.broken.grade, basis: active.broken.basis };
    } else if (active !== null) {
      const dir: Direction | 0 = bar.close > active.hi ? 1 : bar.close < active.lo ? -1 : 0;
      if (dir !== 0) {
        if (active.age >= settings.minCompressionBars) {
          const rangePassed = rangeTestable && (trueRange as number) >= settings.confirmMultiple * (avgRange as number);
          const volumePassed = volumeTestable && bar.volume >= settings.confirmMultiple * (avgVolume as number);
          const grade: BreakGrade = rangePassed && volumePassed ? 3 : rangePassed ? 1 : volumePassed ? 2 : 0;
          decision = { kind: "break", dir, grade, basis: gradeBasis, rangePassed, volumePassed };
        } else {
          decision = { ...decision, kind: "abandoned", dir };
        }
      } else if (index - active.openedAt >= RANGE_LIFETIME) {
        decision = { ...decision, kind: "expired" };
      }
    }

    // Readiness counts committed valid-price bars plus this bar when its price is valid; the rings themselves are capped.
    const validThroughThisBar = P.validCount + (priceValid ? 1 : 0);
    return {
      tsOpen: bar.ts_open,
      intervalMs: bar.interval_ms,
      confirmed: bar.closed === true,
      priceValid,
      volumeValid,
      gap,
      trueRange,
      warmupCount: Math.min(validThroughThisBar, readinessCount),
      warmupNeeded: readinessCount,
      rangeReady: validThroughThisBar >= readinessCount,
      active,
      rangeHigh: active?.hi ?? null,
      rangeLow: active?.lo ?? null,
      rangeAge: active?.age ?? null,
      pending: active !== null && active.broken !== null ? 1 : 0,
      pendingBars: active !== null && active.broken !== null ? index - active.broken.index : 0,
      qualified,
      widthRatio,
      trend,
      trendStatus,
      closesCount: Math.min(P.validCount, settings.trendSlow + 5),
      avgRange,
      avgVolume,
      gradeBasis,
      decision,
      held: P.held,
      lastEvent: P.lastEvent,
    };
  }

  /** The commit of the tail's first closed dispatch: `C` from `P`, in the brief's order. */
  function commit(P: CommittedState, bar: BarFrame, reading: Reading): CommittedState {
    const C = cloneState(P);
    const index = P.committedIndex;
    // (a) held countdown: free the ones that reached zero at the previous commit, then count the rest down.
    C.held = C.held.filter((range) => range.remaining > 0).map((range) => ({ ...range, remaining: range.remaining - 1 }));
    if (!reading.priceValid) {
      // The clock advances below; a gap this bar saw waits for the next valid-price commit.
      C.pendingGapReset = P.pendingGapReset || reading.gap;
    } else {
      if (reading.gap) C.active = null;
      C.pendingGapReset = false;
      // (b) rings: only finite derived observations enter them.
      pushCapped(C.highs, bar.high, settings.rangeLength);
      pushCapped(C.lows, bar.low, settings.rangeLength);
      pushCapped(C.closes, bar.close, closeCapacity);
      if (reading.trueRange !== null) pushCapped(C.trs, reading.trueRange, trCapacity);
      if (reading.volumeValid) pushCapped(C.volumes, bar.volume, DENOMINATOR_LENGTH);
      const fastMa = tailMean(C.closes, settings.trendFast);
      if (fastMa !== null) pushCapped(C.fastHistory, fastMa, SLOPE_HISTORY);
      // (c) the decision
      const decision = reading.decision;
      const active = C.active;
      if (active !== null) {
        switch (decision.kind) {
          case "break":
            active.broken = { index, tsOpen: bar.ts_open, dir: decision.dir as Direction, grade: decision.grade, basis: decision.basis };
            active.excursionHi = bar.high;
            active.excursionLo = bar.low;
            C.lastEvent = { kind: "break", index, tsOpen: bar.ts_open, dir: decision.dir as Direction, grade: decision.grade, basis: decision.basis };
            break;
          case "failed":
          case "heldOutside":
          case "expired": {
            const dir = (active.broken?.dir ?? (bar.close >= active.hi ? 1 : -1)) as Direction;
            C.lastEvent = { kind: decision.kind, index, tsOpen: bar.ts_open, dir, grade: active.broken?.grade ?? 0, basis: active.broken?.basis ?? 0 };
            retire(C, active, decision.kind, bar.ts_open);
            C.active = null;
            break;
          }
          case "abandoned":
            C.active = null;
            break;
          case "pending":
            active.excursionHi = Math.max(active.excursionHi, bar.high);
            active.excursionLo = Math.min(active.excursionLo, bar.low);
            active.age += 1;
            break;
          case "none":
            active.age += 1;
            break;
          default:
            break;
        }
      }
      // (d) a new range opens only on a bar with no event, from the committed rings.
      if (C.active === null && decision.kind === "none") {
        const qualification = qualificationOf(C.highs, C.lows, C.trs, C.closes, settings);
        if (qualification.ready && qualification.qualified) {
          C.active = {
            hi: qualification.hi,
            lo: qualification.lo,
            openedAt: index,
            openedTs: bar.ts_open,
            age: 0,
            widthRatio: qualification.widthRatio,
            broken: null,
            excursionHi: qualification.hi,
            excursionLo: qualification.lo,
          };
        }
      }
      C.prevClose = bar.close;
      C.validCount += 1;
    }
    // (e) every committed dispatched bar advances the clock, valid or not.
    C.lastCommittedTsOpen = bar.ts_open;
    C.committedIndex = index + 1;
    return C;
  }

  function retire(C: CommittedState, range: ActiveRange, outcome: Outcome, closedTs: number): void {
    const held: HeldRange = { hi: range.hi, lo: range.lo, openedTs: range.openedTs, closedTs, outcome, remaining: settings.holdBars };
    C.held.push(held);
    // One active handle and seven held ones: the oldest held range gives way to a new one.
    if (C.held.length > MAX_HELD_RANGES) C.held.splice(0, C.held.length - MAX_HELD_RANGES);
  }

  function onBar(bar: BarFrame): Reading {
    if (tailTsOpen !== null && bar.ts_open < tailTsOpen) {
      // Older than the tail: the runtime replays those as a REBUILT; here it is ignored.
      return current ?? evaluate(pre, bar);
    }
    if (tailTsOpen === null || bar.ts_open > tailTsOpen) {
      // A new ts_open: C seeds P; a tail superseded without closing wrote nothing.
      pre = committed;
      tailTsOpen = bar.ts_open;
    }
    const reading = evaluate(pre, bar);
    if (bar.closed === true) {
      committed = commit(pre, bar, reading);
      reading.held = committed.held;
      reading.lastEvent = committed.lastEvent;
    } else {
      committed = pre;
    }
    current = reading;
    return reading;
  }

  return {
    settings,
    onBar,
    get current() {
      return current;
    },
    get pre() {
      return pre;
    },
    get committed() {
      return committed;
    },
  };
}
