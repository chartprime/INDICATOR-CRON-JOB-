## 3. Polling design per family

**Trades (`/api/v3/aggTrades`, weight 4).** The WS path emits one envelope per `@trade` message (`binance-connection.js:76`), normalized from keys `t,p,q,T,m` (`normalizer :21, :42, :318-325`, event time `T` :297), and downstream derives side as `isBuyerMaker ? "sell" : "buy"` (`frames.js:163`, `l2-memory/live-binding.js:52`) and dedupes by `trade_id` (`server/history.js:206-214`). Pager: on subscribe, `GET aggTrades?symbol&limit=1` sets `cursor = a`. Each tick: `GET aggTrades?symbol&fromId=cursor+1&limit=1000`; while a page is full, fetch the next at once (cap 5 pages per tick, then `feedHealth.beginRecovery(TRADE)` and continue next tick, never drop). Aggregate ids are contiguous: a row with `a <= cursor` is dropped as a duplicate; a jump is telemetry `market_data.binance_rest.trade_id_gap`, never filled. Each row becomes raw `{e:"trade", E: receivedAtMs, s, t: a, p, q, T, m, M}` for `normalizeBinanceEvent`: `payload.tradeId` is the aggregate id, `eventTime` the exchange time `T`, emission order `a` ascending.

**Bars (`/api/v3/klines`, weight 1 for limit ≤ 100).** Today 1m bars come from the `@kline_1m` stream, not from trades (`market-data-server.js:119, :1248-1249`; `klineEnvelopeToFrame` `frames.js:168-210`, closed from `k.x`); backfill uses REST rows (`restKlineRowToBarFrame` `frames.js:212-263`). Each tick: `GET klines?symbol&interval=1m&startTime=<previous minute open>&limit=2`. Row 0 is emitted `x:true` once per `openTime`, only after `closeTime < receivedAtMs`; row 1 `x:false` whenever `c,v,n` changed. Raw: `{e:"kline", E: receivedAtMs, s, k:{t,T,s,i:"1m",o,c,h,l,v,n,x,q,V,Q}}`; `f`,`L`,`B` are optional (`normalizer :24, :48-64`). `fetchRecentKlines` delegates to the existing backfill.

**Depth (`/api/v3/depth?limit=1000`, weight 50) as periodic snapshots.** The assembler needs a snapshot and then a bridging diff: `applySnapshotStatus` sets `needsBridgeCheck = true` (`binance-book-assembler.js:352`) and `getStatus` stays `BUFFERING` until a diff with `U <= lastUpdateId+1` arrives (:85-105, :264-288, :381-398). A snapshot-only feed never leaves BUFFERING, so add one explicit method, `applyStandaloneSnapshotStatus(body)`: the same validation (`snapshotDepthBody` :27-43, crossed book :339-344, level cap), then `needsBridgeCheck = false`, `localUpdateId = body.lastUpdateId`, buffer cleared. No synthetic update ids. The transport keeps one real assembler per pair and feeds it every poll, so `getOrderBook` returns a READY book whose `lastUpdateId` is the snapshot's own id (`emitBook` fingerprints on it, `market-data-server.js:963-968`).

For the L2 engine the transport emits one DEPTH envelope per snapshot: `firstUpdateId = lastUpdateId = snapshot.lastUpdateId`, `previousUpdateId: null` (SPOT, `normalizer :364-367`, `assembler :69-71`) and `bids`/`asks` = the observed level changes between the previous and current snapshot, computed only inside the price window both snapshots cover (bids `>= max(oldLowestBid, newLowestBid)`, asks mirrored); a vanished level is reported with quantity `"0"` as Binance does; levels that merely left the 1000-level window are not reported. `live-binding.js:44-47` makes a `book` frame whose `delta` is those changes; `memory-engine.js:201-250` applies it as a diff while `live`, seeds on the first READY book (:131-141), resyncs after a gap (:143-158), and `coverageOf` (:106-114) reads the real edge of the 1000-level book. A failed poll emits nothing; `429/418` or three consecutive failures mark DEPTH recovering, the `gateBookState` equivalent returns `UNAVAILABLE: RECOVERY_IN_PROGRESS` and `live-binding.js:45` sends a `gap` frame, as a WS sequence gap does (`binance-connection.js:1377-1390`). The periodic and shadow refreshes (:65, :867-886, :1580-1641) do not apply.

## 4. Honesty

- `getStatus()` reports `SPOT.public` `CONNECTED` only after a successful `exchangeInfo?symbol=BTCUSDT` probe (weight 20, `fetchExchangeInfo` :303-319), `DISCONNECTED` after three consecutive failures; PERPETUAL routes stay `DISCONNECTED`, so a perpetual `subscribeMany` throws today's "route is connected" error (`binance-connection.js:1004-1016`) and `requestSwitch` parks the selection (`market-data-server.js:3496-3508`).
- `getFeedHealth()` returns the feed-health context plus `transport: "rest"`, `pollMs`, `lastPollLatencyMs` and `reason`: `REST_POLL` while READY, `REST_RATE_LIMITED`, `REST_POLL_FAILED`, `REST_BACKOFF_<ms>` while degraded. `market-data-server.js:845-856` passes the worst context's `reason` to `healthFrame` (`frames.js:663-694` accepts a reason with READY, limit 256 chars :28); the browser already prints it (`apps/web/src/components/chart/MainPanel.tsx:2436`). The health fingerprint includes it (`market-data-server.js:944`), so every change is broadcast.
- Staleness keeps today's thresholds (`binance-feed-health.js:7-12`: TRADE 30 s, KLINE 10 s, DEPTH 5 s). A successful empty trade poll is a real observation and records `recordEvent(TRADE)`; a failed poll records nothing, so silence becomes `stale: true` as with a dead stream. No envelope is ever emitted without a row.
- Backoff: on `RATE_LIMITED` (`binance-http-client.js:231-234` parses `Retry-After`) every family of every pair pauses until the later of `Retry-After` and exponential backoff (1 s base, 30 s cap, 20% jitter, as `binance-connection.js:47-49, :1704-1740`), with `beginRecovery` on all families and telemetry `market_data.binance_rest.backoff`. A `418` (IP ban) waits the full `Retry-After` and sets `DISCONNECTED`.
- Weight accounting: every response's `x-mbx-used-weight-1m` (already in `result.value.headers`) is authoritative; the budget module also projects per calendar minute: aggTrades 4 per page, klines 1, depth 50 (limit 1000), exchangeInfo 20, kline backfill 5 per 1000-row page. With one pair at `pollMs=1000`: 60·(4+1) + 60·50 = 3300/min ≤ 4000, so depth polls every tick. The scheduler stretches the depth cadence first (to the smallest multiple of `pollMs` that fits), then klines, never trades; two pairs: 600 + 3000 (depth every 2 s) = 3600. If the header reaches the budget, all polling stops until the minute boundary; the hard limit 6000 is never approached (margin ≥ 2000).

## 5. Proxy support

The REST client is Node's built-in `fetch` (`binance-http-client.js:208-211`, `fetchImpl = globalThis.fetch` :253; `binance-connection.js:116`), not `undici` or `https`; `redirect: "error"`, 5 s timeout, 2 MB cap. It ignores `HTTPS_PROXY` unless `NODE_USE_ENV_PROXY=1` (Node ≥ 22.21; the repo pins 24.21.0, `package.json:6-7`). CA: Node reads `NODE_EXTRA_CA_CERTS`, which this container sets beside `SSL_CERT_FILE` (Node ignores the latter). No code change: document both in `09-configuration.md` and `03-server-runbook.md`; on the owner's machine neither is set and nothing changes. `ws` never honoured a proxy.

## 8. Risks and what is not supported

- Not supported: perpetuals (no mirror; routes stay DISCONNECTED); sub-second latency (trades arrive up to `pollMs` plus round trip late; the engine's late-trade rule, `memory-engine.js:83-94`, keeps order); order-book diffs (a 1000-level snapshot at most once per tick; iceberg and exhaustion engines see coarser deltas, to be documented as degraded on REST); bookTicker; switching transport at runtime (aggregate and raw trade ids differ).
- Risks: endpoint weights may change (the header is authoritative, the ledger a projection); the mirror's lag behind the primary is undocumented (measure `T` versus `receivedAt` in the acceptance run); a 1000-level book is shallower than the 5000-level WS snapshot, so lane-0 heatmap coverage (±5%) may be partial on volatile days, with `coverageOf` marking the real edge.

+ * time (plus a grace) has passed on the exchange is final and is emitted
+ * closed exactly once; any other row is the forming bar, emitted as a
+ * revision whenever its values changed. A response from an older poll never
+ * overwrites a newer one.
+ */
+function createBinanceRestBarCursor({ intervalMs, finalizeGraceMs = DEFAULT_FINALIZE_GRACE_MS } = {}) {
+  if (!Number.isSafeInteger(intervalMs) || intervalMs <= 0) throw new Error("intervalMs must be a positive safe integer");
+  if (!Number.isSafeInteger(finalizeGraceMs) || finalizeGraceMs < 0) throw new Error("finalizeGraceMs must be a non-negative safe integer");
+
+  let confirmedOpenTime = null;
+  let lastSeq = 0;
+  let holes = 0;
+  const forming = new Map();
+
+  function currentOpen(exchangeNowMs) {
+    return Math.floor(exchangeNowMs / intervalMs) * intervalMs;
+  }
+
+  /** After an outage the previous closed bar lies more than one bar past the last confirmed close. */
+  function needsCatchUp(exchangeNowMs) {
+    return confirmedOpenTime !== null && currentOpen(exchangeNowMs) - intervalMs > confirmedOpenTime + intervalMs;
+  }
+
+  function nextRequest(exchangeNowMs) {
+    if (needsCatchUp(exchangeNowMs)) {
+      return Object.freeze({ startTime: confirmedOpenTime + intervalMs, limit: MAX_KLINES_PER_REQUEST, catchUp: true });
+    }
+    return Object.freeze({ startTime: currentOpen(exchangeNowMs) - intervalMs, limit: TWO_ROW_POLL_LIMIT, catchUp: false });
+  }
+
+  function signatureOf(row) {
+    return `${row.open}|${row.high}|${row.low}|${row.close}|${row.volume}|${row.numberOfTrades}|${row.takerBuyBaseVolume}`;
+  }
+
+  /** `rows` are parsed kline rows ascending by open time (parseKlineRows); `seq` orders the polls that produced them. */
+  function apply({ rows, exchangeNowMs, seq }) {
+    if (!Number.isSafeInteger(seq) || seq <= lastSeq) {
+      return Object.freeze({ stale: true, emit: Object.freeze([]), hole: false, catchingUp: needsCatchUp(exchangeNowMs) });
+    }
+    lastSeq = seq;
+    const emit = [];
+    let hole = false;
+    for (const row of rows) {
+      if (confirmedOpenTime !== null && row.openTime <= confirmedOpenTime) continue;
+      const closed = row.closeTime + finalizeGraceMs <= exchangeNowMs;
+      if (closed) {
+        if (confirmedOpenTime !== null && row.openTime > confirmedOpenTime + intervalMs) {
+          hole = true;
+          holes += 1;
+        }
+        emit.push(Object.freeze({ row, closed: true }));
+        confirmedOpenTime = row.openTime;
+        forming.delete(row.openTime);
+        continue;
+      }
+      const signature = signatureOf(row);
+      if (forming.get(row.openTime) === signature) continue;
+      forming.set(row.openTime, signature);
+      emit.push(Object.freeze({ row, closed: false }));
+    }
+    for (const openTime of forming.keys()) {
+      if (confirmedOpenTime !== null && openTime <= confirmedOpenTime) forming.delete(openTime);
+    }
+    return Object.freeze({ stale: false, emit: Object.freeze(emit), hole, catchingUp: needsCatchUp(exchangeNowMs) });
+  }
+
+  function reset() {
+    confirmedOpenTime = null;
+    forming.clear();
+  }
+
+  return Object.freeze({
+    nextRequest,
+    needsCatchUp,
+    apply,
+    reset,
+    get confirmedOpenTime() { return confirmedOpenTime; },
+    get stats() { return Object.freeze({ confirmedOpenTime, holes, lastSeq }); },
+  });
+}

+// Binance's spot REST limit is REQUEST_WEIGHT 6000 per minute per IP, counted
+// by the exchange and reported back in every response's x-mbx-used-weight-1m
+// header. The REST transport reserves each request's weight here before it is
+// sent, against a budget that leaves at least 1000 of margin, and raises its
+// own count to whatever the exchange reports, so it never has to be told off.
+const REQUEST_WEIGHTS = Object.freeze({
+  KLINES: 2,
+  EXCHANGE_INFO: 20,
+  SERVER_TIME: 1,
+});
+const EXCHANGE_WEIGHT_LIMIT_PER_MINUTE = 6000;
+const DEFAULT_WEIGHT_BUDGET_PER_MINUTE = 4000;
+const MAX_WEIGHT_BUDGET_PER_MINUTE = 5000;
+const MIN_WEIGHT_BUDGET_PER_MINUTE = 100;
+const MINUTE_MS = 60_000;
+const USED_WEIGHT_HEADER = "x-mbx-used-weight-1m";
+// The share of the budget the steady cadence may plan on; the rest is kept
+// for the connect probe, the clock refresh, catch-up pages and the candle
+// backfill.
+const PLANNED_SHARE = 0.9;
+const MAX_CADENCE_STRETCH = 60;
+

+  if (
+    !Number.isSafeInteger(budgetPerMinute) ||
+    budgetPerMinute < MIN_WEIGHT_BUDGET_PER_MINUTE ||
+    budgetPerMinute > MAX_WEIGHT_BUDGET_PER_MINUTE
+  ) {
+    throw new Error(
+      `weight budget must be a whole number between ${MIN_WEIGHT_BUDGET_PER_MINUTE} and ${MAX_WEIGHT_BUDGET_PER_MINUTE} per minute`,
+    );
+  }

+function usedWeightFromHeaders(headers) {
+  if (headers === null || typeof headers !== "object") return null;
+  const entry = Object.entries(headers).find(([key]) => key.toLowerCase() === USED_WEIGHT_HEADER);
+  if (!entry || typeof entry[1] !== "string" || !/^\d+$/.test(entry[1].trim())) return null;
+  const value = Number.parseInt(entry[1].trim(), 10);
+  return Number.isSafeInteger(value) ? value : null;
+}

+function createBinanceRestWeightBudget({ budgetPerMinute = DEFAULT_WEIGHT_BUDGET_PER_MINUTE, now = () => Date.now() } = {}) {
+  assertBudget(budgetPerMinute);
+  if (typeof now !== "function") throw new Error("now must be a function");
+
+  let minuteStart = Math.floor(now() / MINUTE_MS) * MINUTE_MS;
+  let reserved = 0;
+  let observed = 0;
+  let deferrals = 0;
+  let reservations = 0;
+
+  function rollMinute() {
+    const current = Math.floor(now() / MINUTE_MS) * MINUTE_MS;
+    if (current !== minuteStart) {
+      minuteStart = current;
+      reserved = 0;
+      observed = 0;
+    }
+  }
+
+  function used() {
+    rollMinute();
+    return Math.max(reserved, observed);
+  }
+
+  /** Reserves `weight` for a request about to be sent; false means wait for the next minute. */
+  function reserve(weight) {
+    if (!Number.isSafeInteger(weight) || weight <= 0) throw new Error("weight must be a positive safe integer");
+    rollMinute();
+    if (Math.max(reserved, observed) + weight > budgetPerMinute) {
+      deferrals += 1;
+      return false;
+    }
+    reserved += weight;
+    reservations += 1;
+    return true;
+  }
+
+  /** Raises this minute's count to what the exchange reports in a response's headers. */
+  function observe(headers) {
+    const value = usedWeightFromHeaders(headers);
+    if (value === null) return null;
+    rollMinute();
+    if (value > observed) observed = value;
+    return value;
+  }
+
+  function msUntilReset() {
+    const at = now();
+    return Math.max(1, minuteStart + MINUTE_MS - at);
+  }
+
+  function stats() {
+    rollMinute();
+    return Object.freeze({
+      budgetPerMinute,
+      minuteStart,
+      reserved,
+      observed,
+      used: Math.max(reserved, observed),
+      remaining: Math.max(0, budgetPerMinute - Math.max(reserved, observed)),
+      reservations,
+      deferrals,
+    });
+  }
+
+  return Object.freeze({ reserve, observe, used, msUntilReset, stats, get budgetPerMinute() { return budgetPerMinute; } });

+/**
+ * The steady candle cadence that fits the budget: the poll interval, lengthened
+ * in whole multiples until the planned share holds. The caller says so in the
+ * health reason when it was lengthened. The budget is never exceeded to keep a
+ * cadence.
+ */
+function planCadence({ klinePollers, pollMs, budgetPerMinute }) {
+  assertBudget(budgetPerMinute);
+  if (!Number.isSafeInteger(pollMs) || pollMs <= 0) throw new Error("pollMs must be a positive safe integer");
+  if (!Number.isSafeInteger(klinePollers) || klinePollers < 0) throw new Error("klinePollers must be a non-negative safe integer");
+  const target = Math.floor(budgetPerMinute * PLANNED_SHARE);
+  const cost = (cadenceMs) => klinePollers * Math.ceil(MINUTE_MS / cadenceMs) * REQUEST_WEIGHTS.KLINES + REQUEST_WEIGHTS.SERVER_TIME;
+  let klineCadenceMs = pollMs;
+  let stretched = false;
+  for (let multiple = 2; cost(klineCadenceMs) > target && multiple <= MAX_CADENCE_STRETCH; multiple += 1) {
+    klineCadenceMs = pollMs * multiple;
+    stretched = true;
+  }
+  return Object.freeze({
+    klineCadenceMs,
+    stretched,
+    projectedPerMinute: cost(klineCadenceMs),
+    fits: cost(klineCadenceMs) <= target,
+  });
+}

+function fakeBinance() {
+  const state = {
+    serverTimeOffsetMs: 0,
+    usedWeight: 10,
+    klineStart: OPEN - 10 * MINUTE,
+    rowFor: () => ({}),
+    failures: [],
+    hang: null,
+    pending: [],
+  };
+  const requests = [];
+  function respond(body, status = 200, headers = {}) {
+    return new Response(JSON.stringify(body), { status, headers: { "x-mbx-used-weight-1m": String(state.usedWeight), ...headers } });
+  }
+  function currentOpen() {
+    return Math.floor((Date.now() + state.serverTimeOffsetMs) / MINUTE) * MINUTE;
+  }
+  const fetchImpl = jest.fn(async (url, init) => {
+    const u = new URL(url);
+    requests.push(u);
+    const failure = state.failures.find((entry) => entry.match(u) && entry.times > 0);
+    if (failure) {
+      failure.times -= 1;
+      if (failure.network) throw new TypeError("fetch failed");
+      return respond(failure.body ?? {}, failure.status, failure.headers ?? {});
+    }
+    if (state.hang && state.hang(u)) {
+      return new Promise((resolve, reject) => {
+        init.signal.addEventListener("abort", () => {
+          const error = new Error("aborted");
+          error.name = "AbortError";
+          reject(error);
+        });
+        state.pending.push((body) => resolve(respond(body)));
+      });
+    }
+    switch (u.pathname) {
+      case "/api/v3/exchangeInfo":
+        return respond({ serverTime: Date.now() + state.serverTimeOffsetMs, symbols: [] });
+      case "/api/v3/time":
+        return respond({ serverTime: Date.now() + state.serverTimeOffsetMs });
+      case "/api/v3/klines": {
+        const startTime = Number(u.searchParams.get("startTime"));
+        const limit = Number(u.searchParams.get("limit"));
+        const rows = [];
+        for (let openTime = Math.max(startTime, state.klineStart); openTime <= currentOpen() && rows.length < limit; openTime += MINUTE) {
+          rows.push(klineRow(openTime, state.rowFor(openTime)));
+        }
+        return respond(rows);
+      }
+      default:
+        return respond({}, 404);
+    }
+  });
+  return {
+    fetchImpl,
+    requests,
+    state,
+    pathsRequested: () => requests.map((u) => u.pathname),
+    klineRequests: () => requests.filter((u) => u.pathname === "/api/v3/klines"),
+  };

+### Binance REST transport (`TT_BINANCE_TRANSPORT=rest`)
+
+For a host that cannot open a WebSocket (a cloud container whose proxy refuses
+upgrades, a region Binance's primary API blocks). Spot only; set
+`TT_BINANCE_SPOT_REST_BASE_URL=https://data-api.binance.vision` beside it when
+`api.binance.com` is blocked. Nothing changes while the setting is absent.
+
+**What it serves: 1m candles**, from `/api/v3/klines`, each with open, high,
+low, close, volume, taker-buy volume (the sided candle flow) and trade count,
+forming and closed. Every `TT_BINANCE_REST_POLL_MS` the previous and the
+forming bar are read. Every row is classified by its own open and close time
+against the exchange clock, never by its position or by the machine clock: a
+bar is final one second after its close time has passed on the exchange and is
+emitted closed exactly once; the forming bar is re-sent only when one of its
+seven fields changed; a response from an older poll never overwrites a newer
+one. The exchange clock comes from the `exchangeInfo` probe that brings the
+route up (`serverTime`) and is re-read from `/api/v3/time` once a minute; a
+failed refresh keeps the last offset. After an outage of more than one bar the
+poller catches up from the last confirmed close, in pages of up to 1000 candles,
+at most 10 pages back to back before it yields for one cadence and continues;
+the health reason reads `catching up` until it is current.
+
+**What it does not serve.** There is no tape and no order book. No trade frame
+is sent; the book is `UNAVAILABLE` with reason `REST_NO_DEPTH`. Unavailable:
+time and sales, Large Trade Bubbles and large-trade markers, aggressive-print
+clusters, every `ctx.ticks` and `ctx.trades` indicator (VWAP bands on prints,
+tick intensity), VPIN, the DOM, the Passive Liquidity heatmap and its walls,
+the L2 memory indicators (liquidity voids, L2 feed status), the Iceberg
+Detector, Exhaustion, Initiative Continuation, the `l2_*` channels and
+`bandHistory`. Works: candles and every resampled timeframe, `buy_volume` and
+`sell_volume` from taker-buy volume (`barSides`), `trade_count`, the candle
+backfill and Historical Mode candles, and every candle-only indicator (RSI,
+relative volume, structure, volatility, candle flow).
+
+**Health.** The feed's reason reads `Polled spot candles · no tape · no order
+book`, with `· rate limited` (a 429 or an IP ban: polling paused for
+`Retry-After`), `· poll failed` (the last poll failed or the route is down),
+`· catching up` or `· slow polling (weight budget)` appended while they apply.
+The health frame's state follows the candle feed; the tape and depth feeds
+are reported unavailable and do not change that state. `/health` reports
+`delivery.transport: "rest"`, the cadence, the weight used and the exchange
+clock offset.
+
+**Weight.** The guarantee is this runtime's reserved dispatch budget: every
+request reserves its weight before it is sent (klines 2, `exchangeInfo` 20 for
+the connect probe, `time` 1, candle backfill 2 per page), against
+`TT_BINANCE_REST_WEIGHT_BUDGET` per calendar minute (default 4000, at most
+5000; the exchange limit is 6000). The exchange's own `x-mbx-used-weight-1m`
+raises the count when it is higher. The steady cadence plans on 90 % of the
+budget and is lengthened in whole multiples of the poll interval when the
+pairs would not fit; the reason then says `slow polling`. The budget is never
+exceeded to keep a cadence. One pair at 1 s costs about 121 of 4000 per minute.
+
+**Proxy.** Node's built-in `fetch` ignores `HTTPS_PROXY` unless
+`NODE_USE_ENV_PROXY=1` is set (Node 22.21 and later; the project pins 24.21.0).
+A custom CA is read from `NODE_EXTRA_CA_CERTS`, not from `SSL_CERT_FILE`. The
+stream transport (`ws`) never used a proxy and still does not.

   165	  // Wraps fetch for the candle backfill: each page's weight is reserved first
   166	  // and the exchange's own count is read back from the response.
   167	  async function meteredFetch(url, init) {
   168	    while (!budget.reserve(REQUEST_WEIGHTS.KLINES)) {
   169	      counters.budgetDeferrals += 1;
   170	      await new Promise((resolve) => {
   171	        const timer = setTimeout(resolve, budget.msUntilReset());
   172	        timer.unref?.();
   173	      });
   174	    }
   175	    const response = await Reflect.apply(fetchImpl, undefined, [url, init]);
   176	    try {
   177	      budget.observe(Object.fromEntries(response.headers.entries()));
   178	    } catch {
   179	      void 0;
   180	    }
   181	    return response;
   182	  }

   184	  function setRouteState(next, fields = {}) {
   185	    if (routeState === next) return;
   186	    routeState = next;
   187	    if (next === "CONNECTED") feedHealth.recordRouteConnected(MARKET_KINDS.SPOT, ROUTE_NAME);
   188	    else feedHealth.recordRouteDisconnected(MARKET_KINDS.SPOT, ROUTE_NAME);
   189	    telemetryEvent(next === "CONNECTED" ? "route_connected" : "route_disconnected", { state: next, ...fields });

   192	  function backoffDelayMs(attempt) {
   193	    const raw = Math.min(BACKOFF_BASE_DELAY_MS * 2 ** Math.max(0, attempt - 1), BACKOFF_MAX_DELAY_MS);
   194	    const jitter = raw * BACKOFF_JITTER_RATIO * (random() * 2 - 1);
   195	    return Math.max(0, Math.round(raw + jitter));
   196	  }

   203	  function schedule(holder, delayMs, run) {
   204	    clearTimer(holder);
   205	    const generationAtSchedule = sessionGeneration;
   206	    holder.timer = setTimeout(() => {
   207	      holder.timer = null;

   230	  function applyServerTime(serverTime, sentAt, receivedAt) {
   231	    exchangeOffsetMs = serverTime - Math.round((sentAt + receivedAt) / 2);
   232	    clockSyncedAtMs = receivedAt;
   233	    counters.clockSyncs += 1;
   234	  }

   236	  // The route is up once exchangeInfo (weight 20) answers: it proves the
   237	  // origin, the proxy and the symbol, and its serverTime seeds the exchange
   238	  // clock every candle is classified against.
   239	  async function runProbe() {
   240	    if (!accepting || probe.inflight) return;
   241	    const wait = waitBeforeDispatchMs();
   242	    if (wait > 0) {
   243	      schedule(probe, wait, runProbe);
   244	      return;
   245	    }
   246	    if (!budget.reserve(REQUEST_WEIGHTS.EXCHANGE_INFO)) {
   247	      counters.budgetDeferrals += 1;
   248	      schedule(probe, budget.msUntilReset(), runProbe);
   249	      return;
   250	    }
   251	    const controller = new AbortController();
   252	    probe.inflight = controller;
   253	    const generation = sessionGeneration;
   254	    const sentAt = now();
   255	    counters.probes += 1;
   256	    let result;
   257	    try {
   258	      result = await fetchExchangeInfo(MARKET_KINDS.SPOT, probeSymbol, requestOptions(controller.signal));
   259	    } catch {
   260	      result = Object.freeze({ ok: false, reason: "NETWORK_ERROR" });
   261	    }
   262	    probe.inflight = null;
   263	    if (!accepting || generation !== sessionGeneration) return;
   264	    const receivedAt = now();
   265	    observeWeight(result);
   266	    const serverTime = result.ok ? result.value.body?.serverTime : undefined;
   267	    if (!result.ok || !Number.isSafeInteger(serverTime)) {
   268	      probe.attempt += 1;
   269	      telemetryEvent("probe_failed", { reason: result.ok ? "MALFORMED_RESPONSE_BODY" : result.reason, attempt: probe.attempt });
   270	      if (!result.ok) noteRequestFailure(result);
   271	      schedule(probe, Math.max(waitBeforeDispatchMs(), backoffDelayMs(probe.attempt)), runProbe);
   272	      return;
   273	    }
   274	    probe.attempt = 0;
   275	    applyServerTime(serverTime, sentAt, receivedAt);
   276	    consecutiveTransportFailures = 0;
   277	    setRouteState("CONNECTED");
   278	    scheduleClockRefresh();
   279	    for (const poller of pollers.values()) schedulePoll(poller, 0);
   280	  }

   282	  // The exchange clock is re-read from /api/v3/time (weight 1, reserved like
   283	  // every request) once a minute; a failed refresh keeps the last offset.
   284	  function scheduleClockRefresh() {
   285	    schedule(clock, clockRefreshMs, refreshClock);
   286	  }
   287	
   288	  async function refreshClock() {
   289	    if (!accepting || routeState !== "CONNECTED" || clock.inflight) return;
   290	    if (waitBeforeDispatchMs() > 0 || !budget.reserve(REQUEST_WEIGHTS.SERVER_TIME)) {
   291	      counters.budgetDeferrals += 1;
   292	      scheduleClockRefresh();
   293	      return;
   294	    }
   295	    const controller = new AbortController();
   296	    clock.inflight = controller;
   297	    const generation = sessionGeneration;
   298	    const sentAt = now();
   299	    let result;
   300	    try {
   301	      result = await fetchServerTime(MARKET_KINDS.SPOT, requestOptions(controller.signal));
   302	    } catch {
   303	      result = Object.freeze({ ok: false, reason: "NETWORK_ERROR" });
   304	    }
   305	    clock.inflight = null;
   306	    if (!accepting || generation !== sessionGeneration) return;
   307	    observeWeight(result);
   308	    if (result.ok && Number.isSafeInteger(result.value.body?.serverTime)) {
   309	      applyServerTime(result.value.body.serverTime, sentAt, now());
   310	    } else {
   311	      counters.clockRefreshFailures += 1;
   312	      telemetryEvent("clock_refresh_failed", { reason: result.ok ? "MALFORMED_RESPONSE_BODY" : result.reason });
   313	    }
   314	    scheduleClockRefresh();
   315	  }

   317	  // Bookkeeping shared by every failed request: 429 pauses everything until
   318	  // Retry-After (or the backoff); 418 is an IP ban that stops polling for the
   319	  // whole window; three transport failures in a row mean the route is down.
   320	  function noteRequestFailure(result) {
   321	    counters.pollFailures += 1;
   322	    const at = now();
   323	    if (result.reason === "IP_BANNED") {
   324	      banUntilMs = Math.max(banUntilMs, at + (result.retryAfterMs ?? defaultBanMs));
   325	      telemetryEvent("ip_banned", { untilMs: banUntilMs, retryAfterMs: result.retryAfterMs ?? null });
   326	      notifyErrorListeners({ marketKind: MARKET_KINDS.SPOT, route: ROUTE_NAME, message: "Binance banned this IP; polling stops for the Retry-After window.", code: 418 });
   327	      setRouteState("DISCONNECTED", { reason: "IP_BANNED" });
   328	      schedule(probe, banUntilMs - at, runProbe);
   329	      return;
   330	    }
   331	    if (result.reason === "RATE_LIMITED") {
   332	      rateLimitedUntilMs = Math.max(rateLimitedUntilMs, at + (result.retryAfterMs ?? backoffDelayMs(1)));
   333	      telemetryEvent("rate_limited", { untilMs: rateLimitedUntilMs, retryAfterMs: result.retryAfterMs ?? null });
   334	      return;
   335	    }
   336	    if (TRANSPORT_FAILURE_REASONS.has(result.reason)) {
   337	      consecutiveTransportFailures += 1;
   338	      if (routeState === "CONNECTED" && consecutiveTransportFailures >= CONSECUTIVE_FAILURES_BEFORE_DISCONNECT) {
   339	        notifyErrorListeners({ marketKind: MARKET_KINDS.SPOT, route: ROUTE_NAME, message: "Binance REST polling failed repeatedly; the route is down until a probe succeeds." });
   340	        setRouteState("DISCONNECTED", { reason: result.reason });
   341	        schedule(probe, backoffDelayMs(1), runProbe);
   342	      }
   343	    }
   344	  }

   400	  async function runPoll(poller) {
   401	    if (!accepting || routeState !== "CONNECTED" || poller.inflight || pollers.get(poller.key) !== poller) return;
   402	    const wait = waitBeforeDispatchMs();
   403	    if (wait > 0) {
   404	      schedulePoll(poller, wait);
   405	      return;
   406	    }
   407	    // Weight is reserved before dispatch; a refusal waits for the next minute.
   408	    if (!budget.reserve(REQUEST_WEIGHTS.KLINES)) {
   409	      counters.budgetDeferrals += 1;
   410	      poller.budgetDeferred = true;
   411	      telemetryEvent("poll_deferred_by_budget", { symbol: safeTelemetrySymbol(poller.descriptor.symbol) });
   412	      schedulePoll(poller, budget.msUntilReset());
   413	      return;
   414	    }
   415	    poller.budgetDeferred = false;
   416	    const controller = new AbortController();
   417	    const epochAtRequest = poller.epoch;
   418	    const generationAtRequest = sessionGeneration;
   419	    const seq = ++poller.seq;
   420	    poller.inflight = controller;
   421	    poller.lastSentAtMs = now();
   422	    counters.polls += 1;
   423	    const request = poller.bars.nextRequest(exchangeNow());
   424	    let result;
   425	    try {
   426	      result = await fetchKlines(MARKET_KINDS.SPOT, poller.descriptor.symbol, {
   427	        ...requestOptions(controller.signal),
   428	        interval: poller.descriptor.interval,
   429	        startTime: request.startTime,
   430	        limit: request.limit,
   431	      });
   432	    } catch (error) {
   433	      result = Object.freeze({ ok: false, reason: error?.name === "AbortError" ? "ABORTED" : "NETWORK_ERROR" });
   434	    }
   435	    if (poller.inflight === controller) poller.inflight = null;
   436	    // A response for a subscription that ended, or from a session that was
   437	    // disconnected, is thrown away whatever it says.
   438	    if (!accepting || generationAtRequest !== sessionGeneration || epochAtRequest !== poller.epoch || pollers.get(poller.key) !== poller) return;
   439	    const receivedAt = now();
   440	    poller.lastLatencyMs = receivedAt - poller.lastSentAtMs;
   441	    observeWeight(result);
   442	    if (!result.ok) {
   443	      onPollFailure(poller, result);
   444	      return;
   445	    }
   446	    const outcome = applyKlinePage(poller, result.value.body, receivedAt, seq);
   447	    if (outcome.malformed) {
   448	      onPollFailure(poller, Object.freeze({ ok: false, reason: "MALFORMED_RESPONSE_BODY" }));
   449	      return;
   450	    }
   451	    consecutiveTransportFailures = 0;
   452	    poller.attempt = 0;
   453	    poller.lastFailureReason = null;
   454	    poller.lastSuccessAtMs = receivedAt;
   455	    if (outcome.complete) endRecovery(poller);
   456	    scheduleNextPoll(poller, { immediate: outcome.immediate });
   457	  }

   459	  function onPollFailure(poller, result) {
   460	    poller.attempt += 1;
   461	    poller.lastFailureReason = result.reason;
   462	    poller.catchUpPages = 0;
   463	    beginRecovery(poller);
   464	    telemetryEvent("poll_failed", {
   465	      symbol: safeTelemetrySymbol(poller.descriptor.symbol),
   466	      reason: result.reason,
   467	      status: result.status ?? null,
   468	      attempt: poller.attempt,
   469	    });
   470	    noteRequestFailure(result);
   471	    if (routeState !== "CONNECTED") return;
   472	    schedulePoll(poller, Math.max(waitBeforeDispatchMs(), backoffDelayMs(poller.attempt)));
   473	  }

   475	  function emitEnvelope(poller, raw, receivedAtMs) {
   476	    const { marketKind, symbol, eventType, interval } = poller.descriptor;
   477	    const envelope = normalizeBinanceEvent({ marketKind, symbol, eventType, interval, raw }, { receivedAtMs });
   478	    const health = feedHealth.computeContext({ marketKind, symbol, eventType, interval, routeConnected: routeState === "CONNECTED", nowMs: now() });
   479	    notifyMessageListeners(Object.freeze({ ...envelope, stale: health.stale, recoveryState: health.recoveryState }));
   480	  }

   482	  function applyKlinePage(poller, body, receivedAt, seq) {
   483	    const { marketKind, symbol, eventType, interval } = poller.descriptor;
   484	    const rows = parseKlineRows(body, candleIntervalMsFor(interval));
   485	    if (rows === null) return { malformed: true };
   486	    // A successful poll is an observation of the pair; only a failed poll
   487	    // leaves the feed to go stale, as a dead stream would.
   488	    feedHealth.recordEvent(marketKind, symbol, eventType, interval, receivedAt);
   489	    const outcome = poller.bars.apply({ rows, exchangeNowMs: exchangeNow(), seq });
   490	    if (outcome.stale) {
   491	      telemetryEvent("kline_poll_superseded", { symbol: safeTelemetrySymbol(symbol) });
   492	      return { malformed: false, complete: !poller.catchingUp, immediate: false };
   493	    }
   494	    if (outcome.hole) telemetryEvent("kline_hole", { symbol: safeTelemetrySymbol(symbol), confirmedOpenTime: poller.bars.confirmedOpenTime });
   495	    for (const { row, closed } of outcome.emit) {
   496	      emitEnvelope(poller, {
   497	        e: "kline",
   498	        E: receivedAt,
