# Relative Volume (Time of Day)

[Handbook](../../README.md) · [Indicator index](README.md) ·
[Data for indicator authors](data-for-indicator-authors.md) ·
[Setting presets](setting-presets.md)

Code: `apps/web/src/lib/indicators/relative-volume/` (`relativeVolume.ts` is
the registry definition, `relativeVolumeMath.ts` the pure machinery, `tests/`
the evidence). Registry id `relativeVolume`, label "Relative Volume (Time of
Day)", category technical, own pane. The code wins over this page.

## The question it answers

"Is this bar's volume unusual compared with the same minute of the day on
recent sessions, or is it just the open, the close or the London/New York
overlap being its normal self?"

A rolling-average relative volume compares a bar with the twenty bars before
it, so the first minute of a cash session always looks loud and the lunch hour
always looks dead. This indicator compares a bar only with bars that started at
the same minute of the day on earlier sessions. High relative volume says
nothing about direction or follow-through; the colours are purple and blue so
nothing on the pane reads as buy or sell. The baseline is short and noisy, so
the claim is "unusual relative to the last N matching bars at this minute", not
"unusual" in any absolute sense. Descriptive only.

## Calculation

One bar at a time, incrementally; `onBar` never rebuilds from an array.

1. **Clock.** The `clock` setting: `auto` is New York for the dxFeed and
   Databento providers and UTC for Binance; `newYork` and `utc` force it. The
   New York minute of day comes from the killzones helper
   (`nyLocalMinuteOfDay`), cached once per UTC hour; there is no new
   time-zone code.
2. **Slot key.** The bar's start minute of day in that clock (0..1439). There
   is no division by bar length: an hourly equity bar starting 09:30 keys 570
   and the 15:30 half-hour bar keys 930, so they never collide. At most 1,440
   keys exist.
3. **Observation.** The bar's `volume`. A volume that is not a finite number
   at or above zero contributes nothing and the bar reads `null`.
4. **Baseline.** Per slot key, a ring of the last `sessions` committed
   observations (default 10, range 2..60) and their median (even count: mean
   of the two middle values). Median, not mean, so one news day does not
   inflate tomorrow's baseline. The ring capacity is the only bound.
5. **Rolling comparison.** A ring of the last 20 committed bars; its mean is
   the plain relative-volume baseline, shown for comparison.
6. **Read before write.** When a bar first arrives, the slot median, the count
   of prior observations and the rolling mean are read and stored on the bar
   record. Every later recomputation of that bar (a forming revision, a
   corrected close) divides by those stored values. A bar never sees its own
   volume in its denominator.
7. **Commit.** One observation per `ts_open`, filed into both rings at the
   first of: the first dispatch with `closed: true`, or the arrival of a bar
   with a greater `ts_open` while the record is still open (a close that never
   arrived; the last known volume is filed). A later closed dispatch of the
   same bar with a different volume updates the observation in place; a
   valid-to-invalid correction removes it and restores whatever its insertion
   evicted; invalid-to-valid re-inserts it. Corrections are tail-only: a
   correction to an older bar reaches the indicator as the runtime's full
   replay, which recreates this state from scratch.
8. **Outputs.** `rvol = volume / slot median`, `null` while the slot has fewer
   than `minSessions` prior observations (default 3, clamped to `sessions`)
   or the median is zero. `rolling = volume / rolling mean`, `null` until 20
   bars are committed. The forming bar is divided by the full-bar
   expectation, so it grows toward its final value during the bar.
9. **Fail closed.** Any non-finite intermediate yields `null`; nothing ever
   emits `NaN`.

Lookback counts **matching bars, not calendar sessions**: a missing slot
stretches the lookback across more sessions, and the autumn New York DST
repeat can supply two observations for one local minute on crypto under the
`newYork` clock. The table therefore says "7 prior" and the control is
"Lookback (prior bars)".

## Data and the clock rule

Reads `bar.ts_open`, `bar.interval_ms`, `bar.volume`, `bar.closed` and
`bar.provider` (the provider only picks the clock). No sided volume, no ticks,
no order book, no wall clock. Missing bars (gaps in `ts_open`) contribute
nothing, never a zero; the rolling comparison carries across a gap because it
counts committed bars, not minutes.

Timeframes longer than one hour cannot be keyed by minute of day: every output
is `null` and the table says `Needs 1m to 1h`. There is no `timeframeGate`, so
the pane and the table stay on the chart to say so.

The resampler reports the nominal `interval_ms` even for a shortened bucket
(the 15:30 equity half hour, an early-close session's last bar), so the
indicator cannot know a bar's real duration and does **no duration
normalisation**. The start-minute key already compares the 15:30 bar only with
other 15:30 bars. The one unhandled case is an early-close session, whose last
bar is shorter than its slot's usual bars; it enters as one observation among
`sessions` and the median limits its influence without removing it (on the
test fixture one 30-minute bar among three full hours moves the median from
60 to 59).

## Default view

Own pane with `autoscaleRange` 0..4 and dotted reference lines at 1, 2 and 3.
Those lines are **fixed reference marks**: they do not move when "Unusual
above" is changed; the exact ratio is in the table.

- One line, `rvol`, width 2: purple `#8672b3` at or above 1, blue `#2563eb`
  when at or above the "unusual" threshold, grey `#787b86` below 1.
- One fill between the line and 1, `rgba(134,114,179,0.15)`, above 1 only.
- A circle above the bar when the bar is unusual (section "Alert conditions").
- The rolling comparison line (width 1, grey) is off by default; its value is
  always in the table.
- While a bar is forming, its line colour, marker and table value use the same
  hues at 50 percent alpha; they settle at the close.
- Table, top right, three rows: `RVOL 2.4× · 7 prior` coloured like the line
  (the count is the prior observations in the denominator, excluding this
  bar), `Rolling 1.1× · 20 bars`, and a status row. Unavailable values show
  `—`. Before warm-up the pane is empty, never zero.

Status row, first match wins: `Needs 1m to 1h`, `No usable volume`,
`Learning · 1 of 3 prior`, `No usable baseline` (median 0), `Forming · vs full
bar`, and blank when the bar is ready and closed. The `draw.table` handle has
no way to drop a row once written, so the blank status row stays as an empty
strip when ready; removing it entirely needs a `TableHandle` change in
`apps/web/src/lib/chart/draw/table.ts`.

and a change to the line or unusual colour also replays, for the same reason.
Every key is in the schema, so [presets](setting-presets.md) work without any
extra code.

## Alert conditions

There is no notification channel; an alert condition is a marker plus a table
row.

**Unusual volume.** Rule: `rvol >= hotThreshold` (default 2) on the bar of the
current call. It fires on that bar, as a circle above the bar in the unusual
colour, size 1, enlarged to size 2 when `rvol >= 3` (with a threshold above 3
every drawn marker is large). The marker is a pure function of the bar's
current ratio: it appears while the bar forms (at 50 percent alpha), **confirms
at the bar close**, and a correction crossing the threshold in either direction
adds or removes it on the next dispatch; a forming revision redraws rather than
duplicates. A bar whose close never arrived keeps its provisional marker. The
table's first row carries the same ratio in the same colour.

Fixture rate: on the frozen 15-session equity fixture at the default threshold,
13 markers over the 4,680 evaluated bars (sessions 4..15), 0.28 per 100 bars
(2.2 per 1,000), at most one per bar; the twelve labelled anomalies plus one
noise bar. The protocol ceiling is 40 per 1,000 for a signal tool.

## Warm-up

A slot shows a ratio once it holds `minSessions` prior observations (three by
default), so a fresh symbol shows `Learning · n of 3 prior` for three sessions
at every minute. The rolling comparison needs 20 committed bars. On one-minute
bars the chart retains 10,080 bars: about seven UTC days for crypto, about 25
regular sessions for equities, so the default lookback of ten fits; a
60-bar lookback on one-minute crypto never fills. Hourly bars warm up after
three sessions as well, since the key is the start minute, not the bar count.

## Replay and Historical Mode

Candle-only, policy `OHLCV_POLICY`: it works on every archived instrument and
on equities (equity candles are regular session only, so the New York keys run
570..959). A clean replay and a live feed with forming revisions end on the
same committed numbers and the same confirmed markers; the validation tests
pin this on the equity and crypto fixtures (`relativeVolumeValidation.test.ts`).

One documented difference: live state keeps observations from bars the chart
has already discarded past its 10,080-bar retention, while a replay starts
from the retained bars. Live-versus-replay equivalence therefore holds for
every bar whose full lookback lies within the retained series; on the 12,000-bar
crypto fixture at a lookback of 3 that is 5,760 of the 10,080 retained bars,
and the first 1,920 retained bars differ by design. A bar committed because its
close never arrived keeps provisional styling live, which a replay (where every
bar is closed) does not show; its numbers still match.

Truncation invariance (no future data) holds at every cut: a bar's committed
output and confirmed marker never change when later bars are added.

Measured on this container (4 cores, Node 24.21.0, vitest) with the
harness's pooled probe (three untimed warm-up replays, five timed replays of
the first 10,080 bars of the frozen crypto fixture, `onBar` plus `readOutput`

The real-runtime activation replay of the same bars took 68 ms wall with an

output line holds exactly 10,080 entries and no marker is older than the
oldest retained bar. State is at most 1,440 slot rings of `sessions`
observations, one ring of 20, and one tail record.

## Limitations

- Needs `minSessions` prior observations per slot: one-minute crypto retains
  seven UTC days, one-minute equities about 25 sessions; a fresh symbol shows
  "learning" for three sessions.
- Holidays and early closes are ordinary sessions; an early-close session's
  short last bar is one observation among `sessions` (section "Data").
- No duration normalisation (nominal `interval_ms`).
- Equity candles are regular session only, so no pre-market or after-hours
  slots exist.
- Weekend behaviour on crypto is not separated: a Saturday 14:00 bar is
  compared with weekday 14:00 bars. A weekend slot family is deferred.
- The ratio is unit-free; volume units are the provider's (Binance base
  asset, futures contracts, equity shares).
- Descriptive only: high relative volume says nothing about direction or
  follow-through, and nothing here is a prediction.
- The status row cannot be removed once written (section "Default view").
- No tooltip: an SDK indicator has no hover today, so everything a trader needs
  is in the table and on the reference lines.

import type { BarFrame } from "../../../types/frames";
import { nyLocalMinuteOfDay } from "../killzones/killzones";

/**
 * Relative Volume by Time of Day: the pure, incremental machinery.
 *
 * One observation per committed bar is filed under the bar's start minute of
 * day (the "slot key") in a ring of the last `sessions` observations, and in a
 * second ring of the last 20 committed bars. A bar's ratio divides its volume
 * by the slot ring's median read *before* the bar's own observation entered
 * the ring (`baselineAtOpen`), so a bar never sees itself in its denominator
 * and every later revision of that bar divides by the same number.
 *
 * Corrections are tail-only: a closed dispatch of the newest bar with a
 * different volume updates the observation in place, a valid-to-invalid
 * correction removes it (restoring whatever its insertion evicted), and
 * invalid-to-valid re-inserts it. A correction to any older bar reaches the
 * indicator as a full replay, which recreates this state from scratch.
 *
 * Exported so that a later indicator (Squeeze Breakout Context) can import the
 * slot-median machinery as its volume confirmation.
 */

export const MINUTE_MS = 60_000;
export const HOUR_MS = 3_600_000;
export const DAY_MS = 86_400_000;
export const MINUTES_PER_DAY = 1_440;
/** Time of day needs an intraday bar: anything longer than one hour yields null. */
export const RVOL_MAX_INTERVAL_MS = HOUR_MS;
export const RVOL_ROLLING_LENGTH = 20;
export const RVOL_DEFAULT_SESSIONS = 10;
export const RVOL_MIN_SESSIONS_SETTING = 2;
export const RVOL_MAX_SESSIONS_SETTING = 60;
export const RVOL_DEFAULT_MIN_SESSIONS = 3;

export type RvolClock = "auto" | "newYork" | "utc";
export type ResolvedRvolClock = "newYork" | "utc";

export interface RelativeVolumeMathSettings {
  /** Ring capacity per slot key: the last N matching bars (2..60). */
  sessions: number;
  /** Prior observations a slot needs before a ratio is shown; clamped to `sessions` at read time. */
  minSessions: number;
  clock: RvolClock;
}

/** `auto` is New York for the dxFeed and Databento providers and UTC for Binance. */
export function resolveRvolClock(clock: RvolClock, provider: BarFrame["provider"]): ResolvedRvolClock {
  if (clock === "newYork" || clock === "utc") return clock;
  return provider === "DXFEED" || provider === "DATABENTO" ? "newYork" : "utc";
}

/**
 * One-entry cache of the New York minute at the start of a UTC hour. The New
 * York offset is constant inside any UTC hour (both DST changes fall on an
 * hour boundary), so a chronological series needs one `Intl` call per hour.
 */
export interface ClockCache {
  hourStart: number;
  minuteAtHourStart: number;
}

export function createClockCache(): ClockCache {
  return { hourStart: Number.NaN, minuteAtHourStart: 0 };
}

/** The bar's start minute of day (0..1439) in the resolved clock, or null for an unusable timestamp. */
export function slotKeyOf(tsOpen: number, clock: ResolvedRvolClock, cache?: ClockCache): number | null {
  if (!Number.isSafeInteger(tsOpen) || tsOpen < 0) return null;
  if (clock === "utc") return Math.floor((tsOpen % DAY_MS) / MINUTE_MS);
  const hourStart = Math.floor(tsOpen / HOUR_MS) * HOUR_MS;
  let minuteAtHourStart: number;
  if (cache !== undefined && cache.hourStart === hourStart) {
    minuteAtHourStart = cache.minuteAtHourStart;
  } else {
    minuteAtHourStart = nyLocalMinuteOfDay(hourStart);
    if (cache !== undefined) {
      cache.hourStart = hourStart;
      cache.minuteAtHourStart = minuteAtHourStart;
    }
  }
  return (minuteAtHourStart + Math.floor((tsOpen - hourStart) / MINUTE_MS)) % MINUTES_PER_DAY;
}

/** A finite volume at or above zero; anything else contributes no observation. */
export function usableVolume(volume: unknown): number | null {
  return typeof volume === "number" && Number.isFinite(volume) && volume >= 0 ? volume : null;
}

export interface Observation {
  tsOpen: number;
  volume: number;
}

export interface ObservationRing {
  readonly capacity: number;
  /** Oldest first; never longer than `capacity`. */
  readonly items: Observation[];
  /** What the newest insertion pushed out, kept until that tail is superseded so a correction can restore it. */
  evictedByTail: Observation | null;
}

export function createRing(capacity: number): ObservationRing {
  const size = Number.isFinite(capacity) ? Math.max(1, Math.floor(capacity)) : 1;
  return { capacity: size, items: [], evictedByTail: null };
}

export function ringInsert(ring: ObservationRing, observation: Observation): void {
  ring.items.push(observation);
  if (ring.items.length > ring.capacity) ring.evictedByTail = ring.items.shift() ?? null;
}

/** Changes the volume of the observation filed under `tsOpen` in place; false when none is filed. */
export function ringUpdate(ring: ObservationRing, tsOpen: number, volume: number): boolean {
  for (let index = ring.items.length - 1; index >= 0; index -= 1) {
    if (ring.items[index].tsOpen === tsOpen) {
      ring.items[index].volume = volume;
      return true;
    }
  }
  return false;
}

/** Removes the observation filed under `tsOpen` and restores what its insertion evicted. */
export function ringRemove(ring: ObservationRing, tsOpen: number): boolean {
  for (let index = ring.items.length - 1; index >= 0; index -= 1) {
    if (ring.items[index].tsOpen !== tsOpen) continue;
    ring.items.splice(index, 1);
    if (ring.evictedByTail !== null) {
      ring.items.unshift(ring.evictedByTail);
      ring.evictedByTail = null;
    }
    return true;
  }
  return false;
}

/** The tail that inserted into this ring has been superseded by a newer bar: its eviction is final. */
export function ringSupersede(ring: ObservationRing): void {
  ring.evictedByTail = null;
}

/** Median of the ring's volumes (mean of the two middle values for an even count); null when empty. */
export function ringMedian(ring: ObservationRing, scratch: number[] = []): number | null {
  const count = ring.items.length;
  if (count === 0) return null;
  scratch.length = count;
  for (let index = 0; index < count; index += 1) {
    // Insertion sort: the ring holds at most 60 values and this runs once per bar.
    const value = ring.items[index].volume;
    let position = index;
    while (position > 0 && scratch[position - 1] > value) {
      scratch[position] = scratch[position - 1];
      position -= 1;
    }
    scratch[position] = value;
  }
  const middle = count >> 1;
  const median = count % 2 === 1 ? scratch[middle] : (scratch[middle - 1] + scratch[middle]) / 2;
  return Number.isFinite(median) ? median : null;
}

export function ringMean(ring: ObservationRing): number | null {
  const count = ring.items.length;
  if (count === 0) return null;
  let sum = 0;
  for (let index = 0; index < count; index += 1) sum += ring.items[index].volume;
  const mean = sum / count;
  return Number.isFinite(mean) ? mean : null;
}

/** What the baselines were before this bar's observation existed: read once, stored on the bar record. */
export interface BaselineAtOpen {
  slotMedian: number | null;
  slotMean: number | null;
  priorCount: number;

export function requiredPriorOf(settings: RelativeVolumeMathSettings): number {
  const sessions = Number.isFinite(settings.sessions) ? Math.floor(settings.sessions) : RVOL_DEFAULT_SESSIONS;
  const minimum = Number.isFinite(settings.minSessions) ? Math.floor(settings.minSessions) : RVOL_DEFAULT_MIN_SESSIONS;
  return Math.max(1, Math.min(minimum, sessions));
}

function ratioOf(volume: number, denominator: number | null): number | null {
  if (denominator === null || !(denominator > 0)) return null;
  const ratio = volume / denominator;
  return Number.isFinite(ratio) ? ratio : null;
}

/** The reading for a tail record: rule 9 (outputs) and rule 11 (status precedence, first match wins). */
export function readingOf(tail: TailRecord, settings: RelativeVolumeMathSettings): RvolReading {
  const requiredPrior = requiredPriorOf(settings);
  const base = tail.baselineAtOpen;
  const reading: RvolReading = {
    tsOpen: tail.tsOpen,
    key: tail.key,
    volume: tail.volume,
    rvol: null,
    rolling: null,
    slotMeanRatio: null,
    priorCount: base.priorCount,
    rollingCount: base.rollingCount,
    requiredPrior,
    confirmed: tail.confirmed,
    status: "ready",
  };
  if (!tail.supported) {
    reading.status = "unsupported";
    return reading;
  }
  if (tail.volume === null) {
    reading.status = "noVolume";
    return reading;
  }
  reading.rolling = base.rollingCount >= RVOL_ROLLING_LENGTH ? ratioOf(tail.volume, base.rollingMean) : null;
  if (base.priorCount < requiredPrior) {
    reading.status = "learning";
    return reading;
  }
  reading.slotMeanRatio = ratioOf(tail.volume, base.slotMean);
  reading.rvol = ratioOf(tail.volume, base.slotMedian);
  if (reading.rvol === null) {
    reading.status = "noBaseline";
    return reading;
  }
  reading.status = tail.confirmed ? "ready" : "forming";
  return reading;
}

export function createRelativeVolumeEngine(settings: RelativeVolumeMathSettings): RelativeVolumeEngine {
  const capacity = Number.isFinite(settings.sessions)
    ? Math.min(RVOL_MAX_SESSIONS_SETTING, Math.max(RVOL_MIN_SESSIONS_SETTING, Math.floor(settings.sessions)))
    : RVOL_DEFAULT_SESSIONS;
  const slots = new Map<number, ObservationRing>();
  const rolling = createRing(RVOL_ROLLING_LENGTH);
  const clockCache = createClockCache();
  const scratch: number[] = [];
  let tail: TailRecord | null = null;
  let current: RvolReading | null = null;

  function slotFor(key: number): ObservationRing {
    let ring = slots.get(key);
    if (ring === undefined) {
      ring = createRing(capacity);
      slots.set(key, ring);
    }
    return ring;
  }

  function readBaseline(key: number | null): BaselineAtOpen {
    const slot = key === null ? undefined : slots.get(key);
    return {
      slotMedian: slot === undefined ? null : ringMedian(slot, scratch),
      slotMean: slot === undefined ? null : ringMean(slot),
      priorCount: slot === undefined ? 0 : slot.items.length,
      rollingMean: ringMean(rolling),
      rollingCount: rolling.items.length,
    };
  }

  /** Rule 7: the commit event for the tail, filing its last known volume when it is usable. */
  function commit(record: TailRecord): void {
    record.committed = true;
    if (!record.supported || record.key === null || record.volume === null) return;
    const observation = { tsOpen: record.tsOpen, volume: record.volume };
    ringInsert(slotFor(record.key), observation);
    ringInsert(rolling, { tsOpen: record.tsOpen, volume: record.volume });
    record.inRings = true;
  }

  /** A later dispatch of a committed tail: update in place, remove (valid to invalid) or insert (invalid to valid). */
  function reconcile(record: TailRecord): void {
    if (!record.supported || record.key === null) return;
    const slot = slotFor(record.key);
    if (record.volume !== null && record.inRings) {
      ringUpdate(slot, record.tsOpen, record.volume);
      ringUpdate(rolling, record.tsOpen, record.volume);
    } else if (record.volume !== null) {
      ringInsert(slot, { tsOpen: record.tsOpen, volume: record.volume });
      ringInsert(rolling, { tsOpen: record.tsOpen, volume: record.volume });
      record.inRings = true;
    } else if (record.inRings) {
      ringRemove(slot, record.tsOpen);
      ringRemove(rolling, record.tsOpen);
      record.inRings = false;
    }
  }

  function supersede(record: TailRecord): void {
    if (record.key !== null) {
      const slot = slots.get(record.key);
      if (slot !== undefined) ringSupersede(slot);
    }
    ringSupersede(rolling);
  }

  function onBar(bar: BarFrame): RvolReading {
    const tsOpen = bar.ts_open;
    if (tail !== null && tsOpen < tail.tsOpen) {
      // A dispatch older than the current record: the runtime replays those, so here it is ignored.
      return current ?? readingOf(tail, settings);
    }
    if (tail === null || tsOpen > tail.tsOpen) {
      if (tail !== null) {
        if (!tail.committed) commit(tail); // rule 7(b): a close that never arrived
        supersede(tail);
      }
      const intervalOk = Number.isFinite(bar.interval_ms) && bar.interval_ms > 0 && bar.interval_ms <= RVOL_MAX_INTERVAL_MS;
      const key = intervalOk ? slotKeyOf(tsOpen, resolveRvolClock(settings.clock, bar.provider), clockCache) : null;
      tail = {
        tsOpen,
        key,
        supported: intervalOk && key !== null,
        volume: usableVolume(bar.volume),
        baselineAtOpen: readBaseline(key),
        committed: false,
        inRings: false,
        confirmed: false,
      };
    } else {
      tail.volume = usableVolume(bar.volume);
    }
    if (bar.closed === true) tail.confirmed = true;
    if (!tail.committed) {
      if (bar.closed === true) commit(tail); // rule 7(a)
    } else {
      reconcile(tail);
    }
    current = readingOf(tail, settings);
    return current;
  }

  return {
    settings,
    onBar,
    get current() {
      return current;
    },
    get tail() {
      return tail;
    },
    rollingRing: rolling,
    slotRing: (key) => slots.get(key),
    get slotCount() {
      return slots.size;
    },
  };
}

/** `#rgb` or `#rrggbb` with an alpha; any other colour string is returned unchanged. */
export function withAlpha(color: string, alpha: number): string {
  const hex = /^#([0-9a-f]{3}|[0-9a-f]{6})$/i.exec(color.trim());
  if (hex === null) return color;
  let digits = hex[1];
  if (digits.length === 3) digits = digits.split("").map((d) => d + d).join("");
  const r = Number.parseInt(digits.slice(0, 2), 16);
  const g = Number.parseInt(digits.slice(2, 4), 16);
  const b = Number.parseInt(digits.slice(4, 6), 16);
  return `rgba(${r},${g},${b},${alpha})`;
}

export function isHot(reading: RvolReading | null, hotThreshold: number): boolean {
  return reading !== null && reading.rvol !== null && Number.isFinite(hotThreshold) && reading.rvol >= hotThreshold;
}

/** The rvol line's colour for the bar: unusual, at or above 1, below 1; provisional while the bar forms. */
export function rvolLineColor(reading: RvolReading | null, settings: RelativeVolumeSettings): string {
  let color = settings.lineColor;
  if (reading !== null && reading.rvol !== null) {
    if (isHot(reading, settings.hotThreshold)) color = settings.hotColor;
    else if (reading.rvol < 1) color = RVOL_BELOW_ONE_COLOR;
  }
  return reading !== null && !reading.confirmed ? withAlpha(color, RVOL_PROVISIONAL_ALPHA) : color;
}

function rollingLineColor(reading: RvolReading | null, settings: RelativeVolumeSettings): string {
  return reading !== null && !reading.confirmed ? withAlpha(settings.rollingColor, RVOL_PROVISIONAL_ALPHA) : settings.rollingColor;
}

function formatRatio(value: number | null): string {
  return value === null ? RVOL_UNAVAILABLE : `${value.toFixed(1)}×`;
}

/** Rule 11, first match wins; the empty string means the row is blank because the bar is ready and closed. */
export function statusText(reading: RvolReading | null): string {
  if (reading === null) return "";
  switch (reading.status) {
    case "unsupported":
      return "Needs 1m to 1h";
    case "noVolume":
      return "No usable volume";
    case "learning":
      return `Learning · ${reading.priorCount} of ${reading.requiredPrior} prior`;
    case "noBaseline":
      return "No usable baseline";
    case "forming":
      return "Forming · vs full bar";
    default:
      return "";
  }
}

function commitDrawFlush(
  record: ActivationRecord,
  bar: BarFrame,
  replace: boolean,
): void {
  for (const [key, points] of record.fillPointsByKey) {
    const point = record.pendingFillPoints.get(key) ?? null;
    if (replace) overwriteLastFillPoint(points, point);
    else pushFillPoint(points, point);
  }
  // A band first filled on this bar has no history: backfill it with the bars
  // it did not exist for, so every band's points stay one per bar.
  for (const key of record.pendingFillPoints.keys()) {
    if (record.fillPointsByKey.has(key)) continue;
    // On a re-delivery of the newest bar that bar is already counted, so it takes the band's first point.
    const points: (FillPoint | null)[] = new Array(replace ? Math.max(0, record.fillBars - 1) : record.fillBars).fill(null);
    points.push(record.pendingFillPoints.get(key) ?? null);
    record.fillPointsByKey.set(key, points);
  }
  if (!replace) record.fillBars += 1;
  if (replace) {
    overwriteBarMarkerCalls(
      record.markerCalls,
      bar.ts_open,
      record.pendingMarkerCalls,
    );
  } else {
    pushMarkerCalls(record.markerCalls, record.pendingMarkerCalls);
  }
  flushTableCells(record.drawOwnerId);

export type SourceBarRejection = "FINALIZED_BAR_CANNOT_REOPEN" | "STALE_DEVELOPING_BAR";

  accepted: boolean;
  developingBar: BarFrame | null;
  rejection?: SourceBarRejection;

function lowerBoundByOpenTime(bars: readonly BarFrame[], tsOpen: number): number {
  let low = 0;
  let high = bars.length;
  while (low < high) {
    const middle = low + Math.floor((high - low) / 2);
    if (bars[middle].ts_open < tsOpen) low = middle + 1;
    else high = middle;
  }
  return low;
}

export function replaceClosedBars(bars: readonly BarFrame[]): BarFrame[] {
  const byOpenTime = new Map<number, BarFrame>();
  for (const bar of bars) {
    if (bar.closed) byOpenTime.set(bar.ts_open, bar);
  }
  return [...byOpenTime.values()]
    .sort((a, b) => a.ts_open - b.ts_open)
    .slice(-MAX_RETAINED_SOURCE_BARS);
}

export function upsertClosedBar(bars: BarFrame[], bar: BarFrame): void {
  if (!bar.closed) throw new Error("upsertClosedBar: bar must be finalized");
  const last = bars[bars.length - 1];
  if (last === undefined || last.ts_open < bar.ts_open) bars.push(bar);
  else {
    const index = lowerBoundByOpenTime(bars, bar.ts_open);
    if (bars[index]?.ts_open === bar.ts_open) bars[index] = bar;
    else bars.splice(index, 0, bar);
  }
  if (bars.length > MAX_RETAINED_SOURCE_BARS) {
    bars.splice(0, bars.length - MAX_RETAINED_SOURCE_BARS);
  }
}

export function admitSourceBar(
  closedBars: BarFrame[],
  developingBar: BarFrame | null,
  bar: BarFrame,
): SourceBarAdmission {
  if (bar.closed) {
    upsertClosedBar(closedBars, bar);
    return {
      accepted: true,
      developingBar: developingBar !== null && developingBar.ts_open > bar.ts_open
        ? developingBar
        : null,
    };
  }

  const newestClosed = closedBars[closedBars.length - 1];
  if (newestClosed !== undefined && bar.ts_open <= newestClosed.ts_open) {
    return { accepted: false, developingBar, rejection: "FINALIZED_BAR_CANNOT_REOPEN" };
  }
  if (developingBar !== null && bar.ts_open < developingBar.ts_open) {
    return { accepted: false, developingBar, rejection: "STALE_DEVELOPING_BAR" };
  }
  return { accepted: true, developingBar: bar };
}

export function fullBarBuffer(closedBars: readonly BarFrame[], developingBar: BarFrame | null): BarFrame[] {
  if (developingBar === null) return [...closedBars];

    ? closedBars.slice(closedBars.length - (MAX_RETAINED_SOURCE_BARS - 1))
    : closedBars;

}

    : newestClosed;
}

  closedBars: readonly BarFrame[],
  developingBar: BarFrame | null,
  bucketOpen: number,
  bucketIntervalMs: number,

  if (!Number.isSafeInteger(bucketOpen) || !Number.isSafeInteger(bucketIntervalMs) || bucketIntervalMs <= 0) {

/**
 * Brief, "Baseline comparison": three methods at the same threshold on the same
 * eligible bars. Time of day (slot median) is the indicator; rolling (mean of
 * the previous 20 committed volumes) is the baseline a plain RVOL gives; the
 * same-slot mean separates the benefit of the clock from the benefit of the
 * median. Counts and rates are printed as the table the doc page quotes.
 */

const THRESHOLD = 2;
const METHODS = ["timeOfDay", "sameSlotMean", "rolling"] as const;
type Method = (typeof METHODS)[number];

interface MethodResult {
  eligible: number;
  detections: number;
  anomaliesHit: number;
  falsePositives: number;
  predictableEligible: number;
  predictableFalsePositives: number;
}

export interface ComparisonTable {
  anomalies: number;
  results: Record<Method, MethodResult>;
}

function emptyResult(): MethodResult {
  return { eligible: 0, detections: 0, anomaliesHit: 0, falsePositives: 0, predictableEligible: 0, predictableFalsePositives: 0 };
}

export function compareMethods(fixture: ReturnType<typeof relativeVolumeEquityFixture>): ComparisonTable {
  const { bars, labels } = fixture;
  const engine = createRelativeVolumeEngine({ sessions: RELATIVE_VOLUME_DEFAULT_SETTINGS.sessions, minSessions: RELATIVE_VOLUME_DEFAULT_SETTINGS.minSessions, clock: "auto" });
  const results: Record<Method, MethodResult> = { timeOfDay: emptyResult(), sameSlotMean: emptyResult(), rolling: emptyResult() };
  const anomalyIndices = new Set(labels.anomalyIndices);
  const predictableSlotIndices = new Set(labels.predictableSlotIndices);
  const evaluationIndices = new Set(labels.evaluationIndices);
  for (let index = 0; index < bars.length; index += 1) {
    const reading = engine.onBar(bars[index]);
    if (!evaluationIndices.has(index)) continue;
    const ratios: Record<Method, number | null> = { timeOfDay: reading.rvol, sameSlotMean: reading.slotMeanRatio, rolling: reading.rolling };
    // Readiness is asserted from actual prior observations per key, never from a calendar day number.
    if (METHODS.some((method) => ratios[method] === null)) continue;
    const anomaly = anomalyIndices.has(index);
    const predictable = predictableSlotIndices.has(index);
    for (const method of METHODS) {
      const result = results[method];
      const detected = (ratios[method] as number) >= THRESHOLD;
      result.eligible += 1;
      if (predictable) result.predictableEligible += 1;
      if (detected) result.detections += 1;
      if (anomaly && detected) result.anomaliesHit += 1;
      if (!anomaly && detected) {
        result.falsePositives += 1;
        if (predictable) result.predictableFalsePositives += 1;
      }
    }
  }
  return { anomalies: labels.anomalies.length, results };
}

function pct(numerator: number, denominator: number): string {
  return denominator === 0 ? "n/a" : `${((100 * numerator) / denominator).toFixed(2)}%`;
}

const METHOD_LABELS: Record<Method, string> = {
  timeOfDay: "Time of day (slot median)",
  sameSlotMean: "Same-slot mean",
  rolling: "Rolling 20 mean",
};

export function formatComparison(title: string, table: ComparisonTable): string {
  const lines = [
    `${title} (threshold ${THRESHOLD.toFixed(1)}, ${table.anomalies} anomalies)`,
    "| Method | Eligible bars | Detections | Anomalies hit | Recall | False positives | FP rate | Predictable-slot bars | Predictable-slot FPs | Predictable-slot FP rate |",
    "|---|---|---|---|---|---|---|---|---|---|",
  ];
  for (const method of METHODS) {
    const r = table.results[method];
    lines.push(
      `| ${METHOD_LABELS[method]} | ${r.eligible} | ${r.detections} | ${r.anomaliesHit}/${table.anomalies} | ${pct(r.anomaliesHit, table.anomalies)} | ${r.falsePositives} | ${pct(r.falsePositives, r.eligible - r.anomaliesHit)} | ${r.predictableEligible} | ${r.predictableFalsePositives} | ${pct(r.predictableFalsePositives, r.predictableEligible)} |`,
    );
  }
  return lines.join("\n");
}

/**
 * Protocol check 6, performance. Three probes, each timing the indicator's own
 * `onBar` (the wrapper adds one `performance.now()` pair per call) through the
 * real runtime:
 *
 * - `probeReplay`: activation over a long series (the protocol uses 10,080
 *   bars, the chart's retention cap).
 * - `probeFormingBar`: one bar revised `revisionsPerSecond` times a second for
 *   `seconds`, with `printsPerMinute` prints landing in the tick store and in
 *   `ctx.trades`; the live-update cost.
 * - `probeRollover`: the series at the retention cap, then more bars so the
 *   chart trims the front and `discardLeading` runs; reports what the
 *   indicator retains afterwards.
 *
 * Heap numbers are `process.memoryUsage().heapUsed` after a forced collection
 * when `--expose-gc` is on (`NODE_OPTIONS=--expose-gc npx vitest run ...`);
 * without it they are indicative only and `gcExposed` says so.
 */

export interface Percentiles {
  count: number;
  p50: number;
  p90: number;
  p99: number;
  max: number;
  mean: number;
  totalMs: number;
}

export function percentilesOf(samples: readonly number[]): Percentiles {
  if (samples.length === 0) return { count: 0, p50: 0, p90: 0, p99: 0, max: 0, mean: 0, totalMs: 0 };
  const sorted = [...samples].sort((a, b) => a - b);
  const at = (quantile: number) => sorted[Math.min(sorted.length - 1, Math.max(0, Math.ceil(quantile * sorted.length) - 1))];
  const totalMs = sorted.reduce((sum, value) => sum + value, 0);
  return { count: sorted.length, p50: at(0.5), p90: at(0.9), p99: at(0.99), max: sorted[sorted.length - 1], mean: totalMs / sorted.length, totalMs };
}

export interface HeapReading {
  gcExposed: boolean;
  beforeBytes: number;
  afterBytes: number;
  deltaBytes: number;
}

type GcGlobal = typeof globalThis & { gc?: () => void };

export function heapUsed(): { bytes: number; gcExposed: boolean } {
  const gc = (globalThis as GcGlobal).gc;
  if (typeof gc === "function") gc();
  return { bytes: process.memoryUsage().heapUsed, gcExposed: typeof gc === "function" };
}

function heapReading(before: { bytes: number; gcExposed: boolean }): HeapReading {
  const after = heapUsed();
  return { gcExposed: before.gcExposed && after.gcExposed, beforeBytes: before.bytes, afterBytes: after.bytes, deltaBytes: after.bytes - before.bytes };
}

/** `def` with its `onBar` timed; `samples` fills as the runtime calls it. */
export function timedDef<S, T>(def: RuntimeIndicatorDef<S, T>): { def: RuntimeIndicatorDef<S, T>; samples: number[] } {
  const samples: number[] = [];
  const timed: RuntimeIndicatorDef<S, T> = {
    ...def,
    onBar(ctx) {
      const started = performance.now();
      try {
        def.onBar(ctx);
      } finally {
        samples.push(performance.now() - started);
      }
    },
  };
  return { def: timed, samples };
}

export interface ReplayProbe {
  id: string;
  bars: number;
  onBar: Percentiles;
  /** The whole `onSnapshot`, including the runtime's own bookkeeping. */
  wallMs: number;
  heap: HeapReading;
  faulted: boolean;
}

export function probeReplay<S, T>(def: RuntimeIndicatorDef<S, T>, bars: readonly BarFrame[], settings: T, extras: LiveExtras = {}): ReplayProbe {
  const before = heapUsed();
  const { def: timed, samples } = timedDef(def);
  const session = openLiveSession(timed, settings, extras, []);
  const started = performance.now();
  session.runtime.onSnapshot(bars);
  const wallMs = performance.now() - started;
  const capture = session.capture();
  const heap = heapReading(before);
  session.close();
  return { id: def.id, bars: bars.length, onBar: percentilesOf(samples), wallMs, heap, faulted: capture.faulted };
}

export interface FormingBarOptions {
  seconds?: number;
  revisionsPerSecond?: number;
  printsPerMinute?: number;
  extras?: LiveExtras;
  identity?: FixtureIdentity;
  /** Feed the prints to a real `AggressiveTape` handed over as `ctx.ticks` (default true). */
  tape?: boolean;
  seed?: number;
}

export interface FormingBarProbe {
  id: string;
  revisions: number;
  prints: number;
  onBar: Percentiles;
  wallMs: number;
  heap: HeapReading;
  faulted: boolean;
}

/**
 * The bar after `warmup` forms for `seconds`: `revisionsPerSecond` REPLACED_EDGE
 * dispatches a second, each carrying the prints so far in `ctx.trades`
 * (LIVE_COMPLETE) and in the tick store.
 */
export function probeFormingBar<S, T>(def: RuntimeIndicatorDef<S, T>, warmup: readonly BarFrame[], settings: T, options: FormingBarOptions = {}): FormingBarProbe {
  const seconds = options.seconds ?? 60;
  const revisionsPerSecond = options.revisionsPerSecond ?? 50;
  const printsPerMinute = options.printsPerMinute ?? 1_000;
  const last = warmup[warmup.length - 1];
  if (last === undefined) throw new Error("probeFormingBar: warmup must hold at least one bar");
  const identity = options.identity ?? ({ provider: last.provider, marketKind: last.marketKind, assetClass: last.assetClass, symbol: last.symbol } as FixtureIdentity);
  const ts_open = last.ts_open + last.interval_ms;
  const random = seeded(options.seed ?? 3);
  const totalRevisions = seconds * revisionsPerSecond;
  const totalPrints = Math.round((printsPerMinute * seconds) / 60);
  const prints: TradeFrame[] = [];
  for (let index = 0; index < totalPrints; index += 1) {
    const ts = ts_open + Math.floor((index / totalPrints) * seconds * 1_000);
    const price = Math.round((last.close + (random() - 0.5) * last.close * 0.0005) * 100) / 100;
    prints.push(tradeFrame(ts, price, Math.round((0.01 + random() * 0.5) * 1e6) / 1e6, random() < 0.5 ? "buy" : "sell", identity, `forming-${index}`));
  }
  const tape = options.tape === false ? null : tapeOf([], ts_open);
  const extras: LiveExtras = { ...options.extras };
  if (tape !== null && extras.ticks === undefined) extras.ticks = ticksOf(tape);

  const before = heapUsed();
  const { def: timed, samples } = timedDef(def);
  const session = openLiveSession(timed, settings, extras, warmup);
  const started = performance.now();
  let printIndex = 0;
  let high = last.close;
  let low = last.close;
  let volume = 0;
  let buy = 0;
  let close = last.close;
  for (let revision = 0; revision < totalRevisions; revision += 1) {
    const now = ts_open + Math.floor(((revision + 1) / totalRevisions) * seconds * 1_000);
    while (printIndex < prints.length && prints[printIndex].ts_exchange < now) {
      const print = prints[printIndex];
      tape?.add(print);
      volume += print.size;
      if (print.side === "buy") buy += print.size;
      high = Math.max(high, print.price);
      low = Math.min(low, print.price);
      close = print.price;
      printIndex += 1;
    }
    const closed = revision === totalRevisions - 1;
    const bar = {
      type: "bar",
      ...identity,
      interval_ms: last.interval_ms,
      ts_open,
      open: last.close,
      high,
      low,
      close,
      volume: Math.round(volume * 1e6) / 1e6,
      buy_volume: Math.round(buy * 1e6) / 1e6,
      sell_volume: Math.round((volume - buy) * 1e6) / 1e6,
      trade_count: printIndex,
      closed,
    } as BarFrame;
    session.dispatch({ bar, trades: prints.slice(0, printIndex), tradeAvailability: "LIVE_COMPLETE" });
  }
  const wallMs = performance.now() - started;
  const capture = session.capture();
  const heap = heapReading(before);
  session.close();
  return { id: def.id, revisions: totalRevisions, prints: printIndex, onBar: percentilesOf(samples), wallMs, heap, faulted: capture.faulted };
}

export interface RolloverOptions {
  /** Bars appended past the retention cap (default 1,000). */
  extraBars?: number;
  extras?: LiveExtras;
}

export interface RolloverProbe {
  id: string;
  retainedBars: number;
  discarded: number;
  /** Length of every cached output line after the rollover; each must equal `retainedBars`. */
  outputLengths: Record<string, number>;
  markersRetained: number;
  /** Markers whose time is older than the oldest retained bar: the runtime should have trimmed them. */
  markersBeforeRetention: number;
  onBar: Percentiles;
  heap: HeapReading;
  /** Heap growth per appended bar after the cap, bytes; a positive slope is a leak candidate. */
  bytesPerExtraBar: number;
  faulted: boolean;
}

function round2(value: number): number {
  return Math.round(value * 100) / 100;
}

/**
 * The bar after `last` for the rollover probe: a small random step in price
 * and volume, with sides read through `barSides` and written coherently. A
 * sided bar gets a fresh buy share and keeps `last`'s unknown share; a bar
 * that carried only `buy_volume` keeps carrying only that; an unsided bar
 * stays unsided. Nothing is inherited by spreading `last`.
 */
export function rolloverBar(last: BarFrame, random: () => number): BarFrame {
  const open = last.close;
  const close = Math.max(1, open + (random() - 0.5) * open * 0.001);
  const volume = round2(50 + random() * 100);
  const { buy_volume: _buy, sell_volume: _sell, ...rest } = last;
  const bar: Record<string, unknown> = {
    ...rest,
    ts_open: last.ts_open + last.interval_ms,
    open,
    high: Math.max(open, close) + random(),
    low: Math.min(open, close) - random(),
    close,
    volume,
    trade_count: last.trade_count === null ? null : Math.max(1, Math.round(volume / 3)),
    closed: true,
  };
  const sides = barSides(last);
  if (sides.known) {
    const unknownShare = last.volume > 0 ? sides.unknown / last.volume : 0;
    const sided = round2(volume * (1 - unknownShare));
    const buy = round2(sided * (0.3 + random() * 0.4));
    bar.buy_volume = buy;
    if (last.sell_volume !== undefined && last.sell_volume !== null) bar.sell_volume = round2(sided - buy);
  }
  return bar as BarFrame;
}

/** `bars` fills the chart to the cap; `extraBars` more then roll the front off, as the live chart does after a week. */
export function probeRollover<S, T>(def: RuntimeIndicatorDef<S, T>, bars: readonly BarFrame[], settings: T, options: RolloverOptions = {}): RolloverProbe {
  const extraBars = options.extraBars ?? 1_000;
  const seed = bars.slice(-MAX_RETAINED_SOURCE_BARS);
  if (seed.length < MAX_RETAINED_SOURCE_BARS) throw new Error(`probeRollover: needs at least ${MAX_RETAINED_SOURCE_BARS} bars`);
  const { def: timed, samples } = timedDef(def);
  const session = openLiveSession(timed, settings, options.extras, seed);
  samples.length = 0;
  const before = heapUsed();
  const random = seeded(13);
  let last = seed[seed.length - 1];
  for (let index = 0; index < extraBars; index += 1) {
    const bar = rolloverBar(last, random);
    session.dispatch({ bar });
    last = bar;
  }
  const heap = heapReading(before);
  const capture = session.capture();
  const oldest = session.bars[0]?.ts_open ?? -Infinity;
  const outputLengths: Record<string, number> = {};
  for (const [key, values] of Object.entries(capture.outputs)) outputLengths[key] = values.length;
  const result: RolloverProbe = {
    id: def.id,
    retainedBars: session.bars.length,
    discarded: session.discarded,
    outputLengths,
    markersRetained: capture.markers.length,
    markersBeforeRetention: capture.markers.filter((call) => call.time < oldest).length,
    onBar: percentilesOf(samples),
    heap,
    bytesPerExtraBar: extraBars === 0 ? 0 : heap.deltaBytes / extraBars,
    faulted: capture.faulted,
  };
  session.close();
  return result;
}

export function relativeVolumeEquityFixture(options: RelativeVolumeEquityOptions = {}): LabelledBars<RelativeVolumeEquityLabels> {
  const flat = options.flatSeasonality ?? false;
  const seed = options.seed ?? RVOL_EQUITY_SEED;
  const baseVolume = options.baseVolume ?? RVOL_BASE_VOLUME;
  const expected = (minute: number) => (flat ? baseVolume : relativeVolumeExpectedEquity(minute, baseVolume));
  const expectedVolumes = Array.from({ length: RVOL_EQUITY_BARS_PER_SESSION }, (_, minute) => expected(minute));

  const sessionStarts: number[] = [];
  const sessionDates: string[] = [];
  for (let day = Date.UTC(2026, 2, 2, 17); sessionStarts.length < RVOL_EQUITY_SESSIONS; day += 24 * 60 * MINUTE_MS) {
    const session = regularSessionAt(day);
    if (session === null) continue;
    sessionStarts.push(session.openMs);
    sessionDates.push(sessionDateKey(session.openMs));
  }

  const uniform = mulberry32(seed);
  const normal = standardNormals(uniform);
  const bars: BarFrame[] = [];
  const predictableSlotIndices: number[] = [];
  const evaluationIndices: number[] = [];
  sessionStarts.forEach((start, sessionIndex) => {
    for (let minute = 0; minute < RVOL_EQUITY_BARS_PER_SESSION; minute += 1) {
      const index = bars.length;
      bars.push(rvolBar(start + minute * MINUTE_MS, index, noisyVolume(expectedVolumes[minute], normal()), 190, 2, DXFEED_EQUITY, false));
      if (minute < 10 || minute >= 380) predictableSlotIndices.push(index);
      if (sessionIndex + 1 >= 4) evaluationIndices.push(index);
    }
  });

  const anomalies: RelativeVolumeAnomaly[] = [];
  const taken = new Set<string>();
  while (anomalies.length < RVOL_EQUITY_ANOMALIES) {
    const session = 4 + Math.floor(uniform() * 12);
    const minute = flat ? Math.floor(uniform() * RVOL_EQUITY_BARS_PER_SESSION) : 90 + Math.floor(uniform() * 241);
    const key = `${session}:${minute}`;
    if (taken.has(key)) continue;
    taken.add(key);
    const index = (session - 1) * RVOL_EQUITY_BARS_PER_SESSION + minute;
    const volume = Math.round(RVOL_ANOMALY_MULTIPLE * expectedVolumes[minute]);
    bars[index] = { ...bars[index], volume, trade_count: Math.max(1, Math.round(volume / 5)) } as BarFrame;
    anomalies.push({ session, minute, index, expectedVolume: expectedVolumes[minute], volume });

      sessionDates,

      anomalyIndices: anomalies.map((anomaly) => anomaly.index),

      evaluationSessions: { first: 4, last: RVOL_EQUITY_SESSIONS },

    },
  };

  newCalls: readonly MarkerCall[],

function bucketOpenMs(tsClose: number, intervalMs: number): number {
  return Math.floor((tsClose - 1) / intervalMs) * intervalMs;

function bucketFor(bar: BarFrame, intervalMs: number, sessionAnchored: boolean): { openMs: number; spanMs: number } {
  const session = sessionAnchored ? regularSessionAt(bar.ts_open) : null;
  if (session === null) return { openMs: bucketOpenMs(bar.ts_open + bar.interval_ms, intervalMs), spanMs: intervalMs };
  const openMs = session.openMs + Math.floor((bar.ts_open - session.openMs) / intervalMs) * intervalMs;
  return { openMs, spanMs: Math.min(intervalMs, session.closeMs - openMs) };
}

function isCompleteBucket(group: readonly BarFrame[], bucketOpen: number, targetIntervalMs: number): boolean {
  let expectedOpen = bucketOpen;
  for (const bar of group) {
    if (bar.ts_open !== expectedOpen || bar.closed !== true) return false;
    expectedOpen += bar.interval_ms;
  }
  return expectedOpen === bucketOpen + targetIntervalMs;
}

function isRepresentableBucket(group: readonly BarFrame[], bucketOpen: number): boolean {
  let expectedOpen = bucketOpen;
  for (let index = 0; index < group.length; index += 1) {
    const bar = group[index];
    if (bar.ts_open !== expectedOpen) return false;
    if (bar.closed !== true && index !== group.length - 1) return false;
    expectedOpen += bar.interval_ms;
  }
  return true;
}

export function resampleBars(bars: readonly BarFrame[], targetIntervalMs: number): BarFrame[] {
  if (bars.length === 0) return [];
  if (!Number.isSafeInteger(targetIntervalMs) || targetIntervalMs <= 0) {
    throw new Error("resampleBars: targetIntervalMs must be a positive safe integer");
  }
  const first = bars[0];
  if (targetIntervalMs < first.interval_ms || targetIntervalMs % first.interval_ms !== 0) {
    throw new Error("resampleBars: targetIntervalMs must be a whole multiple of the source interval");
  }
  for (const bar of bars) {
    if (
      bar.symbol !== first.symbol ||
      !identitiesMatch(bar, first) ||
      bar.interval_ms !== first.interval_ms ||
      bar.ts_open % bar.interval_ms !== 0 ||
      !Number.isSafeInteger(bar.ts_open + bar.interval_ms)
    ) {
      throw new Error("resampleBars: bars must belong to one pair and source interval");
    }
  }
  const barsByOpenTime = new Map<number, BarFrame>();
  for (const bar of bars) barsByOpenTime.set(bar.ts_open, bar);
  const orderedBars = [...barsByOpenTime.values()].sort((a, b) => a.ts_open - b.ts_open);
  if (targetIntervalMs === first.interval_ms) return orderedBars;

  const sessionAnchored = isRegularSessionOnly(first);
  const groups = new Map<number, BarFrame[]>();
  const spans = new Map<number, number>();
  for (const bar of orderedBars) {
    const bucket = bucketFor(bar, targetIntervalMs, sessionAnchored);
    const group = groups.get(bucket.openMs);
    if (group) group.push(bar);
    else groups.set(bucket.openMs, [bar]);
    spans.set(bucket.openMs, bucket.spanMs);
  }

  const bucketOpens = [...groups.keys()].sort((a, b) => a - b);
  const result: BarFrame[] = [];
  for (const bucketOpen of bucketOpens) {
    const group = groups.get(bucketOpen)!;
    if (!isRepresentableBucket(group, bucketOpen)) continue;
    const last = group[group.length - 1];
    const closed = isCompleteBucket(group, bucketOpen, spans.get(bucketOpen)!);
    const volume = group.reduce((sum, b) => sum + b.volume, 0);
    const tradeCount = group.every((bar) => bar.trade_count !== null)
      ? group.reduce((sum, bar) => sum + bar.trade_count!, 0)
      : null;
    const buyVolume = group.every((b) => b.buy_volume !== undefined)
      ? group.reduce((sum, b) => sum + b.buy_volume!, 0)
      : undefined;
    const sellVolume = group.every((b) => b.sell_volume !== undefined)
      ? group.reduce((sum, b) => sum + b.sell_volume!, 0)
      : undefined;
    const reconstructed = group.some((b) => b.reconstructed === true) ? true : undefined;
    if (!Number.isFinite(volume) || (tradeCount !== null && !Number.isSafeInteger(tradeCount)) || (buyVolume !== undefined && !Number.isFinite(buyVolume)) || (sellVolume !== undefined && !Number.isFinite(sellVolume))) {
      throw new Error("resampleBars: aggregate is outside the supported numeric range");
    }
    result.push({
      ...(last.provider === "BINANCE"
        ? { provider: "BINANCE" as const, marketKind: last.marketKind }
        : { provider: last.provider, assetClass: last.assetClass }),
      type: "bar",
      symbol: last.symbol,
      interval_ms: targetIntervalMs,
      ts_open: bucketOpen,
      open: group[0].open,
      high: Math.max(...group.map((b) => b.high)),
      low: Math.min(...group.map((b) => b.low)),
      close: last.close,
      volume,
      ...(buyVolume !== undefined ? { buy_volume: buyVolume } : {}),
      ...(sellVolume !== undefined ? { sell_volume: sellVolume } : {}),
      trade_count: tradeCount,
      closed,
      ...(reconstructed !== undefined ? { reconstructed } : {}),
    });
  }
  return result;
}

function copyOutputs(outputs: Outputs | null): Outputs {
  if (outputs === null) return {};
  const copy: Record<string, (number | null)[]> = {};
  for (const [key, values] of Object.entries(outputs)) copy[key] = [...values];
  return copy;
}

export function captureOf(runtime: IndicatorRuntime, id: string, hasLines: boolean): Capture {
  const outputs = runtime.getOutput(id);
  const markers = runtime.getMarkers(id);
  return {
    outputs: copyOutputs(outputs),
    markers: markers === null ? [] : markers.map((call) => ({ ...call })),
    faulted: hasLines ? outputs === null : markers === null,
  };
}

export function openLiveSession<S, T>(
  def: RuntimeIndicatorDef<S, T>,
  settings: T,
  extras: LiveExtras = {},
  warmup: readonly BarFrame[] = [],
): LiveSession<S, T> {
  const runtime = createIndicatorRuntime([def as RuntimeIndicatorDef<unknown, unknown>]);
  const bars: BarFrame[] = [...warmup];
  const mutations: ChartBarMutation[] = [];
  let discarded = 0;
  if (extras.ticks !== undefined) runtime.setTicks(extras.ticks, []);
  if (extras.l2 !== undefined) runtime.setL2(extras.l2, []);
  if (extras.liquidity !== undefined) runtime.setLiquidity(extras.liquidity, []);
  runtime.setActive(new Set([def.id]), { [def.id]: settings }, bars);

  const session: LiveSession<S, T> = {
    def,
    runtime,
    bars,
    mutations,
    get discarded() {
      return discarded;
    },
    setTicks(ticks) {
      runtime.setTicks(ticks, bars);
    },
    setL2(l2) {
      runtime.setL2(l2, bars);
    },
    updateSettings(next) {
      runtime.updateSettings(def.id, next, bars);
    },
    dispatch(arrival) {
      arrival.act?.(session);
      const mutation = mergeChartBar(bars, arrival.bar);
      mutations.push(mutation);
      if (mutation === "REJECTED_REOPEN") return mutation;
      let removed = 0;
      if (bars.length > MAX_RETAINED_SOURCE_BARS) {
        removed = bars.length - MAX_RETAINED_SOURCE_BARS;
        bars.splice(0, removed);
        discarded += removed;
      }
      runtime.onBar(arrival.bar, mutation, bars, arrival.trades, arrival.tradeAvailability);
      if (removed > 0 && mutation === "APPENDED") runtime.discardLeading(removed, bars[0]?.ts_open);
      return mutation;
    },
    capture() {
      return captureOf(runtime, def.id, def.lines.length > 0);
    },
    close() {
      runtime.setActive(new Set(), {}, []);
    },
  };
  return session;
}

  key: string;

  right: number | null | undefined;

export function valuesEqual(left: number | null | undefined, right: number | null | undefined, tolerance: number): boolean {
  if (left === right) return true;
  if (left === null || left === undefined || right === null || right === undefined) return false;
  if (Number.isNaN(left) || Number.isNaN(right)) return false;
  return Math.abs(left - right) <= tolerance;
}

/** Every position where two output maps disagree; keys present on one side only count as disagreements. */
export function diffOutputs(left: Outputs, right: Outputs, tolerance = 0, upToIndex = Infinity): OutputDiff[] {
  const diffs: OutputDiff[] = [];
  const keys = new Set([...Object.keys(left), ...Object.keys(right)]);
  for (const key of keys) {
    const a = left[key] ?? [];
    const b = right[key] ?? [];
    const length = Math.min(Math.max(a.length, b.length), upToIndex + 1);
    for (let index = 0; index < length; index += 1) {
      if (!valuesEqual(a[index], b[index], tolerance)) diffs.push({ index, key, left: a[index], right: b[index] });
    }
  }
  return diffs;
}

export function compareMethods(fixture: ReturnType<typeof relativeVolumeEquityFixture>): ComparisonTable {
  const { bars, labels } = fixture;
  const engine = createRelativeVolumeEngine({ sessions: RELATIVE_VOLUME_DEFAULT_SETTINGS.sessions, minSessions: RELATIVE_VOLUME_DEFAULT_SETTINGS.minSessions, clock: "auto" });
  const results: Record<Method, MethodResult> = { timeOfDay: emptyResult(), sameSlotMean: emptyResult(), rolling: emptyResult() };
  const anomalyIndices = new Set(labels.anomalyIndices);
  const predictableSlotIndices = new Set(labels.predictableSlotIndices);
  const evaluationIndices = new Set(labels.evaluationIndices);
  for (let index = 0; index < bars.length; index += 1) {
    const reading = engine.onBar(bars[index]);
    if (!evaluationIndices.has(index)) continue;
    const ratios: Record<Method, number | null> = { timeOfDay: reading.rvol, sameSlotMean: reading.slotMeanRatio, rolling: reading.rolling };
    // Readiness is asserted from actual prior observations per key, never from a calendar day number.
    if (METHODS.some((method) => ratios[method] === null)) continue;
    const anomaly = anomalyIndices.has(index);
    const predictable = predictableSlotIndices.has(index);
    for (const method of METHODS) {
      const result = results[method];
      const detected = (ratios[method] as number) >= THRESHOLD;
      result.eligible += 1;
      if (predictable) result.predictableEligible += 1;
      if (detected) result.detections += 1;
      if (anomaly && detected) result.anomaliesHit += 1;
      if (!anomaly && detected) {
        result.falsePositives += 1;
        if (predictable) result.predictableFalsePositives += 1;
      }
    }
  }
  return { anomalies: labels.anomalies.length, results };
}

  if (!Number.isSafeInteger(tsMs) || tsMs < 0) throw new Error("market-calendar: timestamp must be a non-negative safe integer");

export function probeReplayPooled<S, T>(def: RuntimeIndicatorDef<S, T>, bars: readonly BarFrame[], settings: T, options: PooledReplayOptions = {}): PooledReplayProbe {
  const warmupRuns = options.warmupRuns ?? 3;
  const timedRuns = options.timedRuns ?? 5;
  const extras = options.extras ?? {};
  const pooled: number[] = [];
  const perRun: Percentiles[] = [];
  const runWallMs: number[] = [];
  let faulted = false;
  const lastClosed = bars.findLastIndex((bar) => bar.closed);
  const run = (timed: boolean): void => {
    const ownerId = `pooled:${nextPooledOwnerId}:${def.id}`;
    nextPooledOwnerId += 1;
    const samples: number[] = [];
    try {
      const state = withDrawOwnerScope(ownerId, () => def.createState(settings));
      const runStarted = performance.now();
      for (let index = 0; index < bars.length; index += 1) {
        const bar = bars[index];
        const ctx: IndicatorBarCtx<S, T> = {
          bar,
          trades: [],
          tradeAvailability: "HISTORICAL_UNAVAILABLE",
          // The same knowledge-time cutoffs indicatorRuntime.makeCtx applies: a
          // liquidity provider with atTime is asked for the bar's close and a
          // null answer is unavailable; an L2 view without a cut falls back.
          liquidity: (extras.liquidity?.atTime ? extras.liquidity.atTime(bar.ts_open + bar.interval_ms) : extras.liquidity) ?? undefined,
          l2: extras.l2?.atTime?.(bar.ts_open + bar.interval_ms) ?? extras.l2 ?? undefined,
          ticks: extras.ticks ?? undefined,
          state,
          settings,
          replace: false,
          replaying: true,
          drawNow: index >= lastClosed,
          barIndex: index,
          barCount: bars.length,
          ta: EMPTY_TA,
          draw: NOOP_DRAW,
          markers: NOOP_MARKERS,
          pane: { paneIndex: 0 },
        };
        const started = performance.now();
        def.onBar(ctx);
        const output = def.readOutput(state);
        const elapsed = performance.now() - started;
        if (timed) samples.push(elapsed);
        for (const value of Object.values(output)) if (value !== null && !Number.isFinite(value)) faulted = true;
      }
      if (timed) {
        runWallMs.push(performance.now() - runStarted);
        perRun.push(percentilesOf(samples));
        pooled.push(...samples);
      }
    } catch {
      faulted = true;
    } finally {
      clearForIndicator(ownerId);
    }
  };
  for (let index = 0; index < warmupRuns; index += 1) run(false);
  for (let index = 0; index < timedRuns; index += 1) run(true);
  return { id: def.id, bars: bars.length, warmupRuns, timedRuns, pooled: percentilesOf(pooled), perRun, runWallMs, faulted };
}
